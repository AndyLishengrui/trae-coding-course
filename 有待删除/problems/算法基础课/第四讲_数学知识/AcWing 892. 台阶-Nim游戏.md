# AcWing 892. 台阶-Nim游戏 — 台阶-Nim游戏

**难度:** 中等 | **时间限制:** 1000ms | **内存限制:** 256MB

> 原题链接: https://www.acwing.com/problem/content/892/

## 题目描述

给定一个 n 级台阶的楼梯，每级台阶上都有若干个石子，其中第 i 级台阶上有 ai个石子 (i ≥ 1)。

两位玩家轮流操作，每次可以从任意一级台阶上拿走至少 1 个石子并将其放到下一级台阶中（放到地面上的石子不能再移动）。

无法进行操作的一方失败。

问：在双方均采用最优策略的情况下，先手是否必胜？

### 输入格式

第一行包含整数 n (1 ≤ n ≤ 105)。第二行包含 n 个整数 a1, a2, …, an(1 ≤ ai≤ 109)，表示各级台阶上的石子数。

### 输出格式

如果先手必胜，则输出 "Yes"；否则输出 "No"。

### 样例

**输入:**
```
3
2 1 3
```

**输出:**
```
Yes
```

### 提示

将每个台阶视为一个子游戏。对于台阶 i，每个石子单独的 Grundy 值为 i（因为操作允许将石子移到任一更低级的台阶）。由于同一台阶中偶数个石子的贡献相消，初态 Nim 和即为所有 ai为奇数的台阶编号的 XOR。先手必胜当且仅当该 XOR 不为 0。

## AC代码

```cpp
//只需要考虑奇数级台阶的情况
#include <iostream>
#include <cstring>
#include <algorithm>

using namespace std;

int main()
{
    int n;
    int res = 0;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++)
    {
      int x;
      scanf("%d", &x);
      if (i % 2) res ^= x;//奇数台阶的情况求异或（Nim游戏）
    }

    if (res) puts("Yes");//先手必胜
    else puts("No");//先手必败

    return 0;
}
```
