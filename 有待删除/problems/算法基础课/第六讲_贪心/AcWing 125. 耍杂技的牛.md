# AcWing 125. 耍杂技的牛 — 机器人塔

**难度:** 困难 | **时间限制:** 1000ms | **内存限制:** 256MB

> 原题链接: https://www.acwing.com/problem/content/125/

## 题目描述

在一个未来的科技都市中，林克是一名机器人工程师，负责管理N个智能机器人（编号为1..N）。

这些机器人被设计用于执行高空维修任务，最近它们被分配到一个新的项目：

通过协作组装一个垂直的机器人塔，以完成一项超高层建筑的维护工作。

为了完成任务，林克需要指挥这些机器人通过自适应磁力接口彼此连接，形成一个稳定的垂直堆叠结构。

每个机器人可以悬浮并支撑上方的其他机器人，但它们的稳定性和负载能力各不相同。

林克的目标是为这些机器人确定一个最佳的堆叠顺序。

每个机器人拥有两个关键参数：

质量W_i`（单位：千克），表示其自身重量。
负载能力S_i`（单位：千克力），表示其能够承受的最大额外重量。
在堆叠中，每个机器人的“风险指数”定义为其上方所有机器人的总质量（不包括自身）减去其负载能力S_i`

。如果风险指数过高，机器人的支撑结构可能会过载，导致整个塔失稳。

林克的任务是设计一个堆叠顺序，使得所有机器人的风险指数中的最大值尽可能小，以确保维修任务的安全性和效率。

例如，有3个机器人：

机器人1：W_1 = 10, S_1 = 3`

机器人2：W_2 = 2, S_2 = 5`

机器人3：W_3 = 3, S_3 = 3`

一种可能的堆叠顺序：

底部：机器人1 (W = 10, S = 3`)，上方质量 =2 + 3 = 5`，风险指数 =5 - 3 = 2`

中间：机器人2 (W = 2, S = 5`)，上方质量 =(3)，风险指数 =3 - 5 = -2`

顶部：机器人3 (W = 3, S = 3`)，上方质量 =(0)，风险指数 =0 - 3 = -3`

最大风险指数为\max(2, -2, -3) = 2`。

你的目标是帮助林克计算出堆叠顺序，并输出最小的最大风险指数，确保机器人塔能够在高空作业中保持稳定。

### 输入格式

第一行输入整数N，表示机器人的数量。

接下来N行，每行输入两个整数，表示机器人的质量和负载能力，第i行表示第i个机器人的质量W_i`以及它的负载能力S_i`。

### 输出格式

输出一个整数，表示最大风险指数的最小可能值。

### 样例

**输入:**
```
3
10 3
2 5
3 3
```

**输出:**
```
2
```

## AC代码

```cpp
#include <iostream>
#include <cstring>
#include <algorithm>

using namespace std;
typedef pair<int, int> PII;


const int N = 500007;

int n;
PII a[N];

int main()
{
    ios::sync_with_stdio(false);
    //读入数据
    cin>>n;
    for (int i = 0; i < n; i ++ )
    {
      int w, s;
      cin>>w>>s;
      a[i] = {w+s,w};
    }

    sort(a, a+n);

    int res = -1e9;
    for (int i = 0, sum = 0; i < n; i ++ )
    {
      int w = a[i].second, s = a[i].first - w;
      res = max(res, sum - s);
      sum += w;
    }

    cout<<res<<endl;
    return 0;

}
```
