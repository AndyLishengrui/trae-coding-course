# AcWing 711. 乘法表 — 乘法表

**难度:** 简单 | **时间限制:** 1000ms | **内存限制:** 256MB

> 原题链接: https://www.acwing.com/problem/content/711/

## 题目描述

输入一个整数 N，输出 N 的乘法表，格式如下：

`1 x N = N
2 x N = 2N
...
10 x N = 10N
`

### 输入格式

一个整数 N。

数据范围1<N<1000

### 输出格式

输出 N 的乘法表，具体形式参照输出样例。

### 样例

**输入:**
```
140
```

**输出:**
```
1 x 140 = 140
2 x 140 = 280
3 x 140 = 420
4 x 140 = 560
5 x 140 = 700
6 x 140 = 840
7 x 140 = 980
8 x 140 = 1120
9 x 140 = 1260
10 x 140 = 1400
```

### 提示

注意输出格式。

## AC代码

```cpp
#include <cstdio>

int main()
{
  int n;
  scanf("%d", &n);

  for (int i = 1; i <= 10; i ++ ) printf("%d x %d = %d\n", i, n, i * n);

  return 0;
}
```
