# AcWing 607. 平均数2 — 平均数2

**难度:** 简单 | **时间限制:** 1000ms | **内存限制:** 256MB

> 原题链接: https://www.acwing.com/problem/content/607/

## 题目描述

读取三个浮点数 A，B 和 C 的值，对应于三个学生的成绩。

请你计算学生的平均分，其中 A 的成绩的权重为 2，B 的成绩的权重为 3，C 的成绩的权重为 5。

成绩的取值范围在 0 到 10 之间，且均保留一位小数。

### 输入格式

输入共三行，每行包含一个浮点数，第一行表示 A，第二行表示 B，第三行表示 C。

### 输出格式

输出格式为`MEDIA = X`，其中 X 为平均分，结果保留一位小数。

### 样例

**输入:**
```
5.0
6.0
7.0
```

**输出:**
```
MEDIA = 6.3
```

### 提示

计算平均分时需要注意权重。

## AC代码

```cpp
#include <cstdio>

int main()
{
    double a, b, c;
    scanf("%lf%lf%lf", &a, &b, &c);
    printf("MEDIA = %.1lf\n", (a * 2 + b * 3 + c * 5) / 10);

    return 0;
}
```
