# NQ021 废强重建

## 解题思路
1. **读取输入**：读取墙的列数n，然后读取n列墙的高度。
2. **计算总高度**：累加所有墙的高度得到总高度。
3. **计算平均值**：总高度除以n，向下取整得到平均值。
4. **统计砖块数**：遍历所有墙的高度，累加低于平均值的墙与平均值的差值，得到需要的砖块数。
5. **输出结果**：打印需要的砖块数，测试用例之间用空行分隔。
