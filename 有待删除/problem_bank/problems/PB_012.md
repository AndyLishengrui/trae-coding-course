# 打印字符串

## 题目描述

给定字符串，编写函数 void print(char str[]) （Python 用 print_str()）打印该字符串。

## 输入格式

一行一个字符串。数据范围：1 ≤ 长度 ≤ 100

## 输出格式

一行表示打印出的字符串。

## 样例

**样例 1：**

输入：
I love AcWing.
输出：
I love AcWing.
