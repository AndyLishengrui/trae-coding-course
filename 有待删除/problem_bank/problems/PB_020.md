# 求 1+2+...+n

## 题目描述

求1+2+...+n，要求不能使用乘除法、for、while、if、else、switch、case 等关键字及条件判断语句 (A?B : C)。

## 输入格式

输入一个整数n。数据范围：1 ≤ n ≤ 50000

## 输出格式

输出1+2+...+n的结果。

## 样例

**样例 1：**

输入：
10
输出：
55
