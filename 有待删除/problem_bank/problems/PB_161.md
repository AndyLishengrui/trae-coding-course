# NQ083 思路分析

## 问题描述
给定两个字符串 s1 和 s2，求它们的最长公共子序列的长度。

## 思考过程
1. **问题分析**：最长公共子序列（LCS）是一个经典问题，要求找到两个字符串中最长的公共子序列，子序列不需要连续。
2. **算法选择**：动态规划是解决 LCS 问题的标准方法，因为它可以有效地处理子问题重叠的情况。
3. **状态定义**：使用二维数组 `maxSlength[i][j]` 表示 s1 的前 i 个字符和 s2 的前 j 个字符的最长公共子序列长度。
4. **状态转移**：根据当前字符是否相同，有两种转移情况：如果相同则长度加 1，否则取两种情况的最大值。
5. **边界条件**：当其中一个字符串为空时，最长公共子序列长度为 0。

## 算法思路
1. **动态规划**：使用二维数组 `maxSlength[i][j]` 表示 s1 的前 i 个字符和 s2 的前 j 个字符的最长公共子序列长度。
2. **状态转移**：
   - 如果 s1[i-1] == s2[j-1]，则 maxSlength[i][j] = maxSlength[i-1][j-1] + 1
   - 否则，maxSlength[i][j] = max(maxSlength[i-1][j], maxSlength[i][j-1])
3. **边界条件**：当 i=0 或 j=0 时，maxSlength[i][j] = 0
4. **结果计算**：maxSlength[len1][len2] 即为最长公共子序列的长度

## 实现步骤
1. 读取两个字符串 s1 和 s2。
2. 计算两个字符串的长度 len1 和 len2。
3. 初始化二维数组 maxSlength，边界值设为 0。
4. 递推计算 maxSlength 数组。
5. 输出 maxSlength[len1][len2]。

## 关键点编码逻辑
1. **字符比较**：使用 `s1[i-1] == s2[j-1]` 比较两个字符串的当前字符，因为字符串索引从 0 开始。
2. **状态转移**：根据字符是否相同，选择不同的转移方式。
3. **边界初始化**：将二维数组的第一行和第一列初始化为 0，处理空字符串的情况。
4. **双重循环**：使用嵌套循环遍历两个字符串的所有字符组合。

## 时间复杂度
- 时间复杂度：O(len1 * len2)，其中 len1 和 len2 分别是两个字符串的长度。需要遍历二维数组的所有元素。
- 空间复杂度：O(len1 * len2)，需要使用二维数组存储动态规划状态。
