# 最小的 k 个数

## 题目描述

输入 n 个整数，找出其中最小的 k 个数。注意输出数组内元素请按从小到大顺序排序。

## 输入格式

输入一个整数数组和一个整数 k。数据范围：1 ≤ k ≤ n ≤ 1000

## 输出格式

输出最小的 k 个数，按从小到大排序。

## 样例

**样例 1：**

输入：
[1,2,3,4,5,6,7,8]
4
输出：
[1,2,3,4]
