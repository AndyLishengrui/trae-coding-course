# NQ001 求连续整数和

## 解题思路
1. **读取起始整数**：从输入中读取第一个整数作为起始值 a。
2. **过滤有效n值**：继续读取输入，跳过所有非正整数，直到找到第一个大于0的整数作为n。
3. **计算连续和**：初始化结果为0，循环n次，每次将当前a的值累加到结果中，然后a自增1。
4. **输出结果**：打印最终计算得到的连续整数和。
