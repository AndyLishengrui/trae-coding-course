# NQ098 靶形数独

## 问题描述
解决数独问题，填充数独盘面中的空白格子（用0表示），使得每一行、每一列和每一个3x3的小九宫格都包含1-9的数字，且无重复。同时，计算数独的得分，得分规则是根据格子到中心的距离计算，距离中心越近，得分越高。

## 算法思路
1. **位运算优化**：使用位运算来表示每个位置的可用数字，提高效率。
   - `row[i]` 表示第i行的可用数字
   - `col[j]` 表示第j列的可用数字
   - `cell[x][y]` 表示第(x,y)个小九宫格的可用数字

2. **预处理**：
   - 预处理 `LOG2` 数组，用于将低位1的位置转换为数字
   - 预处理 `ones` 数组，用于快速计算每个位掩码中1的个数

3. **深度优先搜索（DFS） + 回溯**：
   - 每次选择可选数字最少的空白格子进行填充，减少搜索空间
   - 尝试填入每个可能的数字，递归搜索
   - 如果无法继续填充，回溯到上一步

4. **得分计算**：
   - 计算每个格子到中心的距离，距离中心越近，得分权重越高
   - 实时更新当前得分，当所有空白格子都被填充时，更新最大得分

5. **状态管理**：
   - 使用位运算快速更新和恢复状态
   - 当所有空白格子都被填充时，更新最大得分

## 代码实现
- **C++**：使用位运算和DFS回溯，通过预处理和位操作优化效率。
- **Python**：使用位运算和DFS回溯，通过预处理和位操作优化效率，注意输入处理。

## 时间复杂度
- 时间复杂度：O(9^(n))，其中 n 是空白格子的数量。但由于使用了启发式搜索（选择可选数字最少的格子），实际运行时间远低于最坏情况。
- 空间复杂度：O(1)，需要存储数独盘面和位掩码数组。
