# NQ061 求矩形重叠面积解题思路

## 解题思路
1. **问题描述**：输入两个矩形的坐标，计算它们的重叠面积。每个矩形由左上角和右下角的坐标定义。
2. **输入处理**：读取多个测试用例，每个测试用例包含8个浮点数，分别是第一个矩形的左上角坐标(x1, y1)、右下角坐标(x2, y2)，以及第二个矩形的左上角坐标(x3, y3)、右下角坐标(x4, y4)。
3. **核心逻辑**：
   - 确保每个矩形的x1 < x2, y1 < y2
   - 计算重叠区域的边界：
     - 重叠区域的左边界是两个矩形左边界的最大值
     - 重叠区域的右边界是两个矩形右边界的最小值
     - 重叠区域的下边界是两个矩形下边界的最大值
     - 重叠区域的上边界是两个矩形上边界的最小值
   - 判断是否有重叠：如果左边界 >= 右边界或下边界 >= 上边界，则无重叠
   - 计算重叠面积：(右边界 - 左边界) * (上边界 - 下边界)
4. **关键处理**：
   - 处理坐标顺序，确保每个矩形的x1 < x2, y1 < y2
   - 处理无重叠的情况
   - 保留两位小数输出

## 输入输出示例

#### 输入示例
```
0 0 2 2 1 1 3 3
0 0 1 1 2 2 3 3
```

#### 输出示例
```
1.00
0.00
```

**解释**：
- 第一组：两个矩形有重叠区域，重叠面积为1.00
- 第二组：两个矩形无重叠，输出0.00

## 复杂度分析

### 时间复杂度
- 对于每组测试用例，计算重叠面积的时间复杂度为O(1)
- 总体时间复杂度为O(T)，其中T是测试用例的数量

### 空间复杂度
- 仅使用常数级额外空间，空间复杂度为O(1)
