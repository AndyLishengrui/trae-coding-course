# NQ060

## 题目描述

本题要求在数组中找到所有满足四数之和等于目标值的四元组。采用排序加双指针的方法，具体步骤如下：首先对数组进行排序，这样可以利用双指针技术并方便去重。然后使用三层循环遍历前三个数i、j、k，其中i < j < k。对于每个i、j、k组合，使用双指针l从数组末尾开始向左移动，找到最小的l使得四数之和大于等于目标值。如果此时四数之和等于目标值，则记录该四元组。为了避免重复四元组，需要在循环中跳过重复的i、j、k值。该算法的时间复杂度为O(n³)，其中n是数组长度，因为排序的时间复杂度为O(n log n)，而三层循环的时间复杂度为O(n³)。空间复杂度为O(1)（不考虑存储结果的空间）。该方法通过排序和双指针技术，将暴力解法的O(n⁴)时间复杂度优化到O(n³)，提高了算法效率。
