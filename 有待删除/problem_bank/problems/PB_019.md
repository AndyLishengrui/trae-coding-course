# 替换空格

## 题目描述

请实现一个函数，把字符串中的每个空格替换成%20。

## 输入格式

输入一个字符串。数据范围：0 ≤ 输入字符串的长度 ≤ 1000

## 输出格式

输出替换后的字符串。

## 样例

**样例 1：**

输入：
We are happy.
输出：
We%20are%20happy.


## 提示

注意输出格式。
