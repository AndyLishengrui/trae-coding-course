# 0 到 n-1 中缺失的数字

## 题目描述

一个长度为n−1的递增排序数组中的所有数字都是唯一的，并且每个数字都在范围0到n−1之内。在范围00到n−1的n个数字中有且只有一个数字不在该数组中，请找出这个数字。

## 输入格式

第一行输入整数 n；第二行输入 n-1 个整数，数字之间以空格隔开。数据范围1≤n≤1000

## 输出格式

输出一个整数，表示缺失的数字。

## 样例

**样例 1：**

输入：
[0,1,2,4]
输出：
3
