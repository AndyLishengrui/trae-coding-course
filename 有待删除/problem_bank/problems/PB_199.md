# 输出N皇后的所有摆法思路

## 题目描述

# NQ072 输出N皇后的所有摆法思路

## 问题分析

### 问题描述
输入一个正整数N，输出N皇后问题的所有摆法。

### 问题分析
- N皇后问题是一个经典的回溯算法问题
- 目标是在N×N的棋盘上放置N个皇后，使得它们互不攻击
- 皇后的攻击范围包括同一行、同一列和同一对角线

## 算法设计

### 深度优先搜索（DFS）+ 回溯法
1. **状态表示**：使用一个数组`positions`，其中`positions[i]`表示第i行皇后的列位置
2. **递归过程**：
   - 从第0行开始，尝试在每一列放置皇后
   - 检查当前位置是否安全（不与之前的皇后冲突）
   - 如果安全，放置皇后并递归处理下一行
   - 如果所有行都处理完毕，输出当前摆法
3. **安全检查**：
   - 检查同一列是否已有皇后
   - 检查同一对角线是否已有皇后

### 算法优势
- **正确性**：通过深度优先搜索和回溯，确保找到所有可能的解决方案
- **效率**：通过提前剪枝（安全检查），避免无效的搜索路径
- **简洁性**：代码结构清晰，逻辑简单

## 代码实现

### C++实现
```cpp
// NQ072 输出N皇后的所有摆法
#include <iostream>
#include <vector>
using namespace std;

int N;
vector<int> positions;

bool isSafe(int row, int col) {
    for (int i = 0; i < row; ++i) {
        if (positions[i] == col) {
            return false;
        }
        if (abs(positions[i] - col) == abs(row - i)) {
            return false;
        }
    }
    return true;
}

void dfs(int row) {
    if (row == N) {
        for (int pos : positions) {
            cout << pos;
        }
        cout << endl;
        return;
    }
    
    for (int col = 1; col <= N; ++col) {
        if (isSafe(row, col)) {
            positions[row] = col;
            dfs(row + 1);
        }
    }
}

int main() {
    cin >> N;
    positions.resize(N);
    dfs(0);
    return 0;
}
```

### Python实现
```python
# NQ072 输出N皇后的所有摆法
def is_safe(row, col, positions):
    for i in range(row):
        if positions[i] == col:
            return False
        if abs(positions[i] - col) == abs(row - i):
            return False
    return True

def dfs(row, N, positions):
    if row == N:
        for pos in positions:
            print(pos, end='')
        print()
        return
    
    for col in range(1, N + 1):
        if is_safe(row, col, positions):
            positions[row] = col
            dfs(row + 1, N, positions)

def main():
    N = int(input().strip())
    positions = [0] * N
    dfs(0, N, positions)

if __name__ == "__main__":
    main()
```

## 时间空间复杂度分析

### 时间复杂度
- **时间复杂度**：O(N!)，其中N是皇后的数量
- 对于第一个皇后，有N种选择
- 对于第二个皇后，最多有N-1种选择
- 对于第三个皇后，最多有N-2种选择
- 以此类推，总共有N!种可能的排列
- 实际运行时间会比N!小，因为很多路径会被安全检查提前剪枝

### 空间复杂度
- **空间复杂度**：O(N)
- 递归调用栈的深度最多为N
- 存储皇后位置的数组大小为N

## 算法优化

1. **位运算优化**：可以使用位运算来加速安全检查，减少计算时间
2. **记忆化**：可以记录已经处理过的状态，避免重复计算
3. **并行处理**：对于较大的N，可以考虑使用并行计算来加速搜索过程

## 总结

- N皇后问题是回溯算法的经典应用
- 深度优先搜索结合回溯法是解决此类问题的有效方法
- 安全检查是算法的关键，能够提前剪枝无效路径
- 时间复杂度为O(N!)，但实际运行时间会因剪枝而减少
- 该算法可以推广到其他类似的排列问题，如八皇后问题的扩展

通过理解N皇后问题的解决方案，我们可以更好地掌握回溯算法的思想和应用，为解决更复杂的问题打下基础。
