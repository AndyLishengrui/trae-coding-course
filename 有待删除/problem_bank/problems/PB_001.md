# 日落

## 题目描述

在大城市里，人们总是匆匆忙忙，很少有时间欣赏美景。但是今天不同，你站在一座摩天大楼的最顶端俯瞰着城市的地平线，欣赏着美丽的日落。城市中从左到右一共有 N 座建筑，每座建筑都有一个高度。如果一座建筑的右边存在更高的建筑，那么这座建筑就无法看到日落，反之则可以看到日落。请你统计出能够看到日落的建筑数量。

## 输入格式

第一行包含整数 N，表示建筑数量。第二行包含 N 个整数 h1, h2, ..., hN，表示从左到右每座建筑的高度。

## 输出格式

输出一个整数，表示能够看到日落的建筑数量。

## 样例

**样例 1：**

输入：
4
3 7 4 1
输出：
3


## 提示

数据范围：1 ≤ N ≤ 1001 ≤ hi ≤ 500
