# NQ027 丑数判断

## 解题思路
1. **问题定义**：丑数是只包含质因数2、3、5的正整数。
2. **判断逻辑**：对于给定的数n，判断其是否为丑数。
3. **核心步骤**：
   - 如果n <= 0，直接返回false（丑数必须是正整数）
   - 不断除以2，直到不能整除
   - 不断除以3，直到不能整除
   - 不断除以5，直到不能整除
   - 如果最终结果是1，返回true，否则返回false
4. **输入输出**：读取输入的整数n，输出"true"或"false"表示是否为丑数。
