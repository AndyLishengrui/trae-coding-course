# NQ075 思路分析

## 问题描述
输入多个测试用例，每个测试用例包含两个整数 n 和 p，将整数 n 转换为 p 进制表示并输出。

## 思考过程
1. **问题分析**：需要将十进制整数转换为任意进制（2-36）的表示，包括处理负数的情况。
2. **算法选择**：使用除基取余法，这是进制转换的标准算法。
3. **数据结构**：使用字符数组（或列表）存储转换后的每一位数字。
4. **字符映射**：需要将数字 0-35 映射到对应的字符（0-9, A-Z）。

## 算法思路
- **除基取余法**：将整数不断除以进制基数 p，记录余数，然后将余数逆序排列得到结果。
- **字符映射**：使用打表法创建数字到字符的映射表，方便快速查找。
- **负数处理**：记录负数标志，将其转换为正数处理，最后添加负号。
- **边界处理**：对于进制 p 越界的情况（p ≤ 1 或 p > 36），忽略该测试用例。

## 实现步骤
1. **创建字符映射表**：预先生成 0-35 对应的字符（0-9, A-Z）。
2. **读取输入**：读取多个测试用例，每个测试用例包含 n 和 p。
3. **边界检查**：检查 p 是否在有效范围内（2-36）。
4. **负数处理**：如果 n 是负数，记录标志并转换为正数。
5. **进制转换**：使用除基取余法，将 n 转换为 p 进制。
6. **结果输出**：如果是负数，先输出负号，然后逆序输出余数。

## 关键点编码逻辑
- **字符映射函数 f**：将数字转换为对应的字符，小于 10 的数字直接转换为字符 '0'-'9'，大于等于 10 的数字转换为 'A'-'Z'。
- **除基取余循环**：不断将 n 除以 p，记录余数，直到 n 为 0。
- **逆序输出**：因为余数是从低位到高位生成的，所以需要逆序输出才能得到正确的结果。
- **输入处理**：使用循环读取输入，处理多个测试用例。

## 时间复杂度
- **时间复杂度**：O(logₚ n)，其中 n 是输入的整数，p 是进制基数。转换过程需要 logₚ n 次循环。
- **空间复杂度**：O(logₚ n)，需要存储转换后的每一位数字。
