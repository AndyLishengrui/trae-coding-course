# 数字5的封杀

## 题目描述

# NQ049 数字5的封杀解题思路

## 解题思路
1. **问题描述**：将输入字符串中的所有'5'替换为空格，分割成若干个新数字（忽略前导零，全零则输出0），然后对这些数字从小到大排序并输出。
2. **输入处理**：读取多行输入，每行是一个由数字组成的字符串。
3. **核心逻辑**：
   - 将所有'5'替换为空格
   - 分割字符串为多个token
   - 处理每个token，去除前导零
   - 对处理后的数字进行排序
   - 输出排序结果
4. **关键处理**：
   - 处理前导零：找到第一个非零字符，若全为零则输出0
   - 处理空token：忽略由连续'5'分割产生的空字符串

## 输入输出示例

#### 输入示例
```
0551223532050775
```

#### 输出示例
```
0 77 320 1223
```

**解释**：
- 替换'5'为空格后："0  1223 320 0 77 "
- 分割后得到："0", "1223", "320", "0", "77"
- 处理前导零后：0, 1223, 320, 0, 77
- 排序后：0, 77, 320, 1223

## 复杂度分析

### 时间复杂度
- 字符串处理（替换和分割）：O(n)，其中n是字符串长度
- 排序：O(m log m)，其中m是分割后的数字个数
- 总体时间复杂度：O(n + m log m)

### 空间复杂度
- 存储分割后的数字：O(m)
- 总体空间复杂度：O(m)

## 代码实现思路

### C++ 实现
1. 使用`getline`读取每行输入
2. 将所有'5'替换为空格
3. 使用`istringstream`分割字符串
4. 处理每个token，去除前导零
5. 将处理后的数字存入vector并排序
6. 输出排序结果

### Python 实现
1. 逐行读取输入
2. 使用`replace`将'5'替换为空格，然后`split`分割
3. 处理每个token，去除前导零
4. 将处理后的数字存入列表并排序
5. 使用`join`和`map`将结果转换为字符串并输出

## 总结
- 该问题主要考察字符串处理和排序能力
- 通过将'5'替换为空格实现分割，简化了处理逻辑
- 处理前导零是关键步骤，需要特别注意全零的情况
- C++和Python实现各有优势，Python的字符串处理更为简洁
