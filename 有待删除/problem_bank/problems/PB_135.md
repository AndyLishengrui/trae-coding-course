# NQ056 三角形判断解题思路

## 解题思路
1. **问题描述**：输入多组测试用例，每组包含三个整数，判断这三个数是否能构成三角形。如果能构成三角形，输出"OK"；否则输出"NO"。
2. **输入处理**：读取测试用例的数量n，然后读取n组三个整数。
3. **核心逻辑**：
   - 三角形的构成条件：任意两边之和大于第三边
   - 验证条件：a + b > c，a + c > b，b + c > a
   - 三个条件都满足时，才能构成三角形
4. **关键处理**：
   - 不需要排序，直接验证三个条件
   - 处理多组测试用例

## 输入输出示例

#### 输入示例
```
3
3 4 5
1 2 3
2 2 2
```

#### 输出示例
```
OK
NO
OK
```

**解释**：
- 第一组：3+4>5，3+5>4，4+5>3，满足条件，输出OK
- 第二组：1+2=3，不满足条件，输出NO
- 第三组：2+2>2，满足条件，输出OK

## 复杂度分析

### 时间复杂度
- 对于每组测试用例，验证三个条件，时间复杂度为O(1)
- 总体时间复杂度为O(n)，其中n是测试用例的数量

### 空间复杂度
- 仅使用常数级额外空间，空间复杂度为O(1)

## 代码实现思路

### C++ 实现
1. 定义一个函数`canFormTriangle`，接收三个整数参数，返回布尔值
2. 在函数中验证三角形的三个构成条件
3. 读取测试用例数量n
4. 循环处理n组测试用例，每组读取三个整数
5. 调用`canFormTriangle`函数判断，输出相应结果

### Python 实现
1. 定义一个函数`can_form_triangle`，接收三个整数参数，返回布尔值
2. 在函数中验证三角形的三个构成条件
3. 一次性读取所有输入，使用指针逐个处理
4. 读取测试用例数量n
5. 循环处理n组测试用例，每组读取三个整数
6. 调用`can_form_triangle`函数判断，输出相应结果
