# 和为 S 的两个数字(系统错误）

## 题目描述

输入一个数组和一个数字 S，在数组中查找两个数，使得它们的和正好是 S。如果有多对数字的和等于 S，输出任意一对即可。你可以认为每组输入中都至少含有一组满足条件的输出。

## 输入格式

输入一个整数数组和一个整数 S。数据范围：数组长度[1, 1002]。

## 输出格式

输出一对和为 S 的数字。

## 样例

**样例 1：**

输入：
[1, 2, 3, 4]
7
输出：
[3, 4]
