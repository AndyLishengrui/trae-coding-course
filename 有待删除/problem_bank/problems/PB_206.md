# NQ079 思路分析

## 问题描述
给定4个小于10的正整数，判断是否可以通过加减乘除四则运算以及括号，得到结果24。

## 思考过程
1. **问题分析**：需要对4个数字进行排列组合，并尝试所有可能的运算组合，判断是否能得到24。
2. **算法选择**：使用递归和回溯的方法，逐步减少问题规模。
3. **数据结构**：使用向量（或列表）存储当前的数字集合。
4. **边界条件**：当只剩一个数字时，判断是否等于24。

## 算法思路
- **递归回溯**：每次从当前数字集合中选择两个数字，进行四则运算，将结果与剩余数字组成新的集合，递归处理。
- **剪枝优化**：一旦找到可行解，立即返回，不再继续搜索。
- **精度处理**：由于涉及浮点数运算，使用EPS来判断两个数是否相等。
- **运算符处理**：对于加减乘除四种运算，分别处理，注意减法和除法的顺序问题。

## 实现步骤
1. **递归终止条件**：当数字集合只剩一个数字时，判断是否等于24。
2. **选择两个数字**：遍历所有可能的两个数字组合。
3. **生成新集合**：将剩余数字与运算结果组成新的集合。
4. **尝试所有运算**：对选中的两个数字尝试加减乘除运算，注意处理除法的除数不为零的情况。
5. **递归调用**：对新生成的集合递归调用函数。
6. **输入处理**：读取输入，直到遇到四个0为止。

## 关键点编码逻辑
- **isZero函数**：用于判断一个浮点数是否为零，处理浮点数精度问题。
- **count24函数**：递归函数，尝试所有可能的运算组合。
- **双重循环**：遍历所有可能的两个数字组合，避免重复计算。
- **运算处理**：对每对数字尝试六种运算组合（加、乘、减、减（交换）、除、除（交换））。
- **输入处理**：读取多行输入，处理结束条件。

## 时间复杂度
- **时间复杂度**：O(4! * 3^3) = O(24 * 27) = O(648)，其中4!是4个数字的排列数，3^3是每一步选择运算符的可能性。
- **空间复杂度**：O(4)，递归调用栈的深度最多为4。

## 代码优化
- 使用向量（或列表）存储数字，简化代码结构。
- 避免重复计算，通过双重循环选择不同的数字对。
- 一旦找到可行解，立即返回，提高效率。
- 代码结构清晰，注释充分，易于理解。
