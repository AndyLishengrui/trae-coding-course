# NQ048 寻找多数元素解题思路

## 解题思路
1. **问题描述**：寻找输入序列中的多数元素，即出现次数超过一半的元素。
2. **输入处理**：读取一系列整数，直到输入结束。
3. **核心逻辑**：
   - 使用摩尔投票算法（Moore Voting Algorithm）寻找多数元素
   - 初始化候选元素和计数器
   - 遍历每个元素，根据规则更新候选元素和计数器
   - 最终的候选元素即为多数元素
4. **算法原理**：
   - 摩尔投票算法的核心思想是通过消除不同元素来找到多数元素
   - 当遇到相同元素时，计数器加1；遇到不同元素时，计数器减1
   - 当计数器为0时，更换候选元素
   - 由于多数元素出现次数超过一半，最终剩下的候选元素一定是多数元素

## 输入输出示例

#### 输入示例
```
3 3 4 2 4 4 2 4 4
```

#### 输出示例
```
4
```

**解释**：数字4出现了5次，超过总元素数9的一半，因此是多数元素。

## 复杂度分析

### 时间复杂度
- 遍历输入序列一次，时间复杂度为O(n)，其中n是输入元素的数量。

### 空间复杂度
- 仅使用常数级额外空间（候选元素和计数器），空间复杂度为O(1)。

## 代码实现思路

### C++ 实现
1. 使用变量`candidate`存储候选元素，`count`存储计数器
2. 循环读取输入元素，应用摩尔投票算法
3. 输出最终的候选元素

### Python 实现
1. 使用变量`candidate`存储候选元素，`count`存储计数器
2. 一次性读取所有输入数据，转换为整数列表
3. 遍历列表，应用摩尔投票算法
4. 输出最终的候选元素

## 总结
- 摩尔投票算法是一种高效的寻找多数元素的方法，时间复杂度为O(n)，空间复杂度为O(1)
- 该算法利用多数元素出现次数超过一半的特性，通过消除不同元素来找到多数元素
- 适用于处理大规模数据集，不需要额外的存储空间
- 代码实现简洁明了，逻辑清晰
