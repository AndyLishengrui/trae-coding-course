# 最长公共字符串后缀

## 题目描述

给出若干个字符串，输出这些字符串的最长公共后缀。

## 输入格式

由不超过 5 组输入组成。每组输入的第一行是一个整数N。N为 0 时表示输入结束，否则后面会继续有N行输入，每行是一个字符串（字符串内不含空白符）。每个字符串的长度不超过 200。

## 输出格式

每组数据输出一行结果，为N个字符串的最长公共后缀（可能为空）。

## 样例

**样例 1：**

输入：
3
baba
baba
cba
2
cc
cc
2
aa
bb
0
输出：
ba
cc

注意输出格式。
