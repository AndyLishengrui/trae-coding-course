# NQ007 一年中的第几天

## 解题思路
1. **定义每月天数**：创建数组存储每个月的天数（2月默认为28天）。
2. **判断闰年**：定义函数判断是否为闰年（能被4整除但不能被100整除，或能被400整除）。
3. **解析日期**：读取并解析输入的年、月、日。
4. **计算总天数**：初始化总天数为日数，累加前几个月的天数。
5. **闰年调整**：如果是闰年且月份大于2，总天数加1（闰年2月有29天）。
6. **输出结果**：打印计算得到的总天数。
