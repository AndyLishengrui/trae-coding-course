# NQ047 唯一值统计问题

## 解题思路
1. **问题描述**：计算数组前size个元素中的唯一值数量，然后输出 n - size + 唯一值数量 的结果。
2. **输入处理**：读取数组长度n和前缀大小size，然后读取n个元素的数组。
3. **核心逻辑**：
   - 创建一个集合用于存储唯一值
   - 遍历数组前size个元素，将每个元素添加到集合中
   - 计算集合大小得到唯一值数量
   - 应用公式 n - size + 唯一值数量 计算最终结果
   - 输出计算结果
4. **数据结构选择**：
   - C++：使用`unordered_set`存储唯一值，利用哈希表实现，插入和查询效率高
   - Python：使用内置`set`类型存储唯一值，自动处理去重

## 输入输出示例

#### 输入示例
```
5 3
1 2 2 3 4
```

#### 输出示例
```
4
```

**解释**：前3个元素为[1, 2, 2]，唯一值为1和2，共2个，计算5-3+2=4
