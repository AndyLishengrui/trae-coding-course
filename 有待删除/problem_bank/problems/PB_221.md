# NQ095 真假记忆碎片 思路

## 问题描述
给定一个数独盘面，判断其是否为有效数独。具体要求：
1. 验证输入的数独是否符合初始盘面的固定数字
2. 验证每一行、每一列、每一个3x3小九宫格内的数字是否唯一且在1-9之间

## 算法选择
我们选择使用**直接验证法**，因为：
1. 数独盘面固定为9x9，规模较小
2. 直接验证每一行、每一列、每一个小九宫格的有效性
3. 实现简单直观，代码清晰易懂

## 算法原理
1. **验证初始盘面**：检查输入的数独是否与初始盘面的固定数字一致
2. **验证行有效性**：检查每一行的数字是否唯一且在1-9之间
3. **验证列有效性**：检查每一列的数字是否唯一且在1-9之间
4. **验证小九宫格有效性**：检查每一个3x3小九宫格的数字是否唯一且在1-9之间

## 实现步骤

### 步骤1：读取输入
- 读取9行输入，每行9个字符
- 检查输入格式是否正确（每行长度为9）
- 将输入转换为整数数组

### 步骤2：验证初始盘面
- 检查输入的数独是否与初始盘面的固定数字一致
- 如果初始盘面的某个位置不为0，则输入的对应位置必须与初始盘面相同

### 步骤3：验证行有效性
- 遍历每一行
- 使用集合或布尔数组记录已出现的数字
- 检查每个数字是否在1-9之间，且是否重复

### 步骤4：验证列有效性
- 遍历每一列
- 使用集合或布尔数组记录已出现的数字
- 检查每个数字是否重复

### 步骤5：验证小九宫格有效性
- 遍历每一个3x3小九宫格
- 使用集合或布尔数组记录已出现的数字
- 检查每个数字是否重复

### 步骤6：输出结果
- 如果所有验证都通过，输出"Yes"
- 否则输出"No"

## 代码优化

### 时间优化
- 输入处理：一次性读取所有输入，提高处理速度
- 验证顺序：先验证初始盘面，再验证行、列和小九宫格，尽早发现错误
- 数据结构：使用集合或布尔数组记录已出现的数字，快速判断重复

### 空间优化
- 固定大小的数组：数独盘面固定为9x9，使用固定大小的数组存储
- 复用验证数组：在验证过程中复用布尔数组，减少内存使用

## 时间复杂度分析
- 读取输入：O(81) = O(1)
- 验证初始盘面：O(81) = O(1)
- 验证行：O(9 * 9) = O(1)
- 验证列：O(9 * 9) = O(1)
- 验证小九宫格：O(9 * 9) = O(1)
- 总时间复杂度：O(1)（常数时间）

## 空间复杂度分析
- 存储输入：O(81) = O(1)
- 验证辅助数组：O(10) = O(1)
- 总空间复杂度：O(1)（常数空间）

## 注意事项
1. 输入格式验证：确保每行长度为9，且每个字符都是数字
2. 数字范围验证：确保每个数字在1-9之间
3. 初始盘面验证：确保输入的数独与初始盘面的固定数字一致
4. 重复数字验证：确保每行、每列、每个小九宫格内的数字不重复
5. 验证顺序：先验证初始盘面，再验证其他条件，尽早发现错误
