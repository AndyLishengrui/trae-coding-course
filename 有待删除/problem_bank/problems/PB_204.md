# 求第K大的数

## 题目描述

# NQ077 求第K大的数

## 问题描述
给定N个整数，计算任意两个不同整数的差的绝对值，输出第K大的差。

## 算法选择
采用**暴力枚举+排序**的方法，计算所有可能的差的绝对值，排序后去重，然后输出第K大的差。

## 算法原理
1. **问题分析**：需要计算所有两两不同整数的差的绝对值，然后找到第K大的那个值
2. **暴力枚举**：遍历所有可能的数对，计算它们的差的绝对值
3. **排序去重**：对所有差进行降序排序，然后去重，得到唯一的差的集合
4. **查找第K大**：在去重后的有序列表中，直接访问第K-1个元素（因为索引从0开始）

## 实现步骤
1. **读取输入**：读取测试用例数量q
2. **处理每个测试用例**：
   - 读取整数数量n和要找的第K大的差k
   - 读取n个整数到数组中
   - 计算所有可能的两两差的绝对值，存储到列表中
   - 对差进行降序排序
   - 去重，移除重复的差
   - 输出第K大的差（如果k有效）
3. **输出结果**：对于每个测试用例，输出第K大的差或错误信息

## 代码实现

### C++ 实现
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cmath>
using namespace std;

const int MAXN = 1007;
int a[MAXN];

int main() {
    int q;
    cin >> q;
    
    while (q--) {
        vector<int> diffs;
        int n, k;
        cin >> n >> k;
        
        for (int i = 0; i < n; ++i) {
            cin >> a[i];
        }
        
        // 计算所有可能的差
        for (int i = 0; i < n-1; ++i) {
            for (int j = i+1; j < n; ++j) {
                int diff = abs(a[i] - a[j]);
                diffs.push_back(diff);
            }
        }
        
        // 降序排序
        sort(diffs.begin(), diffs.end(), greater<int>());
        
        // 去重
        auto last = unique(diffs.begin(), diffs.end());
        diffs.erase(last, diffs.end());
        
        // 输出第K大的差
        if (k <= diffs.size()) {
            cout << diffs[k-1] << endl;
        } else {
            cout << "Invalid k value!" << endl;
        }
    }
    return 0;
}
```

### Python 实现
```python
def main():
    import sys
    q = int(sys.stdin.readline().strip())
    while q > 0:
        diffs = []
        line = sys.stdin.readline().strip()
        n, k = map(int, line.split())
        line = sys.stdin.readline().strip()
        a = list(map(int, line.split()))
        for i in range(n-1):
            for j in range(i+1, n):
                diff = abs(a[i] - a[j])
                diffs.append(diff)  # 计算所有可能的差
        diffs.sort(reverse=True)  # 降序排序
        unique_diffs = []
        seen = set()
        for d in diffs:
            if d not in seen:
                seen.add(d)
                unique_diffs.append(d)  # 去重
        if k <= len(unique_diffs):
            print(unique_diffs[k-1])  # 输出第K大的差
        else:
            print("Invalid k value!")
        q -= 1

if __name__ == "__main__":
    main()
```

## 算法分析
- **时间复杂度**：O(n² log n)，其中n是整数的数量
  - 计算所有差的时间复杂度：O(n²)
  - 排序的时间复杂度：O(n² log n²) = O(n² log n)
  - 去重的时间复杂度：O(n²)
  - 总体时间复杂度：O(n² log n)

- **空间复杂度**：O(n²)
  - 需要存储所有可能的差，最多有n(n-1)/2个差

## 总结
暴力枚举+排序是解决求第K大差问题的直接方法，虽然时间复杂度为O(n² log n)，但对于n较小的情况（如n≤1000）是完全可行的。该算法的核心步骤包括：

1. **计算所有可能的差**：通过嵌套循环遍历所有数对，计算它们的差的绝对值
2. **排序和去重**：对差进行降序排序，然后去重，得到唯一的差的有序列表
3. **查找第K大的差**：在去重后的列表中直接访问第K-1个元素

**算法特点**：
- 实现简单直观，逻辑清晰
- 代码结构简洁，易于理解和维护
- 对于小规模输入，效率足够高
- 不需要复杂的数据结构，只使用基本的排序和去重操作

**适用场景**：
- 输入规模较小的情况（n≤1000）
- 需要快速实现且代码可读性要求高的场景
- 作为算法入门教学的示例问题

通过本算法的学习，读者可以掌握基本的枚举、排序和去重操作，以及如何解决类似的第K大问题。
