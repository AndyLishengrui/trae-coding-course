# 上台阶问题

## 题目描述

# NQ063 上台阶问题思路

## 问题分析

### 问题描述
有一个n级的台阶，每一步可以走1级或2级，问有多少种不同的上台阶方法。

### 问题分析
- 这是一个典型的斐波那契数列问题
- 对于n级台阶，最后一步要么是从n-1级走1步，要么是从n-2级走2步
- 因此，上n级台阶的方法数等于上n-1级台阶的方法数加上上n-2级台阶的方法数

## 算法设计

### 动态规划思路
1. **状态定义**：`dp[i]`表示上i级台阶的方法数
2. **状态转移方程**：`dp[i] = dp[i-1] + dp[i-2]`
3. **基础情况**：
   - `dp[1] = 1`（1级台阶只有1种走法）
   - `dp[2] = 2`（2级台阶有2种走法：[1,1]和[2]）
4. **预计算**：由于n的范围是1-40，我们可以预先计算所有可能的结果，然后在查询时直接返回

### 算法优势
- **时间复杂度**：预计算时间为O(n)，查询时间为O(1)
- **空间复杂度**：O(n)，用于存储预计算的结果
- **高效处理多组查询**：一次预计算后，多次查询都可以在常数时间内完成

## 代码实现

### C++实现
```cpp
#include <iostream>
using namespace std;

const int MAX_N = 40;
long long dp[MAX_N + 1];

void Precalculate() {
    dp[1] = 1;
    dp[2] = 2;
    
    for (int i = 3; i <= MAX_N; ++i) {
        dp[i] = dp[i-1] + dp[i-2];
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    Precalculate();
    
    int q;
    cin >> q;
    
    while (q--) {
        int n;
        cin >> n;
        if (n >= 1 && n <= MAX_N) {
            cout << dp[n] << '\n';
        }
    }
    return 0;
}
```

### Python实现
```python
def precalculate():
    MAX_N = 40
    dp = [0] * (MAX_N + 1)
    
    dp[1] = 1
    dp[2] = 2
    
    for i in range(3, MAX_N + 1):
        dp[i] = dp[i-1] + dp[i-2]
    
    return dp

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    
    dp = precalculate()
    
    q = int(input[idx])
    idx += 1
    
    for _ in range(q):
        n = int(input[idx])
        idx += 1
        
        if 1 <= n <= 40:
            print(dp[n])

if __name__ == "__main__":
    main()
```

## 时间空间复杂度分析

### 时间复杂度
- **预计算阶段**：O(n)，其中n=40，因此时间复杂度可视为O(1)
- **查询阶段**：O(1) per query
- **整体时间复杂度**：O(q)，其中q是查询次数

### 空间复杂度
- O(n)，其中n=40，用于存储预计算的结果
- 由于n很小，空间复杂度可视为O(1)

### 解释
- 对于n=3，有3种走法：[1,1,1], [1,2], [2,1]
- 对于n=5，有8种走法
- 对于n=10，有89种走法

## 优化策略

1. **预计算**：提前计算所有可能的结果，避免重复计算
2. **输入输出优化**：在C++中使用`ios_base::sync_with_stdio(false); cin.tie(NULL);`来加速输入输出
3. **内存优化**：只存储需要的结果，由于n的范围很小，空间使用非常有限

## 总结

- 该问题是一个典型的动态规划问题，通过预计算斐波那契数列来高效解决
- 时间复杂度为O(q)，空间复杂度为O(1)（相对于问题规模）
- 该方法适用于处理多组查询的情况，能够在常数时间内返回结果
- 代码实现简洁明了，易于理解和维护
