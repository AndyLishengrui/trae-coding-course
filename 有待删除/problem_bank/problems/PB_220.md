# NQ094 全面反击 思路

## 问题描述
给定一个有向无环图（DAG），计算每个节点的可达节点数。

## 算法选择
我们选择使用**拓扑排序 + 逆序处理**的算法，因为：
1. 拓扑排序可以处理有向无环图的节点顺序
2. 逆序处理拓扑序列可以高效计算每个节点的可达节点集合
3. 时间复杂度低：O(n + m)，适用于n和m较大的情况

## 算法原理
1. **拓扑排序**：对图进行拓扑排序，得到一个拓扑序列
2. **逆序处理**：从拓扑序列的末尾开始，逆序计算每个节点的可达节点集合
   - 对于每个节点u，初始时只有自身可达
   - 遍历u的所有邻接点v，将v的可达节点集合合并到u的可达集合中
   - 这样，每个节点的可达集合会包含所有从该节点出发可以到达的节点
3. **内存优化**：使用位运算存储可达性，大幅减少内存使用

## 实现步骤

### 步骤1：读取输入
- 读取n和m
- 构建邻接表和入度数组

### 步骤2：拓扑排序
- 使用队列进行BFS拓扑排序
- 将所有入度为0的节点加入队列
- 依次处理队列中的节点，更新邻接节点的入度
- 记录拓扑序列

### 步骤3：逆序计算可达节点
- 从拓扑序列的末尾开始，逆序处理每个节点
- 使用位运算存储可达性，每个节点的可达性用一个整数的位表示
- 对于每个节点u，先标记自身为可达
- 遍历u的所有邻接点v，合并v的可达集合到u的可达集合

### 步骤4：输出结果
- 统计每个节点的可达节点数（计算二进制中1的个数）
- 输出每个节点的可达节点数

## 代码优化

### 内存优化
- 使用`array`模块存储无符号长整型，比普通列表更节省内存
- 使用位运算表示可达性，每个节点的可达性用一个整数的位表示
- 从0位开始存储节点1的可达性，充分利用位空间

### 时间优化
- 一次性读取所有输入并转换为整数列表，提高输入处理速度
- 使用`deque`作为队列，提高出队操作的效率
- 位运算操作比集合操作更高效，时间复杂度更低

## 时间复杂度分析
- 构建邻接表和入度数组：O(m)
- 拓扑排序：O(n + m)
- 逆序计算可达节点：O(n + m)
- 总时间复杂度：O(n + m)

## 空间复杂度分析
- 邻接表：O(m)
- 入度数组：O(n)
- 拓扑序列：O(n)
- 可达性数组：O(n)（使用位运算，每个元素8字节）
- 总空间复杂度：O(n + m)

## 测试用例

### 输入样例
```
5 4
1 2
2 3
1 4
4 5
```

### 输出样例
```
5
2
1
2
1
```

## 注意事项
1. 处理大规模输入时，使用一次性读取所有输入的方式，避免逐行读取的性能问题
2. 对于内存限制较大的情况，使用位运算存储可达性，大幅减少内存使用
3. 拓扑排序确保了在逆序处理时，每个节点的所有后继节点已经处理完毕
4. 位运算的偏移量从u-1开始计算，充分利用位空间，避免浪费
