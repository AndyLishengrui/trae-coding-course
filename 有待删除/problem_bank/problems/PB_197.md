# 寻找最接近的元素

## 题目描述

# NQ070 寻找最接近的元素

## 问题描述
在一个非降序列中，查找与给定值最接近的元素，但该元素不能与给定值相等。如果有多个元素距离相等，则输出最小的那个。

## 算法选择
采用**二分查找**的方法，使用 `lower_bound` 和 `upper_bound` 函数快速定位候选元素的位置。

## 算法原理
1. **问题分析**：需要找到与给定值最接近但不相等的元素，因此需要考虑该值的左右两侧元素
2. **二分查找定位**：
   - `lower_bound`：找到第一个不小于给定值的元素位置
   - `upper_bound`：找到第一个大于给定值的元素位置
3. **候选元素确定**：
   - 左侧候选：最后一个小于给定值的元素
   - 右侧候选：第一个大于给定值的元素
4. **边界情况处理**：
   - 当所有元素都小于给定值时，选择最后一个元素
   - 当所有元素都大于给定值时，选择第一个元素
5. **距离比较**：比较左右候选元素与给定值的距离，选择距离较小的那个；若距离相等，选择较小的元素

## 实现步骤
1. **读取输入**：读取序列长度n，序列元素，查询次数m，以及m个查询值
2. **哨兵设置**：在序列首尾设置哨兵值，处理边界情况
3. **处理每个查询**：
   - 使用 `lower_bound` 和 `upper_bound` 定位候选元素位置
   - 调整左侧候选位置为最后一个小于给定值的元素
   - 处理边界情况：
     - 所有元素都小于给定值（l == n+1）
     - 所有元素都大于给定值（r == 1）
   - 比较左右候选元素与给定值的距离，输出结果

## 代码实现

### C++ 实现
```cpp
#include <cstdio>
#include <algorithm>
using namespace std;

const int MAXN = 100015;
int g[MAXN];

int main() {
    int n, m;
    scanf("%d", &n);
    
    g[0] = -1000000000;
    for (int i = 1; i <= n; ++i) {
        scanf("%d", &g[i]);
    }
    g[n+1] = 1000000000;
    
    scanf("%d", &m);
    while (m--) {
        int t;
        scanf("%d", &t);
        
        int l = lower_bound(g + 1, g + n + 1, t) - g;
        int r = upper_bound(g + 1, g + n + 1, t) - g;
        if (l <= n) l--;
        
        if (l == n + 1) {
            printf("%d\n", g[n]);
        } else if (r == 1) {
            printf("%d\n", g[1]);
        } else {
            if (t - g[l] > g[r] - t) {
                printf("%d\n", g[r]);
            } else {
                printf("%d\n", g[l]);
            }
        }
    }
    return 0;
}
```

### Python 实现
```python
def lower_bound(arr, left, right, target):
    """查找第一个不小于target的元素的索引"""
    while left < right:
        mid = left + (right - left) // 2
        if arr[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left

def upper_bound(arr, left, right, target):
    """查找第一个大于target的元素的索引"""
    while left < right:
        mid = left + (right - left) // 2
        if arr[mid] <= target:
            left = mid + 1
        else:
            right = mid
    return left

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    
    n = int(input[idx])
    idx += 1
    
    g = [-1000000000] * (n + 2)
    for i in range(1, n+1):
        g[i] = int(input[idx])
        idx += 1
    g[n+1] = 1000000000
    
    m = int(input[idx])
    idx += 1
    
    for _ in range(m):
        t = int(input[idx])
        idx += 1
        
        l = lower_bound(g, 1, n+1, t)
        r = upper_bound(g, 1, n+1, t)
        if l <= n:
            l -= 1
        
        if l == n + 1:
            print(g[n])
        elif r == 1:
            print(g[1])
        else:
            if t - g[l] > g[r] - t:
                print(g[r])
            else:
                print(g[l])

if __name__ == "__main__":
    main()
```

## 二分函数使用说明

### C++ 中的 lower_bound 函数
- **函数原型**：`template <class ForwardIterator, class T> ForwardIterator lower_bound (ForwardIterator first, ForwardIterator last, const T& val);`
- **功能**：在有序序列中查找第一个不小于val的元素的位置
- **参数**：
  - `first`：搜索范围的起始迭代器
  - `last`：搜索范围的结束迭代器（不包含）
  - `val`：要查找的值
- **返回值**：指向第一个不小于val的元素的迭代器，如果所有元素都小于val，则返回last

### C++ 中的 upper_bound 函数
- **函数原型**：`template <class ForwardIterator, class T> ForwardIterator upper_bound (ForwardIterator first, ForwardIterator last, const T& val);`
- **功能**：在有序序列中查找第一个大于val的元素的位置
- **参数**：
  - `first`：搜索范围的起始迭代器
  - `last`：搜索范围的结束迭代器（不包含）
  - `val`：要查找的值
- **返回值**：指向第一个大于val的元素的迭代器，如果所有元素都小于等于val，则返回last

### Python 中的 lower_bound 函数
- **函数定义**：`def lower_bound(arr, left, right, target):`
- **功能**：在有序数组的指定范围内查找第一个不小于target的元素的索引
- **参数**：
  - `arr`：有序数组
  - `left`：搜索范围的左边界（包含）
  - `right`：搜索范围的右边界（不包含）
  - `target`：要查找的目标值
- **返回值**：第一个不小于target的元素的索引，如果所有元素都小于target，则返回right

### Python 中的 upper_bound 函数
- **函数定义**：`def upper_bound(arr, left, right, target):`
- **功能**：在有序数组的指定范围内查找第一个大于target的元素的索引
- **参数**：
  - `arr`：有序数组
  - `left`：搜索范围的左边界（包含）
  - `right`：搜索范围的右边界（不包含）
  - `target`：要查找的目标值
- **返回值**：第一个大于target的元素的索引，如果所有元素都小于等于target，则返回right

## 代码优化点
1. **哨兵设置**：
   - 在序列首尾设置哨兵值，简化边界情况处理
   - 避免了额外的边界条件判断

2. **二分查找优化**：
   - 使用标准库的二分查找函数（C++）或实现高效的二分查找（Python）
   - 时间复杂度为O(log n)，适合处理大规模数据

3. **边界情况处理**：
   - 处理所有元素都小于给定值的情况（l == n+1）
   - 处理所有元素都大于给定值的情况（r == 1）
   - 确保不会返回与给定值相等的元素

4. **距离比较**：
   - 正确比较左右候选元素与给定值的距离
   - 距离相等时选择较小的元素，符合题目要求

5. **数组大小设置**：
   - C++：设置足够大的数组大小（MAXN = 100015），避免越界访问
   - Python：使用动态列表，根据输入大小调整，无需固定大小

## 算法分析
- **时间复杂度**：O(m log n)，其中n是序列长度，m是查询次数

  - 处理m个查询的总时间复杂度为O(m log n)
