# 调整数组顺序使奇数位于偶数前面

## 题目描述

输入一个整数数组，实现一个函数来调整该数组中数字的顺序。使得所有的奇数位于数组的前半部分，所有的偶数位于数组的后半部分。

## 输入格式

输入一个整数数组。数据范围：数组长度[0, 100]。数组内元素取值范围[0, 100]。

## 输出格式

输出调整后的数组。

## 样例

**样例 1：**

输入：
[1,2,3,4,5]
输出：
[1,3,5,2,4]
