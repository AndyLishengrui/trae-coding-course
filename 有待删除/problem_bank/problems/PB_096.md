# NQ015 辩论赛评分

## 解题思路
1. **读取输入**：读取评委人数n，然后读取n个评分。
2. **计算统计值**：遍历评分，记录最高分、最低分和总分。
3. **计算平均分**：使用公式 (总分 - 最高分 - 最低分) / (n - 2) 计算去掉最高分和最低分后的平均分。
4. **输出结果**：将平均分保留两位小数后输出。
