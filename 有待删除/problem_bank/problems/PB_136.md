# 灯的开关

## 题目描述

# NQ057 灯的开关解题思路

## 解题思路
1. **问题描述**：初始时有n个灯泡关闭。第1轮打开所有灯泡，第2轮每两个灯泡关闭一次，第3轮每三个灯泡切换一次开关，依此类推，第i轮每i个灯泡切换一次开关。第n轮只切换最后一个灯泡的开关。统计n轮后亮着的灯泡数量。
2. **输入处理**：读取若干行测试数据，每行是一个正整数n。
3. **核心逻辑**：
   - 灯泡亮着的数量等于n以内的完全平方数个数
   - 即n的平方根的整数部分
4. **关键处理**：
   - 理解灯泡开关次数与因数个数的关系
   - 完全平方数的因数个数为奇数，非完全平方数的因数个数为偶数

## 输入输出示例

#### 输入示例
```
3
5
7
10
```

#### 输出示例
```
1
2
2
3
```

**解释**：
- 3以内的完全平方数：1，共1个
- 5以内的完全平方数：1, 4，共2个
- 7以内的完全平方数：1, 4，共2个
- 10以内的完全平方数：1, 4, 9，共3个

## 复杂度分析

### 时间复杂度
- 计算平方根的时间复杂度为O(1)
- 总体时间复杂度为O(T)，其中T是测试用例的数量

### 空间复杂度
- 仅使用常数级额外空间，空间复杂度为O(1)

## 代码实现思路

### C++ 实现
1. 读取输入的正整数n
2. 计算n的平方根并取整数部分
3. 输出结果

### Python 实现
1. 逐行读取输入的正整数n
2. 使用math.isqrt计算n的平方根（Python 3.8+）
3. 输出结果

## 总结
- 该问题的关键在于理解灯泡开关次数与因数个数的关系
- 灯泡被切换的次数等于其编号的因数个数
- 完全平方数的因数个数为奇数（因为有一个因数是平方根，只算一次），非完全平方数的因数个数为偶数
- 初始状态为关闭，切换奇数次后为打开，切换偶数次后为关闭
- 因此，亮着的灯泡编号都是完全平方数
- 计算n以内的完全平方数个数，即n的平方根的整数部分，是解决该问题的最优方法
- 这种方法的时间复杂度为O(1)，空间复杂度为O(1)，非常高效
