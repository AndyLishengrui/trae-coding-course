# NQ093 拓扑排序问题思路

## 问题描述
给定一个n个点m条边的有向图，点的编号是1到n，图中可能存在重边和自环。请输出任意一个该有向图的拓扑序列，如果拓扑序列不存在，则输出-1。

## 算法选择
我们选择使用**Kahn算法**（基于BFS的拓扑排序算法），因为它：
1. 时间复杂度低：O(n+m)，适用于n和m较大的情况
2. 实现简单直观
3. 可以同时检测环的存在

## 算法原理
1. **构建邻接表**：存储图的结构
2. **计算入度**：统计每个节点的入度
3. **初始化队列**：将所有入度为0的节点加入队列
4. **BFS遍历**：
   - 取出队首节点，加入拓扑序列
   - 遍历该节点的所有邻接节点，将它们的入度减1
   - 如果邻接节点的入度变为0，将其加入队列
5. **检查结果**：如果拓扑序列的长度等于n，说明存在拓扑排序；否则存在环，输出-1

## 实现步骤

### 步骤1：读取输入
- 读取n和m
- 构建邻接表和入度数组

### 步骤2：初始化队列
- 遍历所有节点，将入度为0的节点加入队列

### 步骤3：BFS执行拓扑排序
- 循环处理队列中的节点
- 每次取出一个节点，加入拓扑序列
- 更新邻接节点的入度
- 将新的入度为0的节点加入队列

### 步骤4：检查并输出结果
- 如果拓扑序列长度等于n，输出序列
- 否则输出-1

## 代码优化

### C++代码优化
- 使用动态向量（vector）替代固定大小的数组，避免内存浪费
- 邻接表使用vector<vector<int>>，只存储实际存在的边
- 入度数组使用vector<int>，大小根据实际n动态分配

### Python代码优化
- 使用sys.stdin.read().split()一次性读取所有输入，避免逐行读取的性能问题
- 使用deque作为队列，提高出队操作的效率
- 邻接表使用列表推导式初始化，代码简洁

## 时间复杂度分析
- 构建邻接表和入度数组：O(m)
- BFS遍历：每个节点和边各处理一次，O(n+m)
- 总时间复杂度：O(n+m)

## 空间复杂度分析
- 邻接表：O(m)
- 入度数组：O(n)
- 队列：最坏情况下O(n)
- 总空间复杂度：O(n+m)

## 测试用例

### 输入样例
```
3 3
1 2
2 3
1 3
```

### 输出样例
```
1 2 3
```

## 注意事项
1. 处理大规模输入时，Python的逐行读取可能会导致超时，因此使用一次性读取所有输入的方式
2. 重边不影响拓扑排序的结果，因为多次增加入度后会被多次减少，最终结果正确
3. 自环会导致该节点的入度永远大于0，从而无法进入队列，最终拓扑序列长度小于n，正确检测到环的存在
