# NQ009 计算偶数平方和和奇数立方和

## 解题思路
1. **读取输入**：读取区间的左右端点a和b。
2. **初始化变量**：初始化偶数平方和s1和奇数立方和s2为0。
3. **遍历区间**：遍历[a, b]中的每个整数，判断奇偶性。
4. **计算累加**：偶数计算平方累加到s1，奇数计算立方累加到s2。
5. **输出结果**：打印s1和s2的值。
