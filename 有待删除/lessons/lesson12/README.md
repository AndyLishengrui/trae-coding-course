# 第12课：基础数据结构

> **课时：** 2小时 | **题目：** 3例题 + 3练习 | **难度：** ⭐⭐⭐

## 一、本课目标
1. 手写理解链表、栈、队列的内部结构
2. 掌握单调栈/单调队列的核心模式
3. **库优先：** Python 用 `list` 和 `collections.deque` 替代手写结构

## 二、C++ vs Python 数据结构

| 数据结构 | C++ 实现 | Python 实现 |
|------|---------|------------|
| 单链表 | 手写 `e[],ne[],idx` | `list`（通常不需要真正链表） |
| 栈 | `stack<int>` / 数组模拟 | `list` 的 `append/pop` |
| 队列 | `queue<int>` | `collections.deque` |
| 单调栈 | 数组+条件维护 | `list`+条件维护 |

**NQ070 重点：** 表达式求值是栈的经典应用——操作数栈 + 运算符栈。Python 中看起来代码很长，但核心就是"遇到数字入栈，遇到运算符弹出计算再入栈"。

**NQ071 模式：** 单调栈的核心代码只有4行：
```python
for i, x in enumerate(arr):
    while stack and arr[stack[-1]] >= x:
        stack.pop()
    stack.append(i)
```
