## 一、本课目标
1. 掌握复杂条件判断的"先想清逻辑再写代码"
2. 学会处理时间跨越判断、象限判断等需要分情况讨论的问题
3. **Python 特色：** `dict` 映射表替代长 if-else 链

| 工具 | 作用 | 示例 |

| `dict` 映射 | 替代 switch/case | `{61:'Brasilia', 71:'Salvador'}` |

| `if/elif` 顺序 | 从一般到特殊 | 先判一般三角形，再判特殊 |
| 元组解包 | 交换变量 | `a, b = b, a`（无需临时变量） |

## 四、练习

| 题号 | 题目 | 教学重点 |
|------|------|---------|
| NQ016 | DDD | `dict`映射替代if堆叠 **【本课核心技巧】** |
| NQ017 | 点的坐标 | 象限判断，注意边界情况（轴和原点） |
| NQ018 | 三角形类型 | 排序降序后从一般到特殊：先判不能构成，再判直角/钝角/锐角，最后判等腰/等边 |

**NQ016 两种写法对比：**
```python
# C++风格 if-else 链（8个分支）
if x == 61: print("Brasilia")
elif x == 71: print("Salvador")
# ... 重复6次

# Python 风格 dict 映射
ddd = {61:'Brasilia', 71:'Salvador', 11:'Sao Paulo',
       21:'Rio de Janeiro', 32:'Juiz de Fora', 19:'Campinas',
       27:'Vitoria', 31:'Belo Horizonte'}
print(ddd.get(x, 'DDD nao cadastrado'))
```
