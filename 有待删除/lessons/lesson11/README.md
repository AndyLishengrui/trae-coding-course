# 第11课：高精度、位运算、离散化与区间合并

> **课时：** 2小时 | **题目：** 3例题 + 3练习 | **难度：** ⭐⭐⭐

## 一、本课目标
1. C++ 手写高精度加减乘除，理解大整数存储原理
2. **Python 震撼教育：** `int` 原生无限精度，高精度问题不用手写！
3. 掌握位运算核心操作：`n>>k&1`, `lowbit(n)=n&-n`, `int.bit_count()`
4. 离散化和区间合并两种经典预处理

## 二、Python vs C++ 高精度对决

```cpp
// C++: 手写 ~30行
vector<int> add(vector<int> &A, vector<int> &B) {
    vector<int> C; int t = 0;
    for (int i = 0; i < A.size(); i++) {
        t += A[i]; if (i < B.size()) t += B[i];
        C.push_back(t % 10); t /= 10;
    }
    if (t) C.push_back(t); return C;
}
```

```python
# Python: 原生支持无限大整数
a = int(input())  # 可以是任意位数！
b = int(input())
print(a + b)      # 自动处理
```

**教学要点：** C++ 中学生要理解用 `vector<int>` 反向存储大整数的每一位。Python 中这是语言内置的功能——理解"为什么 Python 可以做任意大的整数"（底层也是类似 vector 的实现）。

## 四、AI 协作要点

让学生先用 C++ 理解高精度原理（5分钟），然后切换到 Python 发现"一行就行"，建立"不同语言解决同类问题有不同的复杂度"的认知。这是双语言学最重要的收获。
