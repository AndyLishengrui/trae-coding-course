# 第8课：函数、递归与标准库初探

> **课时：** 2小时 | **题目：** 3例题 + 3练习 | **难度：** ⭐⭐⭐

## 一、本课目标
1. 掌握函数的定义和调用（C++ 和 Python）
2. 理解递归思想：基线条件 + 递归条件
3. **库优先第一课：** 学会"先查库，再手写"

## 二、"库优先"核心案例

这是全书最关键的理念课。以下对比贯穿整个教学：

| 需求 | C++ 手写 | Python 库调用 | 行数比 |
|------|---------|-------------|--------|
| 最大公约数 | 9行欧几里得 | `math.gcd(a,b)` | 9:1 |
| 阶乘 | 6行循环 | `math.factorial(n)` | 6:1 |
| 排列生成 | 15行DFS | `itertools.permutations(arr)` | 15:1 |
| 记忆化递归 | 手写memo数组 | `@functools.lru_cache` | 5:1 |

## 三、例题

| 题号 | 题目 | 核心知识点 | 库方案 |
|------|------|-----------|--------|
| NQ043 | n的阶乘 | 函数定义 + 递归 | `math.factorial(n)` |
| NQ044 | x和y的最大值 | 函数参数 | `max()` |
| NQ045 | 最大公约数 | 欧几里得递归 | **`math.gcd()`** 一行秒杀 |

**NQ045 教学重点：** 先让学生手写欧几里得理解原理（5分钟），然后展示 `math.gcd()` 一行搞定，建立"手写理解 + 库调用实战"的双轨思维。

## 五、AI 协作要点

**"Python 有现成的吗？"** —— 这应该是学生编程时的口头禅。任何一个常见需求（最大公约数、排列组合、阶乘、统计），先问 Trae："Python标准库里有没有现成的函数可以做X？" 95%的情况答案是"有"。
