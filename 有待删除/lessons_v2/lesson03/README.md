# 第3课：循环结构——for/while与嵌套循环

> **课时：** 2小时 | **题目：** 14题（9例题+5练习） | **阶段：** 语法基础

## 一、教学目标

1. 掌握 `for` 和 `while` 两种循环的适用场景
2. 理解 Python `range()` 的三种形态
3. 学会累加求和、条件计数、最值查找等循环模式
4. 引入 `collections.Counter` 和 `sum()` + 生成器表达式

## 二、Python 工具箱

| 工具 | 作用 | C++ 等价 |
|------|------|---------|
| `range(n)` | 0 到 n-1 | `for(int i=0;i<n;i++)` |
| `range(s, e, step)` | 带起止和步长 | `for(int i=s;i<e;i+=step)` |
| `sum(iterable)` | 求和 | `accumulate` |
| `sum(1 for x in arr if cond)` | 条件计数 | 循环+计数器 |
| `collections.Counter` | 频率统计 | `map<char,int>` |
| `enumerate(arr)` | 同时取索引和值 | 手动维护索引 |

## 三、关键教学案例

### NQ037: 约数（枚举因子）

```python
n = int(input())
for i in range(1, n + 1):
    if n % i == 0:
        print(i)
```

**优化：** `for i in range(1, int(n**0.5)+1)` — 只需枚举到 √n。这是第一次接触算法优化思想。

### NQ042-NQ043: 完全数与质数

- **完全数：** 所有真因子之和 = 自身。n≤10⁸时仅需判断 6, 28, 496, 8128。
- **质数判定：** 配合 `math.sqrt` 优化到 O(√n)。

**教学点：** 同样是循环，但加上数学知识可以让效率从 O(n) 降到 O(√n)。这是算法思维的萌芽。
