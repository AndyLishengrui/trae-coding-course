# 第11课：高精度、位运算与离散化

> **课时：** 2小时 | **题目：** 7题（3例题+4练习） | **阶段：** 核心算法 | **NQ115-NQ121**

## 一、教学目标

1. C++ 手写高精度加减乘除，理解大整数存储原理（`vector<int>` 反向存）
2. **Python 震撼教育：** `int` 原生无限精度，四道高精度题 Python 一行秒杀
3. 位运算：`lowbit = n & -n`、`n >> k & 1`、`int.bit_count()`
4. 离散化：将稀疏数据映射到连续下标 + 前缀和

## 二、Python vs C++ 高精度对决

```cpp
// C++: 高精度加法 ~30行
vector<int> add(vector<int> &A, vector<int> &B) {
    vector<int> C; int t = 0;
    for (int i = 0; i < A.size(); i++) {
        t += A[i];
        if (i < B.size()) t += B[i];
        C.push_back(t % 10);
        t /= 10;
    }
    if (t) C.push_back(t);
    return C;
}
```

```python
# Python: 原生支持，一行！
print(int(input()) + int(input()))
```

**教学点：** Python 的 `int` 底层也是用类似 `vector` 的结构存储每一位，只是语言帮你封装好了。理解C++的实现，然后在Python中享受便利。

## 三、位运算速查

| 操作 | 代码 | 说明 |
|------|------|------|
| 第k位 | `n >> k & 1` | 取二进制第k位 |
| 最低位1 | `n & -n` | lowbit，树状数组核心 |
| 1的个数 | `__builtin_popcount(n)` (C++) / `n.bit_count()` (Python 3.8+) | 统计二进制1 |
| 判断奇偶 | `n & 1` | 比 `n % 2` 更快 |
