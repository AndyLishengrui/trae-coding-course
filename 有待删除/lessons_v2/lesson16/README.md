## 二、核心模板

### 并查集

```python
# 朴素
p = list(range(n + 1))
def find(x):
    if p[x] != x: p[x] = find(p[x])  # 路径压缩
    return p[x]

# 带权并查集（食物链）
d = [0] * (n + 1)
def find(x):
    if p[x] != x:
        root = find(p[x])
        d[x] += d[p[x]]  # 维护到根的距离（模3等价类）
        p[x] = root
    return p[x]
```

### 快速幂

```python
def qmi(a, k, p):
    res = 1
    while k:
        if k & 1: res = res * a % p
        a = a * a % p
        k >>= 1
    return res
```

### 线性筛

```python
primes = []; st = [False] * (n+1)
for i in range(2, n+1):
    if not st[i]: primes.append(i)
    for p in primes:
        if p * i > n: break
        st[p * i] = True
        if i % p == 0: break  # 每个合数只被最小质因子筛掉
```
