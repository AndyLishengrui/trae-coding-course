## 二、代码速查

### 单调栈模式（找最近的更小元素）

```python
stack = []
for i, x in enumerate(arr):
    while stack and arr[stack[-1]] >= x:
        stack.pop()
    # stack[-1] 是 i 左边第一个比 arr[i] 小的位置
    stack.append(i)
```
