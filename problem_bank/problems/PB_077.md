# 字符串插入

## 题目描述

有两个不包含空白字符的字符串 str 和 substr，str 的字符个数不超过 10，substr 的字符个数为 3。将 substr 插入到 str 中 ASCII 码最大的那个字符后面，若有多个最大则只考虑第一个。

## 输入格式

输入包括若干行，每一行为一组测试数据，格式为 str substr。

## 输出格式

对于每一组测试数据，输出插入之后的字符串。

## 样例

**样例 1：**

输入：
abcab eee
12343 555
输出：
abceeeab
12345553

注意输出格式。来源：语法题
