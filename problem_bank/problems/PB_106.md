# NQ026 数学公式计算

## 解题思路
1. **读取输入**：读取测试用例数量t，然后读取t组浮点数s和u。
2. **计算v值**：使用公式v = 1.0 / tan(atan(1.0/s) - atan(1.0/u))计算v。
3. **计算结果**：使用公式res = v*u - s*u - v*s计算最终结果。
4. **输出结果**：将res的整数部分输出。
