# NQ018 计算折线长度

## 解题思路
1. **读取输入**：读取测试用例数量n，然后读取n组点坐标(x1,y1)和(x2,y2)。
2. **预处理**：确保起点所在的折线层不大于终点所在的折线层，否则交换起点和终点。
3. **计算长度**：根据折线移动规则，分两种情况计算路径长度：
   - 当位于折线层末端时，执行对角线跳跃到下一层起点
   - 当位于对角线上时，沿对角线移动到目标点或当前层末端
4. **输出结果**：将计算得到的折线长度保留三位小数后输出。
