# 三元组排序

## 题目描述

给定 N 个三元组 (x, y, z)，其中 x 是整数，y 是浮点数，z 是字符串。请按照 x 从小到大的顺序将这些三元组打印出来。数据保证不同三元组的 x 值互不相同。

## 输入格式

第一行包含整数 N。接下来 N 行，每行包含一个整数 x，一个浮点数 y，一个字符串 z，表示一个三元组，三者之间用空格隔开。数据范围：1 ≤ N ≤ 10000。1 ≤ x, y ≤ 10^9。字符串总长度不超过 10^5。

## 输出格式

共 N 行，按照 x 从小到大的顺序，每行输出一个三元组。注意，所有输入和输出的浮点数 y 均保留两位小数。

## 样例

**样例 1：**

输入：
5
3 1.36 gtrwcet
32 4.53 npyiupnhc
33 4.86 wrzyvbn
1 3.93 kfowqkn
31 4.53 gtlvivsc
输出：
1 3.93 kfowqkn
3 1.36 gtrwcet
31 4.53 gtlvivsc
32 4.53 npyiupnhc
33 4.86 wrzyvbn
