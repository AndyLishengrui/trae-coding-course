# NQ065 思路分析

## 问题描述
输入多个测试用例，每个测试用例包含一个整数 n，计算并输出 n! 的结果。

## 算法思路
- **大整数处理**：使用数组或向量存储大整数的每一位数字。
- **逐位相乘**：从 2 到 n 逐步乘以每个数字。
- **进位处理**：每一步都处理进位，确保结果正确。

## 实现步骤
1. 处理特殊情况：当 n=1 时，直接输出 1。
2. 初始化结果数组，初始值为 [1]。
3. 从 2 到 n 循环：
   - 将数组中的每个数字乘以当前的 i。
   - 处理进位，从低位到高位依次处理。
   - 处理最高位的进位，可能需要在数组前面插入新的数字。
4. 输出结果数组中的数字。
5. 清空结果数组，准备处理下一个测试用例。

## 程序设计要点
- **大整数存储**：使用向量或列表存储大整数的每一位，避免整数溢出。
- **进位处理**：每一步都要处理进位，确保结果正确。
- **多组输入**：使用循环处理多个测试用例。
- **效率优化**：直接操作数字数组，避免字符串转换的开销。

## 时间复杂度
- 时间复杂度：O(n * m)，其中 n 是输入的整数，m 是 n! 的位数。
- 空间复杂度：O(m)，需要存储 n! 的所有位数。
