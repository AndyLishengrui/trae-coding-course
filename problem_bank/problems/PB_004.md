# 最大公约数

## 题目描述

输入两个整数 a 和 b，请编写一个函数 int gcd(int a, int b)，计算并输出 a 和 b 的最大公约数。

## 输入格式

共一行，包含两个整数 a 和 b。数据范围：1 ≤ a, b ≤ 1000

## 输出格式

共一行，包含一个整数，表示 a 和 b 的最大公约数。

## 样例

**样例 1：**

输入：
12 16
输出：
4
