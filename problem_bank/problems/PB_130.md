# NQ050 排序考试解题思路

## 解题思路
1. **问题描述**：对输入的多个数组进行排序，并按要求输出排序结果。
2. **输入处理**：读取测试用例数量T，然后读取T组数据，每组数据包括数组长度n和n个整数。
3. **核心逻辑**：
   - 读取每组数据的数组长度n
   - 读取n个整数到数组中
   - 对数组进行排序
   - 输出排序结果，相邻元素之间用空格分隔
4. **关键处理**：
   - 输出时注意最后一个元素后不应有空格
   - 确保正确读取每组测试用例的数据

## 输入输出示例

#### 输入示例
```
2
5
3 1 4 1 5
3
9 8 7
```

#### 输出示例
```
1 1 3 4 5
7 8 9
```

## 复杂度分析

### 时间复杂度
- 对于每组测试用例，排序的时间复杂度为O(n log n)，其中n是数组长度
- 总体时间复杂度为O(T * n log n)，其中T是测试用例数量

### 空间复杂度
- 存储每组测试用例的数组，空间复杂度为O(n)

## 代码实现思路

### C++ 实现
1. 使用`cin`读取测试用例数量T
2. 循环处理每个测试用例
3. 读取数组长度n，然后读取n个整数到vector中
4. 使用`sort`函数对vector进行排序
5. 输出排序结果，注意控制空格输出

### Python 实现
1. 使用`sys.stdin.readline`读取测试用例数量T
2. 循环处理每个测试用例
3. 读取数组长度n，然后读取n个整数到列表中
4. 使用列表的`sort`方法对列表进行排序
5. 使用`' '.join(map(str, nums))`将排序后的列表转换为字符串并输出

## 总结
- 该问题是一个基础的排序问题，主要考察对输入数据的处理和排序算法的应用
- C++和Python都提供了内置的排序函数，使用方便且效率较高
- 注意输出格式的处理，确保相邻元素之间用空格分隔，最后一个元素后无空格
- Python的实现更加简洁，利用了字符串方法和列表方法的优势
