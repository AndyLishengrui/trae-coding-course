# 求方程的根

## 题目描述

# NQ068 求方程的根解题思路

## 解题思路
1. **问题描述**：求解方程 f(x) = x³ - 5x² + 10x - 80 = 0 的根，要求精确到小数点后9位。
2. **输入处理**：无需输入，直接在固定区间 [0, 10] 内求解。
3. **函数性质分析**：
   - f(0) = -80 < 0，f(10) = 520 > 0
   - 导数 f’(x) = 3x² - 10x + 10，判别式 Δ = 100 - 120 = -20 < 0，导数恒正，函数单调递增
   - 因此区间 [0, 10] 内有且仅有一个实根
4. **核心逻辑**：
   - 使用二分法求解方程的根
   - 二分法的基本思想是：在一个已知根存在的区间内，不断将区间一分为二，根据函数值的符号确定根所在的子区间，直到区间长度小于给定的精度
   - 由于函数单调递增，f(mid) > 0 说明根在mid左侧，f(mid) ≤ 0 说明根在mid右侧
5. **关键处理**：
   - 选择合适的精度阈值（1e-9）
   - 正确判断根所在的子区间
   - 返回区间中点作为最终近似根，确保精度

## 复杂度分析

### 时间复杂度
- 二分法的时间复杂度为O(log₂((right - left)/eps))，其中right和left是初始区间的端点，eps是精度阈值
- 对于本题，初始区间长度为10，精度阈值为1e-9，需要约log₂(10/1e-9) ≈ 34次迭代
- 总体时间复杂度为O(1)，因为迭代次数是常数级别的

### 空间复杂度
- 仅使用常数级额外空间，空间复杂度为O(1)

## 代码实现思路

### C++ 实现
1. 定义函数 f(x) 计算方程的值
2. 定义二分法函数 binarySearch，接收左右区间端点，返回根的近似值
3. 在二分法中，当区间长度小于精度阈值时，返回区间中点作为最终近似根
4. 在 main 函数中调用 binarySearch 函数，在区间 [0, 10] 内求解
5. 输出结果，保留9位小数

4. 在 main 函数中调用 binary_search 函数，在区间 [0, 10] 内求解
5. 输出结果，保留9位小数

## 总结
- 该问题主要考察二分法求解方程根的应用
- 二分法是一种高效的数值方法，适用于在已知根存在的区间内求解单根
- 对于本题，由于函数 f(x) 在区间 [0, 10] 内单调递增，因此保证有且仅有一个根
- 代码实现简洁明了，逻辑清晰
- 时间复杂度为O(log₂((right - left)/eps))，空间复杂度为O(1)
- 二分法的精度可以通过调整eps参数来控制
- 注意返回区间中点作为最终近似根，以确保精度要求
