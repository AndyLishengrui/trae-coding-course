# NQ086 思路分析

## 问题描述
给定 n 个物品，每个物品有体积 volume[i] 和价值 value[i]，以及一个容量为 m 的背包。要求选择若干物品放入背包，使得总价值最大，且总容量不超过背包容量。

## 算法思路
1. **动态规划**：使用一维数组 `dp[j]` 表示背包容量为 j 时的最大价值。
2. **状态转移**：对于每个物品 i，逆序更新 dp 数组，避免重复选择物品。状态转移方程为：`dp[j] = max(dp[j], dp[j - volume[i]] + value[i])`。
3. **边界条件**：初始时，dp[0] = 0，表示容量为 0 时的价值为 0。
4. **结果计算**：最终 dp[m] 就是背包容量为 m 时的最大价值。

## 实现步骤
1. 读取物品数量 n 和背包容量 m。
2. 读取每个物品的体积和价值。
3. 初始化一维动态规划数组 dp，长度为 m+1，初始值为 0。
4. 遍历每个物品，逆序更新 dp 数组。
5. 输出 dp[m]，即最大价值。

## 时间复杂度
- 时间复杂度：O(n*m)，其中 n 是物品数量，m 是背包容量。需要遍历每个物品和每个容量。
- 空间复杂度：O(m)，使用一维数组存储动态规划状态。
