# 递归求波兰表达式思路

## 题目描述

# NQ073 递归求波兰表达式思路

## 问题分析

### 问题描述
输入一个波兰表达式（前缀表达式），计算其值。

### 波兰表达式特点
- 运算符位于操作数之前
- 不需要括号来表示运算优先级
- 例如：`* + 1 2 + 3 4` 表示 `(1+2)*(3+4)`

## 算法设计

### 递归思路
1. **基本思想**：波兰表达式的结构天然适合递归处理
2. **递归过程**：
   - 读取一个 token
   - 如果是运算符，递归计算左右两个操作数，然后执行相应运算
   - 如果是操作数，直接转换为浮点数返回

### 输入处理
- **C++**：使用 `cin >>` 自动跳过空白字符，逐个读取token
- **Python**：读取所有输入并按空白字符分割成token列表，然后逐个处理

### 算法优势
- **简洁性**：代码结构清晰，逻辑简单
- **自然匹配**：递归方法与波兰表达式的结构完美匹配
- **易于理解**：符合人类的思维方式

## 代码实现

### C++实现
```cpp
// 递归计算波兰表达式
#include <iostream>
using namespace std;

double calc() {
    char token[32];
    cin >> token;
    
    switch (token[0]) {
        case '+': return calc() + calc();
        case '-': return calc() - calc();
        case '*': return calc() * calc();
        case '/': return calc() / calc();
        default: return atof(token);
    }
}

int main() {
    double res = calc();
    printf("%lf", res);
    return 0;
}
```

### Python实现
```python
# 递归计算波兰表达式（Python 3.5 兼容版）
import sys

def calc():
    # 读取所有输入并分割成token
    tokens = []
    for line in sys.stdin:
        tokens.extend(line.strip().split())
    
    index = 0
    
    def helper():
        nonlocal index
        if index >= len(tokens):
            return 0.0
        
        token = tokens[index]
        index += 1
        
        if token == '+':
            return helper() + helper()
        elif token == '-':
            return helper() - helper()
        elif token == '*':
            return helper() * helper()
        elif token == '/':
            return helper() / helper()
        else:
            return float(token)
    
    return helper()

def main():
    res = calc()
    print(res)

if __name__ == "__main__":
    main()
```

## 时间空间复杂度分析

### 时间复杂度
- **时间复杂度**：O(n)，其中n是表达式中token的数量
- 每个token只被处理一次
- 递归调用的深度最多为n（在最坏情况下，如全是操作数）

### 空间复杂度
- **空间复杂度**：O(n)
  - 用于存储递归调用栈
  - Python版本还需要存储token列表
- 在最坏情况下，递归栈的深度为n

## 总结

- 递归方法是计算波兰表达式的理想选择
- 代码实现简洁明了，易于理解
- 时间复杂度和空间复杂度均为O(n)
- 该方法也可以推广到计算逆波兰表达式（后缀表达式），只需调整处理顺序
- Python版本兼容Python 3.5及以上版本
