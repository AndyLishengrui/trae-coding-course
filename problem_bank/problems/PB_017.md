# 走方格

## 题目描述

给定 n x m 的方格阵，从左上角 (0, 0) 开始，每次只能往右或往下走一个单位距离，求走到右下角 (n, m) 的走法数量。

## 输入格式

一行两个整数 n 和 m。数据范围：1 ≤ n, m ≤ 10

## 输出格式

一个整数表示走法数量。

## 样例

**样例 1：**

输入：
2 3
输出：
10
