# 两数之和（双指针法）

## 题目描述

# NQ058 两数之和（双指针法）

## 问题描述
在一个已排序的数组中，寻找两个元素，使得它们的和等于给定的目标值，并输出这两个元素的索引。

## 算法选择
采用**双指针算法**，利用数组已排序的特性，通过左右指针的移动来高效查找目标和。

## 算法原理
1. **问题分析**：由于数组已排序，我们可以利用这一特性，使用双指针从两端向中间移动，逐步缩小搜索范围
2. **双指针策略**：
   - 左指针初始指向数组的第一个元素（索引0）
   - 右指针初始指向数组的最后一个元素（索引n-1）
   - 计算两个指针指向元素的和，与目标值比较
   - 根据比较结果移动指针：
     - 如果和等于目标值，找到答案
     - 如果和小于目标值，移动左指针向右（增大和）
     - 如果和大于目标值，移动右指针向左（减小和）

## 实现步骤
1. **读取输入**：读取目标值target、数组长度n，以及n个数组元素
2. **初始化指针**：左指针i=0，右指针j=n-1
3. **双指针搜索**：
   - 计算当前和sum = a[i] + a[j]
   - 如果sum == target，输出i和j，结束
   - 如果sum < target，i++（移动左指针向右）
   - 如果sum > target，j--（移动右指针向左）
   - 重复上述过程，直到找到答案或指针交叉

## 代码实现

### C++ 实现
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
  int target, n, x;
  vector<int> a;
  cin >> target >> n;
  for (int i = 0; i < n; i++) {
    cin >> x;
    a.push_back(x);
  }
  // 双指针算法
  for (int i = 0, j = n - 1; i <= j; i++) {
    while (j > i && a[i] + a[j] > target) j--;

    if (a[i] + a[j] == target) {
      cout << i << " " << j << endl;
      break;
    }
  }
  return 0;
}
```

### Python 实现
```python
# 读取目标和数组长度
target, n = map(int, input().split())

# 读取数组元素并存储到列表中
a = list(map(int, input().split()))

# 双指针算法
i, j = 0, n - 1
while i < j:
    sum_val = a[i] + a[j]
    if sum_val == target:
        print(i, j)
        break
    elif sum_val < target:
        i += 1  # 和小于target，移动左指针
    else:
        j -= 1  # 和大于target，移动右指针

# Python中不需要显式的return 0，程序正常结束即可
```

## 代码分析

### C++ 实现分析
1. **输入处理**：使用`vector`存储数组元素，动态调整大小
2. **双指针实现**：使用`for`循环控制左指针，`while`循环调整右指针
3. **优化策略**：对于每个左指针，右指针从当前位置向左移动，避免重复计算
4. **终止条件**：找到目标和后立即输出并`break`，结束程序

### Python 实现分析
1. **输入处理**：使用`input().split()`和`map()`函数快速读取输入
2. **双指针实现**：使用`while`循环同时控制左右指针的移动
3. **逻辑清晰**：通过条件判断明确处理三种情况（等于、小于、大于）
4. **代码简洁**：利用Python的语法特性，代码更加简洁易读

## 代码优化点
1. **输入处理优化**：
   - C++：使用`ios_base::sync_with_stdio(false); cin.tie(NULL);`提高输入速度
   - Python：使用`sys.stdin.read()`一次性读取所有输入，避免多次IO操作

2. **双指针移动优化**：
   - C++实现中，右指针从当前位置向左移动，避免了重复计算
   - Python实现中，通过明确的条件判断，使代码逻辑更加清晰

3. **边界情况处理**：
   - 确保指针不越界，当i >= j时结束搜索
   - 题目保证存在解，因此不需要处理无解的情况

## 算法分析
- **时间复杂度**：O(n)，其中n是数组的长度
  - 左右指针最多移动n次，每次移动常数时间
  - 相比暴力枚举的O(n²)时间复杂度，双指针算法效率更高

- **空间复杂度**：O(1)
  - 只使用了常数级的额外空间，不随输入规模变化
  - 不需要额外的数据结构，直接在原数组上操作

## 总结
双指针算法是解决已排序数组中两数之和问题的高效方法，利用数组的有序性，通过左右指针的移动来缩小搜索范围。该算法时间复杂度为O(n)，空间复杂度为O(1)，相比暴力枚举方法有显著的性能优势。

**算法特点**：
- 时间复杂度低，线性时间即可完成查找
- 空间复杂度低，不需要额外的数据结构
- 代码实现简洁，逻辑清晰
- 利用了数组已排序的特性，是对问题特性的充分利用

**适用场景**：
- 已排序数组中的两数之和问题
- 需要在有序数组中寻找满足特定条件的元素对
- 空间资源有限，需要原地算法的场景
