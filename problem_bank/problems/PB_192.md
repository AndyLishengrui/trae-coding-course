# 公主猫问题思路

## 题目描述

# NQ064 公主猫问题思路

## 问题分析

### 问题描述
公主猫的数量增长遵循以下规律：前4年每年的猫数量等于年份，从第5年开始，每年的猫数量是前一年和前三年猫数量的和。

### 问题分析
- 这是一个典型的递推问题，可以使用动态规划来解决
- 前4年的猫数量是已知的：第1年1只，第2年2只，第3年3只，第4年4只
- 从第5年开始，每年的猫数量 = 前一年的猫数量 + 前三年的猫数量
- 该递推关系构成了动态规划的状态转移方程

## 算法设计

### 动态规划思路
1. **状态定义**：`dp[i]`表示第i年的公主猫数量
2. **状态转移方程**：对于i >= 5，`dp[i] = dp[i-1] + dp[i-3]`
3. **基础情况**：对于i < 5，`dp[i] = i`
4. **计算顺序**：从第1年开始，逐年计算到目标年份

### 算法优势
- **时间复杂度**：O(n)，其中n是目标年份
- **空间复杂度**：O(n)，用于存储动态规划数组
- **实现简单**：逻辑清晰，易于理解和实现
- **高效计算**：避免了重复计算，直接使用递推关系计算

## 代码实现

### C++实现
```cpp
#include <iostream>
#include <vector>
using namespace std;

// 计算第year年的公主猫总数
int calculateCats(int year) {
    // 前4年的猫数量等于年份
    if (year < 5) return year;
    
    // 动态规划数组，存储每年的猫数量
    vector<int> dp(year + 1);
    dp[0] = 0; // 第0年不计入统计
    
    // 初始化前4年的猫数量
    for (int i = 1; i <= 4; ++i) {
        dp[i] = i;
    }
    
    // 从第5年开始，使用递推关系计算
    // 递推公式：当前年猫数量 = 前一年 + 前三年
    for (int i = 5; i <= year; ++i) {
        dp[i] = dp[i - 1] + dp[i - 3];
    }
    
    return dp[year];
}

int main() {
    int n, m;
    cin >> n; // 输入测试实例个数
    
    // 处理每个测试实例
    while (n--) {
        cin >> m; // 输入年份
        cout << calculateCats(m) << endl;
    }
    
    return 0;
}
```

### Python实现
```python
def calculate_cats(year):
    # 前4年的猫数量等于年份
    if year < 5:
        return year
    
    # 动态规划数组，存储每年的猫数量
    dp = [0] * (year + 1)
    
    # 初始化前4年的猫数量
    for i in range(1, 5):
        dp[i] = i
    
    # 从第5年开始，使用递推关系计算
    # 递推公式：当前年猫数量 = 前一年 + 前三年
    for i in range(5, year + 1):
        dp[i] = dp[i - 1] + dp[i - 3]
    
    return dp[year]

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    
    n = int(input[idx])  # 输入测试实例个数
    idx += 1
    
    # 处理每个测试实例
    for _ in range(n):
        m = int(input[idx])  # 输入年份
        idx += 1
        print(calculate_cats(m))

if __name__ == "__main__":
    main()
```

## 时间空间复杂度分析

### 时间复杂度
- **时间复杂度**：O(n)，其中n是目标年份
  - 对于每个测试实例，我们需要计算从第1年到目标年份的猫数量
  - 每个年份的计算都是O(1)的操作
  - 对于m个测试实例，总时间复杂度为O(Σn_i)，其中n_i是每个测试实例的年份

### 空间复杂度
- **空间复杂度**：O(n)，其中n是目标年份
  - 需要一个大小为n+1的数组来存储每年的猫数量
  - 对于多个测试实例，每次计算都会创建一个新的数组，空间使用是合理的

## 优化策略

1. **空间优化**：对于单个测试实例，可以只使用几个变量来存储前几年的猫数量，而不是使用整个数组，从而将空间复杂度降低到O(1)

2. **预计算**：如果需要处理多个测试实例，可以预先计算所有可能的年份的猫数量，然后在查询时直接返回，这样可以提高处理多个测试实例的效率

3. **输入输出优化**：在C++中可以使用`ios_base::sync_with_stdio(false); cin.tie(NULL);`来加速输入输出

- 时间复杂度为O(n)，空间复杂度为O(n)
- 代码实现简洁明了，易于理解和维护
- 该方法适用于处理多个测试实例的情况
- 递推关系是解决此类问题的关键，正确理解和应用递推关系是解决问题的核心
