# NQ016 十六进制加法

## 解题思路
1. **读取输入**：读取两个十六进制数。
2. **转换计算**：将十六进制数转换为十进制整数，计算两数之和。
3. **处理负数**：如果结果为负数，输出负号加上绝对值的十六进制表示。
4. **转换输出**：将结果转换为大写十六进制形式输出。
