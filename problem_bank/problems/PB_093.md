# NQ012 水仙花数

## 解题思路
1. **读取输入**：读取区间的左右端点m和n。
2. **遍历区间**：遍历[m, n]中的每个数，提取百位、十位和个位数字。
3. **判断水仙花数**：计算各位数字的立方和，判断是否等于原数。
4. **输出结果**：收集所有水仙花数，用空格分隔输出；若无则输出"no"。
