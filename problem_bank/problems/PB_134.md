## 题目描述

# NQ055 最小公倍数计算解题思路

## 解题思路
1. **问题描述**：输入多个测试用例，每个测试用例包含n个正整数，计算并输出这些数的最小公倍数（LCM）。当输入n≤0时结束处理。
2. **输入处理**：读取多个测试用例，每个测试用例包含一个整数n和n个正整数。
3. **核心逻辑**：
   - 利用最大公约数（GCD）来计算最小公倍数（LCM）
   - 公式：LCM(a, b) = (a * b) / GCD(a, b)
   - 累积计算：对输入的数依次计算当前结果与新数的LCM
4. **关键处理**：
   - 处理多组测试用例，直到输入n≤0
   - 初始化结果为1，因为任何数与1的LCM都是其本身

## 输入输出示例

#### 输入示例
```
3
4 6 8
2
3 5
0
```

#### 输出示例
```
24
15
```

**解释**：
- 第一组：LCM(4, 6) = 12，LCM(12, 8) = 24
- 第二组：LCM(3, 5) = 15
- 输入0时结束处理

## 复杂度分析

### 时间复杂度
- 对于每个测试用例，计算n-1次LCM，每次LCM计算需要一次GCD计算
- GCD计算的时间复杂度为O(log min(a, b))，其中a和b是输入的数
- 总体时间复杂度为O(T * n * log M)，其中T是测试用例数量，n是每个测试用例的数的个数，M是输入数的最大值

### 空间复杂度
- 仅使用常数级额外空间，空间复杂度为O(1)

## 代码实现思路

### C++ 实现
1. 实现递归版的GCD函数，使用欧几里得算法
2. 实现LCM函数，利用GCD计算结果
3. 读取测试用例数量n，直到n≤0
4. 对每个测试用例，累积计算LCM
5. 输出最终结果

### Python 实现
1. 实现迭代版的GCD函数，使用欧几里得算法
2. 实现LCM函数，利用GCD计算结果
3. 一次性读取所有输入，使用指针逐个处理
4. 读取测试用例数量n，直到n≤0
5. 对每个测试用例，累积计算LCM
6. 输出最终结果

## 总结
- 该问题主要考察最大公约数（GCD）和最小公倍数（LCM）的计算
- 利用欧几里得算法可以高效计算GCD，进而得到LCM
- 累积计算LCM的方法可以处理任意数量的输入数
- 代码实现简洁明了，逻辑清晰
- 注意处理边界情况，如输入n≤0时结束处理
