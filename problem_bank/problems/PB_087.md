# NQ006 成绩分区

## 解题思路
1. **读取输入**：循环读取多组成绩输入。
2. **验证范围**：检查成绩是否在0-100的有效范围内，超出范围输出"Wrong Score!"。
3. **成绩分区**：根据成绩大小进行等级划分：90及以上为A级，80-89为B级，70-79为C级，60-69为D级，60以下为E级。
4. **输出结果**：输出对应等级和所属区间。
