# NQ099 最省赛程

## 问题分析
本题是一个带约束的最短路径问题，要求在油箱容量限制下，找到从起点城市到终点城市的最小加油花费路线。每个城市有不同的油价，道路行驶需要消耗一定的油量。

## 解题思路
采用Dijkstra算法的变种，结合优先队列和状态管理，具体步骤如下：
1. **构建邻接表**：存储城市之间的道路信息，包括目标城市和所需油量
2. **初始化状态**：使用二维数组`expenses[city][fuel]`记录到达每个城市时不同油量的最小花费，初始化为无穷大
3. **优先队列**：使用最小堆维护状态，元素为（当前花费，城市，剩余油量）
4. **状态处理**：
   - 从队列中取出花费最小的状态
   - 如果到达终点，返回当前花费
   - 如果状态已处理过，跳过
   - 尝试在当前城市加一升油，更新状态并加入队列
   - 尝试前往相邻城市，更新状态并加入队列
5. **判断无解**：如果队列为空仍未到达终点，返回impossible

## 代码实现
- **C++版本**：使用`vector<vector<Edge>>`构建邻接表，`priority_queue`实现优先队列，`expenses`二维数组记录状态
- **Python版本**：使用列表嵌套构建邻接表，`heapq`模块实现优先队列，确保Python 3.5兼容性

## 时间复杂度
- 时间复杂度：O(n*C*log(n*C))
  - 其中n是城市数，C是油箱容量
  - 每个城市有C+1种可能的油量状态，共n*(C+1)个状态
  - 每个状态最多入队一次，优先队列操作的时间复杂度为O(log(n*C))
  - 因此总体时间复杂度为O(n*C*log(n*C))

## 空间复杂度
- 空间复杂度：O(n*C)
  - 邻接表：O(m)，其中m是道路数
  - 状态数组：O(n*C)，存储每个城市不同油量的最小花费
  - 优先队列：最坏情况下O(n*C)

## 优化考虑
- **状态去重**：使用`visited`数组标记已处理的状态，避免重复处理
- **优先队列**：使用最小堆确保每次处理花费最小的状态，提前找到最优解
- **输入处理**：使用`sys.stdin.read()`一次性读取输入，提高处理大数据的效率
- **邻接表**：使用高效的存储结构，减少内存使用

## 示例
输入：
```
4 4
5 4 6 7
0 1 1
0 2 2
1 2 1
2 3 1
2
10 0 3
5 0 3
```
输出：
```
17
impossible
```

## 注意事项
- 城市编号从0开始
- 道路是无向的，需要双向添加
- 油箱容量C是最大油量限制
- 油价是每个城市的单位油价
- 问题数量q小于100
- 当无法到达终点时，输出"impossible"
- 算法假设油价和道路信息都是有效的非负数
