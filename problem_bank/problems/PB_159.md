# NQ081 思路分析

## 问题描述
输入一个整数 n，输出其所有约数，按升序排列。

## 算法思路
- **枚举法**：从 1 到 √n 枚举所有可能的约数。
- **约数性质**：如果 i 是 n 的约数，则 n/i 也是 n 的约数。
- **去重处理**：对于完全平方数，避免重复添加平方根。
- **排序输出**：将所有约数排序后输出。

## 实现步骤
1. 定义 `get_divisors` 函数，接收整数 n。
2. 从 1 到 √n 枚举，判断是否为约数。
3. 如果是约数，添加 i 和 n/i（注意去重）。
4. 对约数列表排序。
5. 处理多组输入，输出每个数的约数。

## 程序设计要点
- **枚举范围**：只需要枚举到 √n，减少时间复杂度。
- **去重处理**：使用 `if (i != n / i)` 避免重复添加完全平方数的平方根。
- **排序处理**：使用 `sort` 函数对约数列表按升序排列。
- **多组输入**：使用循环处理多个输入值。

## 时间复杂度
- 时间复杂度：O(√n)，枚举到 √n，排序时间可忽略。
- 空间复杂度：O(d(n))，其中 d(n) 是 n 的约数个数。
