# NQ002 字符比大小

## 解题思路
1. **读取数据组数**：从输入中读取第一个整数n，表示后续有n组数据。
2. **处理每组数据**：循环n次，每次读取一个字符串。
3. **排序字符串**：对读取的字符串进行整体排序。
4. **输出结果**：从排序后的字符串中取前三个字符，以空格分隔输出。
