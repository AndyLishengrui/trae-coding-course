# 寻找和为目标值的数对

## 题目描述

# NQ069 寻找和为目标值的数对

## 问题描述
在给定的数组中寻找两个数，使其和等于目标值，并输出这两个数。如果没有找到，输出"No"。

## 算法选择
采用**排序+二分查找**的方法，先对数组排序，然后遍历每个元素，使用二分查找寻找其补数。

## 算法原理
1. **排序预处理**：对数组进行升序排序，为二分查找做准备
2. **遍历元素**：遍历每个元素作为数对中的较小数
3. **计算补数**：目标和减去当前元素，得到需要寻找的补数
4. **二分查找**：在当前元素之后的子数组中二分查找补数
5. **输出结果**：找到则输出，否则继续遍历

## 实现步骤
1. **读取输入**：读取数组长度n、数组元素和目标和target
2. **排序数组**：对数组进行升序排序
3. **遍历元素**：
   - 对于每个元素nums[i]，计算补数complement = target - nums[i]
   - 在nums[i+1..n-1]范围内二分查找complement
   - 找到则输出结果并退出
4. **输出结果**：遍历完成后仍未找到，输出"No"

## 代码实现

### C++ 实现
```cpp
#include <cstdio>
#include <algorithm>
using namespace std;

const int kMaxArraySize = 100005;
long long nums[kMaxArraySize];

int main() {
    int n;
    scanf("%d", &n);
    
    for (int i = 0; i < n; ++i) {
        scanf("%lld", &nums[i]);
    }
    
    long long target;
    scanf("%lld", &target);
    
    sort(nums, nums + n);
    
    for (int i = 0; i < n; ++i) {
        long long complement = target - nums[i];
        auto it = lower_bound(nums + i + 1, nums + n, complement);
        
        if (it != nums + n && *it == complement) {
            printf("%lld %lld\n", nums[i], complement);
            return 0;
        }
    }
    
    printf("No\n");
    return 0;
}
```

### Python 实现
```python
def lower_bound(arr, left, right, target):
    """查找第一个不小于target的元素的索引"""
    while left < right:
        mid = left + (right - left) // 2
        if arr[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    
    n = int(input[idx])
    idx += 1
    
    nums = list(map(int, input[idx:idx+n]))
    idx += n
    
    target = int(input[idx])
    idx += 1
    
    nums.sort()
    
    for i in range(n):
        complement = target - nums[i]
        left = i + 1
        right = n
        pos = lower_bound(nums, left, right, complement)
        
        if pos < n and nums[pos] == complement:
            print(nums[i], complement)
            return
    
    print('No')

if __name__ == "__main__":
    main()
```

## 二分函数使用说明

### C++ 中的 lower_bound 函数
- **函数原型**：`template <class ForwardIterator, class T> ForwardIterator lower_bound (ForwardIterator first, ForwardIterator last, const T& val);`
- **功能**：在有序序列中查找第一个不小于val的元素的位置
- **参数**：
  - `first`：搜索范围的起始迭代器
  - `last`：搜索范围的结束迭代器（不包含）
  - `val`：要查找的值
- **返回值**：指向第一个不小于val的元素的迭代器，如果所有元素都小于val，则返回last
- **使用场景**：在本题中，用于在排序后的子数组中查找补数的位置

### Python 中的 lower_bound 函数
- **函数定义**：`def lower_bound(arr, left, right, target):`
- **功能**：在有序数组的指定范围内查找第一个不小于target的元素的索引
- **参数**：
  - `arr`：有序数组
  - `left`：搜索范围的左边界（包含）
  - `right`：搜索范围的右边界（不包含）
  - `target`：要查找的目标值
- **返回值**：第一个不小于target的元素的索引，如果所有元素都小于target，则返回right
- **使用场景**：在本题中，用于在排序后的子数组中查找补数的索引，与C++的lower_bound函数实现类似的功能

## 代码优化点
1. **排序优化**：
   - 使用标准库的排序函数，时间复杂度为O(n log n)
   - 排序后可以利用二分查找提高查找效率

2. **二分查找优化**：
   - C++：使用标准库的`lower_bound`函数，实现高效的二分查找
   - Python：实现了与C++类似的`lower_bound`函数，保持了实现风格的一致性

3. **边界处理**：
   - 从当前元素的下一个位置开始查找，避免重复使用同一个元素
   - 找到结果后立即返回，提高效率

4. **数据类型处理**：
   - C++：使用`long long`类型，避免整型溢出
   - Python：利用动态类型特性，无需显式类型声明

## 算法分析
- **时间复杂度**：O(n log n)
  - 排序的时间复杂度为O(n log n)
  - 遍历每个元素并进行二分查找的时间复杂度为O(n log n)

- **空间复杂度**：O(n)
  - 用于存储输入的数组元素
