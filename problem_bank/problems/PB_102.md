# NQ022 竞选投票

## 解题思路
1. **读取输入**：读取班级数量n，然后读取每个班级的总人数。
2. **计算每个班级所需票数**：对于每个班级，计算获得支持需要的最少票数（超过半数，即总人数//2 + 1）。
3. **排序**：将每个班级所需的最少票数从小到大排序。
4. **计算总票数**：选择前n//2 + 1个最小的所需票数之和，即为确保当选所需的最少总票数。
5. **输出结果**：打印计算得到的最少总票数。
