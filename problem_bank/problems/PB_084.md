# NQ003 计算线段长度

## 解题思路
1. **读取测试用例数量**：从输入中读取整数n，表示有n组测试数据。
2. **处理每组数据**：循环n次，每次读取两个点的坐标(x1,y1)和(x2,y2)。
3. **计算距离**：使用勾股定理计算两点间的欧几里得距离：distance = sqrt((x1-x2)² + (y1-y2)²)。
4. **输出结果**：将计算得到的距离保留两位小数后输出。
