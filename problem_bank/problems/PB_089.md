# NQ008 奇数的乘积

## 解题思路
1. **读取输入**：读取包含序列长度和元素的输入行。
2. **解析数据**：提取序列长度和对应的整数元素。
3. **计算奇数乘积**：初始化乘积为1，遍历序列，累乘所有奇数。
4. **输出结果**：无论是否存在奇数，都输出乘积（无奇数时默认为1）。
