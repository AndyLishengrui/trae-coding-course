# 同构字符串

## 题目描述

# NQ084 同构字符串

## 问题描述
判断两个字符串是否同构。同构字符串是指可以通过替换字符的方式，将一个字符串转换为另一个字符串。

## 算法选择
采用**哈希映射**方法，使用两个哈希表分别存储从一个字符串到另一个字符串的字符映射关系，确保映射的双向一致性。

## 算法原理
1. **问题分析**：同构字符串要求字符之间存在一一对应的映射关系，因此需要检查这种双向映射的一致性
2. **哈希映射**：使用两个哈希表分别存储 s→t 和 t→s 的映射关系
3. **映射检查**：对于每个字符对，检查映射是否一致，如果不一致则返回 false
4. **边界情况**：如果两个字符串长度不同，直接返回 false

## 实现步骤
1. **检查长度**：如果两个字符串长度不同，直接返回 false
2. **初始化哈希表**：创建两个哈希表，分别存储 s→t 和 t→s 的映射
3. **遍历字符**：同时遍历两个字符串的每个字符
4. **检查映射**：
   - 如果 s 中的字符已在映射中，检查是否与当前 t 中的字符一致
   - 如果 t 中的字符已在反向映射中，检查是否与当前 s 中的字符一致
   - 如果都不在映射中，建立新的映射关系
5. **返回结果**：遍历完成后，返回 true

## 代码实现

### C++ 实现
```cpp
// NQ084 同构字符串
#include <iostream>
#include <string>
#include <unordered_map>
using namespace std;

bool isIsomorphic(const string& s, const string& t) {
    if (s.size() != t.size()) return false;
    
    unordered_map<char, char> s_to_t, t_to_s;
    
    for (int i = 0; i < s.size(); i++) {
        char c1 = s[i], c2 = t[i];
        
        if (s_to_t.count(c1)) {
            if (s_to_t[c1] != c2) return false;
        } else {
            if (t_to_s.count(c2)) return false;
            s_to_t[c1] = c2;
            t_to_s[c2] = c1;
        }
    }
    
    return true;
}

int main() {
    int n;
    cin >> n;
    
    while (n--) {
        string s, t;
        cin >> s >> t;
        cout << (isIsomorphic(s, t) ? "true" : "false") << endl;
    }
    
    return 0;
}
```

### Python 实现
```python
# NQ084 同构字符串
def is_isomorphic(s, t):
    if len(s) != len(t):
        return False
    
    s_to_t = {}
    t_to_s = {}
    
    for c1, c2 in zip(s, t):
        if c1 in s_to_t:
            if s_to_t[c1] != c2:
                return False
        else:
            if c2 in t_to_s:
                return False
            s_to_t[c1] = c2
            t_to_s[c2] = c1
    
    return True

def main():
    import sys
    n = int(sys.stdin.readline())
    
    for _ in range(n):
        line = sys.stdin.readline().strip()
        s, t = line.split()
        print("true" if is_isomorphic(s, t) else "false")

if __name__ == "__main__":
    main()
```

## 代码优化点
1. **边界情况处理**：
   - 首先检查两个字符串的长度是否相同，不同则直接返回 false

2. **双向映射检查**：
   - 使用两个哈希表分别存储正向和反向映射，确保映射的一一对应关系

3. **哈希表操作优化**：
   - C++：使用 `unordered_map` 的 `count` 方法快速检查键是否存在
   - Python：使用字典的 `in` 操作符快速检查键是否存在

4. **代码结构优化**：
   - 逻辑清晰，步骤明确
   - 使用三元运算符简化条件输出

## 算法分析
- **时间复杂度**：O(n)，其中 n 是字符串的长度
  - 需要遍历字符串中的每个字符一次
  - 哈希表的插入和查找操作平均时间复杂度为 O(1)

- **空间复杂度**：O(k)，其中 k 是字符串中不同字符的数量
  - 最坏情况下，k = n，此时空间复杂度为 O(n)
  - 哈希表需要存储字符之间的映射关系

哈希映射是解决同构字符串问题的高效方法，通过建立双向映射关系，确保字符之间的一一对应。该算法时间复杂度为 O(n)，空间复杂度为 O(k)，能够在线性时间内完成判断。

**算法特点**：
- 实现简单直观，逻辑清晰

**适用场景**：
- 判断两个字符串是否同构
