# 三数之和

## 题目描述

# NQ059 三数之和

## 问题描述
在一个数组中寻找所有满足 nums[i] + nums[j] + nums[k] == target 且 i < j < k 的三元组。

## 算法选择
采用**排序+双指针**的方法，利用排序后的数组特性，通过固定一个元素并使用双指针寻找另外两个元素的方式，高效地解决三数之和问题。

## 算法原理
1. **排序预处理**：对数组进行排序，为双指针操作和去重提供基础
2. **固定第一个元素**：遍历数组，将当前元素作为三元组的第一个数 x
3. **双指针寻找剩余两数**：
   - 左指针 j 指向 x 的下一个元素，作为第二个数 y
   - 右指针 k 指向数组末尾，作为第三个数 z
   - 计算三数之和，根据和与目标值的关系移动指针
4. **去重处理**：在遍历过程中跳过重复元素，避免生成重复的三元组
5. **条件过滤**：严格满足 x < y < z 的条件

## 实现步骤
1. **读取输入**：读取目标值 target、数组长度 n，以及 n 个数组元素
2. **排序数组**：对数组进行升序排序
3. **遍历第一个元素**：
   - 对于每个元素 nums[i]，作为三元组的第一个数 x
   - 跳过重复的 x，避免重复三元组
4. **双指针搜索**：
   - 初始化 j = i+1，k = n-1
   - 计算当前和 sum = x + nums[j] + nums[k]
   - 根据 sum 与 target 的关系移动指针：
     - sum == target：记录符合条件的三元组，跳过重复的 y 和 z，移动双指针
     - sum > target：和过大，k 左移
     - sum < target：和过小，j 右移
5. **输出结果**：遍历完成后，输出所有找到的三元组

## 代码实现

### C++ 实现
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

vector<vector<int>> threeSum(vector<int>& nums, int target) {
    vector<vector<int>> res;
    int n = nums.size();
    sort(nums.begin(), nums.end());
    
    for (int i = 0; i < n; ++i) {
        // 跳过重复的第一个元素，避免重复三元组
        if (i > 0 && nums[i] == nums[i-1]) continue;
        
        // 初始化双指针：j指向i的下一个元素，k指向数组末尾
        int j = i + 1, k = n - 1;
        while (j < k) {
            int sum = nums[i] + nums[j] + nums[k];
            
            if (sum == target) {
                // 严格满足x<y<z的条件
                if (nums[i] < nums[j] && nums[j] < nums[k]) {
                    res.push_back({nums[i], nums[j], nums[k]});
                }
                // 跳过重复的第二个元素
                while (j < k && nums[j] == nums[j+1]) ++j;
                // 跳过重复的第三个元素
                while (j < k && nums[k] == nums[k-1]) --k;
                // 移动双指针寻找下一组解
                ++j;
                --k;
            } else if (sum > target) {
                // 和过大，需要减小，移动右指针
                --k;
            } else {
                // 和过小，需要增大，移动左指针
                ++j;
            }
        }
    }
    return res;
}

int main() {
    int target, n;
    cin >> target >> n;
    vector<int> nums(n);
    for (int i = 0; i < n; ++i) {
        cin >> nums[i];
    }
    
    vector<vector<int>> result = threeSum(nums, target);
    for (const auto& triplet : result) {
        cout << triplet[0] << " " << triplet[1] << " " << triplet[2] << endl;
    }
    return 0;
}
```

### Python 实现
```python
def three_sum(nums, target):
    res = []
    n = len(nums)
    nums.sort()
    
    for i in range(n):
        # 跳过重复的第一个元素，避免重复三元组
        if i > 0 and nums[i] == nums[i-1]:
            continue
        
        # 初始化双指针：j指向i的下一个元素，k指向数组末尾
        j, k = i + 1, n - 1
        while j < k:
            current_sum = nums[i] + nums[j] + nums[k]
            
            if current_sum == target:
                # 严格满足x<y<z的条件
                if nums[i] < nums[j] and nums[j] < nums[k]:
                    res.append([nums[i], nums[j], nums[k]])
                # 跳过重复的第二个元素
                while j < k and nums[j] == nums[j+1]:
                    j += 1
                # 跳过重复的第三个元素
                while j < k and nums[k] == nums[k-1]:
                    k -= 1
                # 移动双指针寻找下一组解
                j += 1
                k -= 1
            elif current_sum > target:
                # 和过大，需要减小，移动右指针
                k -= 1
            else:
                # 和过小，需要增大，移动左指针
                j += 1
    
    return res

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    target = int(input[idx])
    idx += 1
    n = int(input[idx])
    idx += 1
    nums = list(map(int, input[idx:idx+n]))
    idx += n
    
    result = three_sum(nums, target)
    for triplet in result:
        print('{0} {1} {2}'.format(triplet[0], triplet[1], triplet[2]))

if __name__ == "__main__":
    main()
```

## 核心要点

### 1. 排序的重要性
- **双指针基础**：排序后，数组元素有序，使得双指针能够有效工作
- **去重方便**：排序后，重复元素相邻，容易跳过重复值
- **指针移动逻辑**：排序后，可以根据和的大小关系，有方向地移动指针

### 2. 双指针的工作原理
- **固定一个元素**：将问题转化为两数之和问题
- **左右指针**：左指针从固定元素的下一个位置开始，右指针从数组末尾开始
- **和的比较**：根据三数之和与目标值的关系，调整指针位置
- **时间复杂度**：O(n²)，其中排序占O(n log n)，双指针搜索占O(n²)

### 3. 去重策略
- **第一个元素去重**：跳过与前一个元素相同的当前元素
- **第二、三个元素去重**：找到符合条件的三元组后，跳过相邻的重复元素
- **避免重复三元组**：通过以上去重步骤，确保每个三元组只被记录一次

### 4. 条件过滤
- **严格递增**：确保三元组中的元素满足 x < y < z 的条件
- **避免无效解**：过滤掉不满足条件的组合

### 5. 边界情况处理
- **数组长度不足**：当数组长度小于3时，直接返回空结果
- **指针越界**：确保 j < k 的条件，避免指针交叉
- **重复元素**：通过去重策略处理重复元素

## 算法分析
- **时间复杂度**：O(n²)
  - 排序时间复杂度：O(n log n)
  - 双指针搜索时间复杂度：O(n²)
  - 总体时间复杂度：O(n²)

- **空间复杂度**：O(1)（不考虑输出空间）
  - 只使用了常数级的额外空间
  - 排序操作原地进行，不需要额外空间

## 总结
三数之和问题是双指针算法的经典应用，通过排序和双指针的结合，将时间复杂度从暴力枚举的O(n³)降低到O(n²)。该算法的核心在于：

1. **排序预处理**：为双指针操作和去重提供基础
2. **固定一个元素**：将问题转化为两数之和问题
3. **双指针搜索**：高效寻找满足条件的另外两个元素
4. **去重处理**：避免生成重复的三元组
5. **条件过滤**：确保满足题目要求的条件

通过本算法的学习，读者可以掌握如何利用排序和双指针技术解决多数之和问题，以及如何处理重复元素的去重策略，提高解决类似问题的能力。
