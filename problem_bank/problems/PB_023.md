# 左旋字符串

## 题目描述

字符串的左旋转操作是把字符串前面的若干个字符转移到字符串的尾部。请定义一个函数实现字符串左旋转操作的功能。比如输入字符串 "abcdefg" 和数字 2，该函数将返回左旋转 2 位得到的结果 "cdefgab" 。

## 输入格式

输入一个字符串和一个整数 n 。数据范围：输入字符串长度[0, 1000]，n小于等于输入字符串的长度。

## 输出格式

输出左旋转后的字符串。

## 样例

**样例 1：**

输入：
"abcdefg"
2
输出：
"cdefgab"
