# NQ087 思路分析

## 问题描述
给定一个R行C列的矩阵，每个位置有一个高度值。要求找到一条最长的滑行路径，路径上的高度必须严格递减。每次移动可以上下左右四个方向。

## 思考过程
1. **问题分析**：需要在矩阵中找到最长的严格递减路径，这是一个典型的路径搜索问题。
2. **算法选择**：使用深度优先搜索（DFS）结合记忆化技术，避免重复计算。
3. **数据结构**：使用二维数组存储高度矩阵和记忆化结果。
4. **记忆化**：对于每个位置，存储从该位置出发的最长滑行路径长度，避免重复计算。

## 算法思路
- **深度优先搜索**：从每个位置出发，向四个方向搜索，寻找可以滑行的路径。
- **记忆化**：使用dp[i][j]存储从(i,j)出发的最长滑行路径长度，当再次访问该位置时直接返回结果。
- **贪心策略**：对于每个位置，选择四个方向中最长的路径，加上当前位置本身。

## 实现步骤
1. **输入处理**：读取矩阵的行数R和列数C，以及每个位置的高度值。
2. **初始化**：初始化记忆化数组dp为-1，表示尚未计算过。
3. **深度优先搜索**：对每个位置调用DFS函数，计算从该位置出发的最长滑行路径长度。
4. **结果计算**：遍历所有位置的最长路径长度，取最大值作为答案。

## 关键点编码逻辑
- **DFS函数**：递归计算从当前位置出发的最长滑行路径长度，使用记忆化技术避免重复计算。
- **方向数组**：定义四个方向的偏移量，方便遍历相邻位置。
- **边界检查**：确保访问的位置在矩阵范围内。
- **高度检查**：确保当前位置的高度大于相邻位置的高度，才能滑行。

## 时间复杂度
- **时间复杂度**：O(R*C)，每个位置只需要计算一次，因为使用了记忆化技术。
- **空间复杂度**：O(R*C)，需要存储高度矩阵和记忆化数组。

## 代码优化
- 使用记忆化技术避免重复计算，提高算法效率。
