# 质数环

## 题目描述

# NQ080 质数环

## 问题描述
构造一个长度为n的环，使得相邻两个数的和为质数，且第一个数固定为1。

## 算法思路
采用**深度优先搜索(DFS) + 回溯**：
1. **质数预处理**：使用打表法标记所有可能的质数（最大和为39）
2. **DFS搜索**：从第一个位置（固定为1）开始，尝试填充每个位置
3. **剪枝条件**：当前数字未被使用，且与前一个数字之和为质数
4. **回溯处理**：递归返回时，恢复状态以尝试其他可能
5. **结束条件**：填充完n个元素，且首尾之和为质数

## 实现步骤
1. **预处理质数表**：标记2-37之间的质数
2. **dfs函数**：
   - 处理递归终止条件
   - 尝试所有可能的数字
   - 检查剪枝条件
   - 递归搜索下一个位置
   - 回溯恢复状态
3. **main函数**：
   - 处理多个测试用例
   - 初始化变量和标记数组
   - 调用dfs函数
   - 控制输出格式

## 代码实现

### C++ 实现
```cpp
#include <iostream>
#include <cstring>
using namespace std;
bool p[100];
bool used[100];
int a[100];
int n, now = 0;
void dfs(int deep) {
    if (deep == n + 1 && p[a[1] + a[n]]) {
        for (int i = 1; i <= n; i++) {
            cout << a[i];
            if (i != n) cout << " ";
        }
        cout << endl;
        return;
    }
    for (int i = 2; i <= n; i++) {
        if (!used[i] && p[i + a[deep - 1]]) {
            used[i] = true;
            a[deep] = i;
            dfs(deep + 1);  // 递归搜索下一个位置
            used[i] = false;  // 回溯
        }
    }
}
int main() {
    // 预处理质数表
    memset(p, false, sizeof(p));
    p[2] = p[3] = p[5] = p[7] = p[11] = true;
    p[13] = p[17] = p[19] = p[23] = p[29] = true;
    p[31] = p[37] = true;
    bool first_case = true;
    while (cin >> n) {
        a[1] = 1;  // 第一个元素固定为1
        if (!first_case) {
            cout << endl;
        }
        first_case = false;
        cout << "Case " << ++now << ":" << endl;
        memset(used, false, sizeof(used));
        dfs(2);  // 从第二个位置开始DFS
    }
    return 0;
}
```

### Python 实现
```python
# 质数标记数组，p[i]为True表示i是质数
p = [False] * 100
# 初始化质数表
p[2] = p[3] = p[5] = p[7] = p[11] = True
p[13] = p[17] = p[19] = p[23] = p[29] = True
p[31] = p[37] = True

now = 0

def dfs(deep, n, a, used):
    if deep == n and p[a[0] + a[-1]]:
        print(' '.join(map(str, a)))
        return
    for i in range(2, n + 1):
        if not used[i] and p[i + a[-1]]:
            used[i] = True
            a.append(i)
            dfs(deep + 1, n, a, used)  # 递归搜索下一个位置
            a.pop()  # 回溯
            used[i] = False  # 回溯

def main():
    global now
    first_case = True
    import sys
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        if not first_case:
            print()
        first_case = False
        now += 1
        print("Case {}:".format(now))
        used = [False] * (n + 1)
        a = [1]  # 第一个元素固定为1
        used[1] = True
        dfs(1, n, a, used)  # 从第二个位置开始DFS

if __name__ == "__main__":
    main()
```

## 复杂度分析
- **时间复杂度**：O(n!)，最坏情况下需要尝试所有排列
- **空间复杂度**：O(n)，用于存储环元素和标记数组

## 示例
以n=6为例：
- 可能的解：1 4 3 2 5 6
- 验证：1+4=5（质数），4+3=7（质数），3+2=5（质数），2+5=7（质数），5+6=11（质数），6+1=7（质数）
