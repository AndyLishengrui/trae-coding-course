# NQ010 小鲁记账

## 解题思路
1. **读取输入**：读取数值个数n，当n为0时结束处理。
2. **初始化计数器**：初始化负数个数a、零个数b、正数个数c为0。
3. **统计数值**：读取n个实数，分别统计负数、零和正数的个数。
4. **输出结果**：按照a、b、c的顺序打印统计结果。
