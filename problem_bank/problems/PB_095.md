# NQ014 凤凰花开吃杨梅

## 解题思路
1. **问题分析**：已知第n天剩下1个杨梅，每天吃一半加一个，需要逆推最初的杨梅数。
2. **逆推公式**：前一天杨梅数 = (当天杨梅数 + 1) * 2。
3. **计算过程**：从第n天开始，使用逆推公式计算n-1次，得到第1天的杨梅数。
4. **输出结果**：打印计算得到的最初杨梅数。
