# NQ066 思路分析

## 问题描述
输入多个测试用例，每个测试用例包含一个整数 idx，输出第 idx 个谦虚数。谦虚数是指只包含质因数 2、3、5、7 的正整数。

## 思考过程
1. **问题分析**：谦虚数的定义是只包含质因数 2、3、5、7 的数，因此需要找到所有这样的数并按顺序存储。
2. **算法选择**：考虑到谦虚数的生成方式，暴力枚举是一种直接有效的方法，因为我们需要找到前 N 个谦虚数。
3. **数据结构**：使用数组存储找到的谦虚数，方便后续查询。
4. **性能考虑**：虽然暴力枚举的时间复杂度较高，但对于题目要求的范围（最大到第 5842 个谦虚数）是可行的。

## 算法思路
- **暴力枚举**：从 1 开始遍历每个数，判断是否是谦虚数。
- **质因数判断**：对于每个数，依次除以 2、3、5、7，看最终是否得到 1。
- **存储结果**：将找到的谦虚数存储在数组中，建立索引表。
- **查询输出**：根据输入的索引，直接从数组中获取对应的谦虚数。

## 实现步骤
1. **初始化数组**：创建一个足够大的数组来存储谦虚数。
2. **暴力枚举**：从 1 开始遍历，直到找到足够多的谦虚数。
3. **判断谦虚数**：对于每个数，依次除以 2、3、5、7，若最终结果为 1，则是谦虚数。
4. **存储结果**：将找到的谦虚数存入数组中。
5. **处理查询**：读取输入的查询次数和索引，从数组中查找并输出对应的值。

## 关键点编码逻辑
- **is_humble_number 函数**：用于判断一个数是否是谦虚数，通过不断除以 2、3、5、7 来验证。
- **数组存储**：使用数组存储所有谦虚数，方便快速查询。
- **暴力枚举范围**：设置足够大的遍历范围（20000000），确保能找到所有需要的谦虚数。
- **查表输出**：通过数组索引直接获取结果，实现 O(1) 时间复杂度的查询。

## 时间复杂度
- **预处理时间**：O(M)，其中 M 是找到第 N 个谦虚数时的最大遍历值。
- **查询时间**：O(1)，直接通过数组索引获取结果。
- **空间复杂度**：O(N)，需要存储前 N 个谦虚数。
