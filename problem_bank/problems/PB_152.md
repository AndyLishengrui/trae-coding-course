# 求八皇后的第n种解

## 题目描述

# NQ074 求八皇后的第n种解思路

## 问题分析

### 问题描述
输入一个正整数n，输出八皇后问题的第n种解。

### 问题分析
- 八皇后问题是一个经典的回溯算法问题
- 目标是在8×8的棋盘上放置8个皇后，使得它们互不攻击
- 皇后的攻击范围包括同一行、同一列和同一对角线
- 八皇后问题共有92种不同的解决方案
- 本题要求输出第n种解决方案

## 算法设计

### 深度优先搜索（DFS）+ 回溯法
1. **预处理所有解**：
   - 使用深度优先搜索和回溯法找出所有8皇后解
   - 将所有解存储在一个二维数组中
2. **查询第n种解**：
   - 输入n后，直接从预处理的解中取出第n-1个解（因为数组从0开始索引）
   - 输出该解

### 状态表示
- 使用一个长度为8的数组`p`（或`path`）表示当前搜索路径，其中`p[i]`表示第i行皇后的列位置
- 使用一个二维数组`s`（或`solutions`）存储所有找到的解
- 使用一个计数器`cnt`（或`solution_count`）记录找到的解的数量

### 递归过程
1. **递归终止条件**：当处理完所有8行时，保存当前解并增加计数器
2. **尝试放置皇后**：在当前行的每一列尝试放置皇后
3. **安全检查**：检查当前位置是否与之前的皇后冲突
4. **递归处理**：如果安全，放置皇后并递归处理下一行

## 代码实现

### C++实现
```cpp
// 求八皇后的第n种解
#include <iostream>
#include <cstring>
using namespace std;

int s[92][8],  // 存储所有8皇后解
    p[8],      // 存储当前搜索路径
    cnt=0;     // 当前找到的解的数量

// 深度优先搜索所有8皇后解
void dfs(int r) {  // r: 当前处理的行
    if(r>7) {  // 所有行处理完毕
        for(int i=0;i<8;++i) s[cnt][i]=p[i];  // 保存当前解
        cnt++;  // 解的数量加1
        return;
    }
    for(int c=1;c<=8;++c) {  // 尝试在当前行的每一列放置皇后
        bool ok=1;  // 标记是否可以放置
        for(int i=0;i<r;++i)  // 检查是否与之前的皇后冲突
            if(p[i]==c||abs(p[i]-c)==abs(r-i)) { ok=0; break; }
        if(ok) { p[r]=c; dfs(r+1); }  // 放置皇后并递归处理下一行
    }
}

// 预处理所有8皇后解
void pre() { memset(p,0,sizeof(p)); cnt=0; dfs(0); }

int main() {
    pre();  // 预处理所有解
    int T,n;  // T: 测试用例数量, n: 要求的解的序号
    cin>>T;
    while(T--) {
        cin>>n;
        if(n<1||n>92) { cout<<"Invalid input!\n"; continue; }
        for(int i=0;i<8;++i) cout<<s[n-1][i];  // 输出第n-1个解
        cout<<'\n';
    }
    return 0;
}
```

### Python实现
```python
# 求八皇后的第n种解
s=[]  # 存储所有8皇后解

# 深度优先搜索所有8皇后解
def dfs(r,p):  # r: 当前处理的行, p: 当前搜索路径
    global s
    if r>7:  # 所有行处理完毕
        s.append(p.copy())  # 保存当前解
        return
    for c in range(1,9):  # 尝试在当前行的每一列放置皇后
        ok=1  # 标记是否可以放置
        for i in range(r):  # 检查是否与之前的皇后冲突
            if p[i]==c or abs(p[i]-c)==abs(r-i):
                ok=0
                break
        if ok:  # 可以放置，递归处理下一行
            p[r]=c
            dfs(r+1,p)

# 预处理所有8皇后解
def pre():
    global s
    s=[]
    dfs(0,[0]*8)  # 从第0行开始搜索

def main():
    pre()  # 预处理所有解
    import sys
    inp=sys.stdin.read().splitlines()
    T=int(inp[0])  # 测试用例数量
    for i in range(1,T+1):
        n=int(inp[i])  # 要求的解的序号
        if n<1 or n>92:
            print("Invalid input!")
            continue
        for pos in s[n-1]:  # 输出第n-1个解
            print(pos,end='')
        print()

if __name__=="__main__":
    main()
```

## 时间空间复杂度分析

### 时间复杂度
- **预处理阶段**：O(8!)，因为八皇后问题的时间复杂度为O(N!)
- **查询阶段**：O(1)，直接从预处理的解中取出对应解
- **总体时间复杂度**：O(1) per query，因为预处理只需要执行一次

### 空间复杂度
- **空间复杂度**：O(92×8) = O(736)，用于存储所有8皇后解
- 递归调用栈的深度最多为8，空间使用可以忽略不计

## 算法优化

1. **预处理优化**：
   - 只需要预处理一次，后续查询直接使用预处理结果
   - 避免了重复计算，提高了查询效率

2. **空间优化**：
   - 只存储必要的解，不需要存储中间状态
   - 空间使用固定，与输入无关

3. **输入处理优化**：
   - 一次性读取所有输入，减少I/O操作
   - 对输入进行有效性检查，提高程序的鲁棒性

## 总结

- 八皇后问题是回溯算法的经典应用
- 预处理所有解的方法可以大大提高查询效率
- 深度优先搜索结合回溯法是解决此类问题的有效方法
- 该算法的时间复杂度为O(1) per query，空间复杂度为O(1)
- 该方法可以推广到其他类似的排列问题，如N皇后问题的第n种解

通过预处理所有解，我们可以在常数时间内回答任意第n种解的查询，这是一种典型的空间换时间的优化策略。
