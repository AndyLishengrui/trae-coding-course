# 交换数值

## 题目描述

输入两个整数 x 和 y，请编写一个函数，交换两个整数的数值并输出交换后的 x 和 y。C++ 中的格式为：void swap(int &x, int &y) 。
Java 中的格式为：void swap(int[] a)，交换 a[0] 和 a[1] 。

## 输入格式

共一行，包含两个整数 x 和 y。数据范围：1 ≤ x, y ≤ 100

## 输出格式

共一行，包含交换后的 x 和 y。

## 样例

**样例 1：**

输入：
3 5
输出：
5 3
