# A04 区间 2

## 题目描述

读取 N 个整数 X1,X2,…,XN，判断这 N 个整数中有多少个在 [10,20] 的范围内，有多少个在范围外。

## 输入格式

第一行包含整数 N，表示共有 N 个整数需要进行判断。接下来 N 行，每行包含一个整数 Xi。数据范围1≤N≤10000,−10^7<Xi<10^7

## 输出格式

第一行输出x in，其中 x 为在范围内的整数的数量。第二行输出y out，其中 y 为在范围外的整数的数量。

## 输入输出样例

**样例 1：**

输入：
4
14
123
10
-25
输出：
2 in
2 out


## 提示

注意区间的开闭情况。
