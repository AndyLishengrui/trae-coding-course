# A07 选择练习1

## 题目描述

读取 4 个整数 A，B，C 和 D。如果四个整数同时满足以下条件：B 大于 A。D 大于 A。C 和 D 的总和大于 A 和 B 的总和。C 是正数。A 是偶数。则输出Valores aceitos，否则，输出Valores nao aceitos。

## 输入格式

输入占一行，包含四个整数 A, B, C, D。数据范围−100≤A,B,C,D≤100

## 输出格式

如果输入数值满足题目条件则输出Valores aceitos，否则输出Valores nao aceitos。

## 输入输出样例

**样例 1：**

输入：
5 6 7 8
输出：
Valores nao aceitos


## 提示

注意条件的顺序和逻辑关系。
