# D07 数组中的列

## 题目描述

输入一个二维数组 M[12][12]，根据要求，求出二维数组中某一列的元素的平均值或元素的和。

## 输入格式

第一行输入整数 C，表示所求的具体列数（列数从 0 开始计数）。第二行包含一个大写字母，若为 S，则表示需要求出第 C 列的元素的和，若为 M，则表示需要求出第 C 列的元素的平均值。接下来 12 行，每行包含 12 个用空格隔开的浮点数，表示这个二维数组。

## 输出格式

输出一个数，表示所求的平均值或元素的和的值，保留一位小数。
