# D02 数组填充

## 题目描述

输入一个整数 V，输出一个长度为 10 的数组 N，其中 N[0] = V，每个后续元素的值都为前一个元素的值的 2 倍。

## 输入格式

输入一行，包含一个整数 V（1 ≤ V ≤ 50）。

## 输出格式

输出数组中的所有元素，每个元素占一行，格式为N[i] = x，其中 i 为数组下标（从 0 开始），x 为对应的数值。

## 输入输出样例

**样例 1：**

输入：
1
输出：
N[0] = 1
N[1] = 2
N[2] = 4
N[3] = 8
N[4] = 16
N[5] = 32
N[6] = 64
N[7] = 128
N[8] = 256
N[9] = 512


## 提示

注意输出格式，每个数都为前一个数的 2 倍。来源：语法题
