# NQ012X 数组的上部区域 解题思路

## 问题描述
输入一个二维数组M[12][12]，根据输入的要求，求出二维数组的上部区域元素的平均值或元素的和。

## 输入输出示例
输入：
```
S
-4.8 -8.0 -2.9 6.7 -7.0 2.6 6.5 1.7 1.9 5.6 -1.6 -6.3
```

输出：
```
21.7
```

## 解题思路
1. **读取输入**：首先读取一个大写字母，如果为'S'，表示需要求上部区域的元素的和；如果为'M'，表示需要求上部区域的元素的平均值。接着读取12行，每行包含12个用空格隔开的小数，表示这个二维数组。
2. **计算上部区域**：上部区域是指i从0到4，j从i+1到11-i的元素。遍历数组，累加这些元素的值，并统计元素个数。
3. **输出结果**：根据输入的字母，输出和或者平均值（平均值为和除以元素个数），保留一位小数。

## 代码实现
- **C++**：使用二维数组存储12x12的浮点数，通过for循环读取输入，计算上部区域的和和元素个数，然后根据输入的字母输出和或平均值，使用fixed和setprecision(1)控制输出格式。
- **Python**：使用列表存储12x12的浮点数，通过for循环读取输入，计算上部区域的和和元素个数，然后根据输入的字母输出和或平均值，使用格式化字符串控制输出格式。
