# NQ051 数组元素交换解题思路

## 解题思路
1. **问题描述**：输入多个数组，每个数组中找到最小值，将其与数组的第一个元素交换，然后输出交换后的数组。当输入n≤0时结束处理。
2. **输入处理**：读取多个测试用例，每个测试用例包含一个整数n和n个整数。
3. **核心逻辑**：
   - 读取数组元素
   - 找到数组中的最小值及其下标
   - 将最小值与第一个元素交换
   - 输出交换后的数组
4. **关键处理**：
   - 当最小值已经在第一个位置时，无需交换
   - 处理多组测试用例，直到输入n≤0

## 输入输出示例

#### 输入示例
```
5
3 1 4 1 5
3
9 8 7
0
```

#### 输出示例
```
1 3 4 1 5
7 8 9
```

**解释**：
- 第一组：最小值是1，位于索引1，与第一个元素3交换
- 第二组：最小值是7，位于索引2，与第一个元素9交换
- 输入0时结束处理

## 复杂度分析

### 时间复杂度
- 对于每个数组，遍历一次找到最小值，时间复杂度为O(n)，其中n是数组长度
- 总体时间复杂度为O(Σn)，其中Σn是所有数组长度的总和

### 空间复杂度
- 存储数组元素，空间复杂度为O(n)

## 代码实现思路

### C++ 实现
1. 使用循环读取测试用例，直到n≤0
2. 读取n个整数到数组中，同时记录最小值及其下标
3. 交换最小值与第一个元素（如果需要）
4. 输出交换后的数组

### Python 实现
1. 一次性读取所有输入，使用指针逐个处理
2. 读取n，然后读取n个整数到列表中
3. 使用内置函数min()找到最小值，index()找到其下标
4. 交换最小值与第一个元素（如果需要）
5. 输出交换后的列表

## 总结
- 该问题主要考察数组的基本操作和最小值查找
- 实现思路简单直接，关键是正确找到最小值并与第一个元素交换
- 注意处理边界情况，如最小值已经在第一个位置时无需交换
- Python的实现利用了内置函数，代码更加简洁
