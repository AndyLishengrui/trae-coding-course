# NQ008X 数组选择 解题思路

## 问题描述
输入一个长度为100的数组A，按顺序输出其中不大于10的所有元素。

## 输入输出示例
输入：
```
0
-5
63
-8.5
... (共100个数)
```

输出：
```
A[0] = 0.0
A[1] = -5.0
A[3] = -8.5
... (仅输出不大于10的元素)
```

## 解题思路
1. **读取输入**：读取100个数，存储到数组A中。
2. **筛选元素**：遍历数组，找出所有不大于10的元素。
3. **输出结果**：按照指定格式输出符合条件的元素，格式为"A[i] = x"，其中i为原数组中对应元素的下标，x保留一位小数。

## 代码实现
- **C++**：使用数组存储100个浮点数，通过for循环读取输入，然后筛选出不大于10的元素并输出，使用fixed和setprecision(1)控制输出格式。
- **Python**：使用列表存储100个浮点数，通过for循环读取输入，然后筛选出不大于10的元素并输出，使用格式化字符串控制输出格式。
