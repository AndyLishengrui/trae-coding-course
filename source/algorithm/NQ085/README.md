# NQ085 数字三角形

## 问题描述
给定一个数字三角形，找到从顶部到底部的最大路径和，每次只能移动到下一层的相邻节点。

## 算法思路
1. **动态规划**：使用二维数组 `f[i][j]` 表示从顶部到达第 `i` 行第 `j` 列的最大路径和。

2. **状态转移**：
   - 状态转移方程：`f[i][j] = a[i][j] + max(f[i-1][j-1], f[i-1][j])`
   - 其中 `a[i][j]` 是数字三角形第 `i` 行第 `j` 列的值
   - 每个位置的最大路径和等于当前值加上来自左上方或正上方的较大路径和

3. **初始化**：`f[1][1] = a[1][1]`，即顶部元素的最大路径和就是它自身。

4. **结果**：遍历最后一层的所有节点，找到最大的路径和即为答案。

## 代码实现
- **C++**：使用二维 vector 存储数字三角形和动态规划状态，通过双重循环进行状态转移。
- **Python**：使用二维列表存储数据，通过双重循环进行状态转移，注意输入处理以兼容 Python 3.5。

## 时间复杂度
- 时间复杂度：O(n²)，其中 n 是数字三角形的行数。
- 空间复杂度：O(n²)，需要存储数字三角形和动态规划状态。
