# NQ030 小球进盒子

## 解题思路
1. **问题描述**：计算小球进盒子的最大得分，红球和黑球可以放入自己的盒子或对方的盒子，不同放入方式有不同得分。
2. **输入参数**：
   - R：红球数量
   - B：黑球数量
   - C：红球放入红盒的得分
   - D：黑球放入黑盒的得分
   - E：球放入对方盒子的得分
3. **核心逻辑**：
   - **情况1**：如果C + D > 2 * E，说明红黑球都放自己盒子得分更高，总得分 = R * C + B * D
   - **情况2**：如果C + D <= 2 * E，说明交换盒子可能得分更高，此时分为三种子情况：
     - 红球比黑球多：总得分 = B * E + B * E + (R - B) * C
     - 黑球比红球多：总得分 = R * E + R * E + (B - R) * D
     - 红黑球数量相等：总得分 = R * 2 * E
4. **输出结果**：根据上述逻辑计算并输出最大得分。

## 代码实现
- **C++**：
  - 使用变量R, B, C, D, E分别表示红球数量、黑球数量、红球放入红盒得分、黑球放入黑盒得分、放入对方盒子得分
  - 根据C + D与2*E的关系判断是否交换盒子
  - 针对不同情况计算并输出最大得分

## 时间复杂度
- O(1)：无论输入规模如何，计算过程都是常数时间的
