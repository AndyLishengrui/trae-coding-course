# NQ029 回文数判断

#### 解题思路
1. **问题定义**：回文数是正向和反向读都一样的整数。
2. **判断逻辑**：对于给定的整数x，判断其是否为回文数。
3. **核心步骤**：
   - 如果x < 0，直接返回false（负数不可能是回文数）
   - 反转x的数字，得到res
   - 比较res和原始x是否相等，相等则是回文数，否则不是
4. **反转方法**：
   - 使用循环，每次取x的最后一位数字（x % 10）
   - 将这个数字添加到res的末尾（res = res * 10 + x % 10）
   - 去掉x的最后一位（x /= 10 或 x //= 10）
   - 重复直到x变为0
5. **输入输出**：读取输入的整数n，输出"true"或"false"表示是否为回文数。
