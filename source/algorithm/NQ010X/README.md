# NQ010X 数组的右上半部分 解题思路

## 问题描述
输入一个二维数组M[12][12]，根据输入的要求，求出二维数组的右上半部分元素的平均值或元素的和。

## 输入输出示例
输入：
```
M
```

输出：
```
-1.2
```

## 解题思路
1. **读取输入**：首先读取一个大写字母，如果为'S'，表示需要求右上半部分的元素的和；如果为'M'，表示需要求右上半部分的元素的平均值。接着读取12行，每行包含12个用空格隔开的小数，表示这个二维数组。
2. **计算右上半部分**：右上半部分是指主对角线以上的部分，即j > i的元素。遍历数组，累加这些元素的值，并统计元素个数。
3. **输出结果**：根据输入的字母，输出和或者平均值（平均值为和除以元素个数），保留一位小数。

## 代码实现
- **C++**：使用二维数组存储12x12的浮点数，通过for循环读取输入，计算右上半部分的和和元素个数，然后根据输入的字母输出和或平均值，使用fixed和setprecision(1)控制输出格式。
- **Python**：使用列表存储12x12的浮点数，通过for循环读取输入，计算右上半部分的和和元素个数，然后根据输入的字母输出和或平均值，使用格式化字符串控制输出格式。
