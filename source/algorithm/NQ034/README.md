# NQ034 求小数点后的数

## 解题思路
1. **问题描述**：给定一个小数x和一个整数t，求x的小数点后第t位数字（1<=t<=6）。
2. **输入处理**：读取测试用例数量N，然后读取N组数据，每组数据包含小数x和整数t。
3. **核心逻辑**：
   - 将小数x乘以10的t次方，将小数点后第t位数字移动到个位位置
   - 添加极小修正值（1e-9）避免浮点数精度问题（如9.999999999999被误判为9）
   - 将结果取整后对10取模，得到个位数字（即原小数点后第t位数字）
4. **输出结果**：输出计算得到的数字。

## 代码实现
- **C++**：
  - 使用`cin`读取输入数据
  - 使用`while`循环处理t次乘以10的操作
  - 使用`static_cast<int>`将浮点数转换为整数
  - 输出取模后的结果

- **Python**：
  - 使用`sys.stdin.read().split()`读取所有输入并分割
  - 使用指针`ptr`追踪当前处理位置
  - 使用`while`循环处理t次乘以10的操作
  - 输出取模后的结果

## 时间复杂度
- O(N*t)：其中N是测试用例数量，t是小数点后位数
- 由于t的取值范围较小（1<=t<=6），因此实际时间复杂度接近O(N)
