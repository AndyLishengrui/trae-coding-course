# NQ007X 数组填充 解题思路

## 问题描述
输入一个整数V，输出一个长度为10的数组N，其中N[0] = V，每个后续元素的值都为前一个元素的值的2倍。

## 输入输出示例
输入：
```
1
```

输出：
```
N[0] = 1
N[1] = 2
N[2] = 4
N[3] = 8
N[4] = 16
N[5] = 32
N[6] = 64
N[7] = 128
N[8] = 256
N[9] = 512
```

## 解题思路
1. **读取输入**：读取一个整数V作为数组的第一个元素。
2. **填充数组**：创建一个长度为10的数组，将第一个元素设为V，然后从第二个元素开始，每个元素都是前一个元素的2倍。
3. **输出结果**：按照指定格式输出数组元素，格式为"N[i] = x"，其中i为元素下标（从0开始），x为元素值。

## 代码实现
- **C++**：使用数组存储10个整数，将第一个元素设为V，然后通过for循环填充后续元素，最后输出结果。
- **Python**：使用列表存储10个整数，将第一个元素设为V，然后通过for循环填充后续元素，最后输出结果。
