# NQ040 标记最大字符

## 解题思路
1. **问题描述**：对于输入的每个字符串，找到其中的最大字符（按ASCII值比较），并在该字符后添加"(max)"标记。
2. **输入处理**：读取多个字符串，每个字符串作为一个测试用例。
3. **核心逻辑**：
   - 对于每个字符串，找到其中的最大字符
   - 遍历字符串中的每个字符
   - 输出当前字符
   - 如果当前字符是最大字符，在其后输出"(max)"
   - 输出完所有字符后换行
4. **最大字符查找**：
   - C++：使用`max_element`函数查找最大字符
   - Python：使用`max`函数查找最大字符
