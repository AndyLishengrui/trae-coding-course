# NQ031 解密问题

## 解题思路
1. **问题描述**：解密密文，将大写字母左移5位，非字母字符保持不变。
2. **输入格式**：输入包含多个行，以"START"开始，以"ENDOFINPUT"结束，中间的行为需要解密的密文。
3. **解密规则**：
   - 对于大写字母：左移5位（等价于右移21位，避免负数取模问题）
   - 对于非大写字母：保持不变
4. **核心步骤**：
   - 使用状态标记`is_awaiting`跟踪是否处于处理密文状态
   - 读取输入行，遇到"START"时设置状态为准备处理
   - 处理密文行，对每个字符应用解密规则
   - 输出解密后的明文，重置状态
   - 遇到"ENDOFINPUT"时结束处理
