# NQ042 最长无重复子串

## 解题思路
1. **问题描述**：给定一个字符串，找出其中不包含重复字符的最长子串的长度。
2. **核心算法**：使用双指针（滑动窗口）和哈希表来实现。
3. **具体步骤**：
   - 定义左指针`j`和右指针`i`，初始都指向字符串起始位置
   - 使用哈希表`count`统计窗口内字符的出现次数
   - 右指针`i`向右移动，扩展窗口
   - 当遇到重复字符时，移动左指针`j`直到窗口内不再有重复字符
   - 在遍历过程中，不断更新最长子串的长度
4. **关键逻辑**：
   - 右指针移动：扩大窗口，统计字符出现次数
   - 左指针移动：缩小窗口，移除重复字符
   - 更新最长长度：每次窗口调整后计算当前窗口长度

## 代码实现
- **C++**：
  - 使用`unordered_map`作为哈希表统计字符出现次数
  - 双指针遍历字符串，处理重复字符
  - 更新并返回最长子串长度

- **Python**：
  - 使用字典作为哈希表统计字符出现次数
  - 双指针遍历字符串，处理重复字符
  - 更新并返回最长子串长度

## 时间复杂度
- O(n)：其中n是字符串长度
- 每个字符最多被访问两次（左指针和右指针各访问一次）
- 哈希表的插入和查询操作时间复杂度均为O(1)

## 空间复杂度
- O(k)：其中k是字符集的大小
- 哈希表最多存储k个不同的字符
- 对于ASCII字符集，空间复杂度为O(1)
