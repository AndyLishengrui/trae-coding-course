# 第10课：前缀和、差分与双指针

> **课时：** 2小时 | **题目：** 3例题 + 3练习 | **难度：** ⭐⭐⭐

## 一、本课目标
1. 理解前缀和的核心思想：用空间换时间，O(n²)→O(1)区间查询
2. 掌握一维和二维差分的区间修改技巧
3. 学会用双指针将 O(n²) 降到 O(n)

## 二、核心公式

```
一维前缀和: S[i] = a[1]+...+a[i],  a[l..r] = S[r] - S[l-1]
二维前缀和: S[x2,y2] - S[x1-1,y2] - S[x2,y1-1] + S[x1-1,y1-1]
一维差分: B[l] += c, B[r+1] -= c  （区间加c）
双指针: for(i=0,j=0;i<n;i++){ while(check) j++; }
```

## 五、AI 协作要点

前缀和是最经典的"预处理"思想。让学生理解：**有时候多算一些东西存下来（空间），反而让后续每次查询变得极快（时间）。** 这是算法设计的核心权衡。
