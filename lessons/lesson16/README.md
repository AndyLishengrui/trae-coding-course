## 一、本课目标
1. 理解贪心策略：局部最优→全局最优（何时成立？何时不成立？）
2. 掌握并查集的三种形态：朴素、维护size、维护距离（带权）
3. 综合运用本课程所有算法

## 二、并查集核心代码

```python
# 朴素并查集
p = list(range(n + 1))
def find(x):
    if p[x] != x:
        p[x] = find(p[x])  # 路径压缩
    return p[x]
def union(a, b):
    p[find(a)] = find(b)

# 带权并查集（食物链）
def find(x):
    if p[x] != x:
        root = find(p[x])
        d[x] += d[p[x]]  # 维护到根的距离
        p[x] = root
    return p[x]
```
