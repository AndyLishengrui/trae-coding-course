# 第5课：数组与线性存储

> **课时：** 2小时 | **题目：** 3例题 + 3练习 | **难度：** ⭐⭐

## 一、本课目标
1. 理解数组/列表的连续存储原理
2. 掌握数组遍历、修改、查找的基础操作
3. **Python 特色：** 列表推导式、切片、`enumerate()`

## 二、Python 工具箱

| 工具 | 用途 | 示例 |
|------|------|------|
| `list` | Python 动态数组（= C++ `vector`） | `arr = [0]*10` |
| `enumerate()` | 同时取索引和值 | `for i, v in enumerate(arr):` |
| 列表推导式 | 一行生成新列表 | `[x*2 for x in arr]` |
| `arr[::-1]` | 数组翻转 | 等价于 C++ `reverse` |
| `min(arr)`/`max(arr)` | 最值 | 等价于 C++ `*min_element` |

## 五、AI 协作要点

C++ 中需要写循环遍历数组，Python 一行列表推导式就能筛选或变换。教学生用 Trae 把 C++ 的 for 循环重构为 Python 的列表推导式。
