# 第6课：二维数组与矩阵

> **课时：** 2小时 | **题目：** 3例题 + 3练习 | **难度：** ⭐⭐⭐

## 一、本课目标
1. 掌握二维数组的创建和遍历（C++ `vector<vector<T>>` vs Python 嵌套 `list`）
2. 学会按区域（三角形、矩形）遍历矩阵
3. 理解平方矩阵 I/II/III 的模式填充逻辑

## 二、Python 工具箱

| 操作 | C++ | Python |
|------|-----|--------|
| 创建n×m矩阵 | `vector<vector<int>> a(n, vector<int>(m))` | `[[0]*m for _ in range(n)]` |
| ⚠ 陷阱 | — | `[[0]*m]*n` 是浅拷贝！每行指向同一对象 |
| 行遍历 | `for(int j=0;j<m;j++)` | `for x in row:` |
| 三角区域 | `for(j=i;j<n;j++)` | `for j in range(i, n):` |

## 三、例题

| 题号 | 题目 | 核心知识点 |
|------|------|-----------|
| NQ031 | 数组中的行 | 行遍历，`sum(row)` |
| NQ032 | 数组的右上半部分 | 三角区域条件 `j > i` |
| NQ033 | 数组的左上半部分 | 三角区域条件 `j < n-1-i` |

## 四、练习

| 题号 | 题目 | 核心模式 |
|------|------|---------|
| NQ034 | 数组的上方区域 | 上方三角 `i < j and i + j < n-1` |
| NQ035 | 平方矩阵 I | 四边距离最小值：`min(i,j,n-1-i,n-1-j)+1` |
| NQ036 | 平方矩阵 II | 对角线距离：`abs(i-j)+1` |

**NQ035/NQ036 教学要点：** 这两个平方矩阵题展示了数学思维在编程中的威力。与其逐格填充，不如找到一个数学公式直接算每个位置的值。

## 五、AI 协作要点

矩阵题很容易写出边界条件错误。教学生用 Trae 生成后，自己在纸上画一个 5×5 的矩阵逐格验证。
