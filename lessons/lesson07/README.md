# 第7课：字符串处理

> **课时：** 2小时 | **题目：** 3例题 + 3练习 | **难度：** ⭐⭐

## 一、本课目标
1. 掌握字符串基本操作：长度、查找、比较、替换、插入
2. **关键认知：** Python 字符串不可变（immutable），每次修改创建新对象
3. 学会何时用 `join()` 而非 `+=`（性能差异可达100倍）

## 二、Python 工具箱

| 操作 | C++ | Python |
|------|-----|--------|
| 长度 | `s.length()` | `len(s)` |
| 查找 | `s.find("x")` | `s.find("x")` |
| 替换 | `s.replace(...)` | `s.replace(old, new)` |
| 拼接列表 | 循环 `+=` | `' '.join(words)`✅（高效） |
| 字符判断 | `isdigit()` | `s.isdigit()` |
| 字符转数字 | `c - '0'` | `ord(c) - ord('0')` 或 `int(c)` |

## 五、AI 协作要点

**Python 字符串不可变！** 本课最重要的概念。Python中每次 `s += x` 都会创建一个全新的字符串对象。教学生在循环中构建字符串时用 `''.join(parts)`，并让 Trae 解释性能差异的原因。
