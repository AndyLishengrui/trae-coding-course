---

## 二、Python 工具箱

| 工具 | 作用 | 示例 |
|------|------|------|
| `//` | 整除 | `7 // 2` → `3` |
| `%` | 取模 | `7 % 2` → `1` |
| `divmod(a, b)` | 同时返回商和余数 | `divmod(7, 2)` → `(3, 1)` |
| `if/elif/else` | 条件分支 | `if x > 0:` |
| `and/or/not` | 逻辑运算 | `a > 0 and b > 0` |
| `a <= x <= b` | 链式比较（Python独有） | C++需要 `a <= x && x <= b` |

## 三、例题精讲

### 例题1：差（NQ007）

读入四个整数A、B、C、D，计算(A×B−C×D)。

```
C++: 声明 int a,b,c,d; 然后 scanf 读入
Python: a,b,c,d = map(int, input().split())
```

**对比要点：** Python 一行解包四个变量，C++ 需要逐个声明和读取。

### 例题2：钞票（NQ008）

读取一个整数表示金额，计算最少需要多少张100、50、20、10、5、2、1元的钞票。

```python
# Python 循环风格 — 消除重复代码
notes = [100, 50, 20, 10, 5, 2, 1]
for note in notes:
    count = n // note
    print(f"{count} nota(s) de R$ {note},00")
    n %= note
```

C++ 版本写了7段几乎相同的代码。Python 用一个循环和列表消除了重复。**这是AI辅助编程的核心思维：识别重复模式，用循环/数据结构消除重复。**

### 例题3：时间转换（NQ009）

读取一个整数（秒数），转换为 `时:分:秒` 格式。

```python
h, remainder = divmod(n, 3600)
m, s = divmod(remainder, 60)
```

## 四、练习

| 题号 | 题目 | 核心技能 | 库工具 |
|------|------|---------|--------|
| NQ010 | 倍数 | 取模判断 | `%` |
| NQ011 | 零食 | 多分支映射 | `dict`做映射表 |
| NQ012 | 区间 | 区间判断 | 链式比较 `a<=x<=b` |

**NQ011 教学重点：** 对比两种写法：

```python
# 写法A：模仿C++的if-else链
if code == 1: price = 4.0
elif code == 2: price = 4.5
# ...

# 写法B：Python dict映射（推荐）
prices = {1: 4.0, 2: 4.5, 3: 5.0, 4: 2.0, 5: 1.5}
price = prices[code]
```
