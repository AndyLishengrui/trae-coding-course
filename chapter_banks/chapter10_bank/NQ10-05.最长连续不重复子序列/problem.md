# NQ10-05：最长连续不重复子序列

> 题目来源：AcWing 799 | 第10章

---

## 题目描述
给定一个长度为n的整数序列，请找出最长的不包含重复数字的连续区间，输出它的长度。

数据范围：
1≤n≤100000

### 输入格式
第一行包含整数n。
第二行包含n个整数（均在0~100000范围内），表示整数序列。

### 输出格式
共一行，包含一个整数，表示最长的不包含重复数字的连续子序列的长度。

### 样例1
**输入：**
```
5
1 2 2 3 5
```
**输出：**
```
3
```
