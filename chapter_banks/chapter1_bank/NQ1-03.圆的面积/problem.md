# NQ1-03：圆的面积

> 题目来源：AcWing 604 | 第1章 程序设计的第一个脚印——变量、输入输出与顺序结构

---

## 题目描述
给定圆的半径r，计算圆的面积。π取3.14159。

### 输入格式
一个浮点数r，表示圆的半径。

### 输出格式
输出"A="后跟圆的面积，结果保留4位小数。

### 样例1
**输入：**
```
2.00
```
**输出：**
```
A=12.5664
```
