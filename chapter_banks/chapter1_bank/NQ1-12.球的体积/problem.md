## 题目描述
V=(4/3)πr³，π=3.14159。

### 输入格式
一个整数r，表示半径。

### 输出格式
"VOLUME = XXX.XXX"，保留3位小数。

### 样例1
**输入：**
```
3
```
**输出：**
```
VOLUME = 113.097
```
