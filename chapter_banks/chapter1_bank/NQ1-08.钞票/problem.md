# NQ1-08：钞票

## 题目描述
给定金额N，用最少的钞票数量支付。面额：100,50,20,10,5,2,1。

### 输入格式
一个整数N。

### 输出格式
第一行输出N。然后7行，按面额从大到小输出"X nota(s) de R$ Y,00"。

### 样例1
**输入：**
```
576
```
**输出：**
```
576
5 nota(s) de R$ 100,00
1 nota(s) de R$ 50,00
1 nota(s) de R$ 20,00
0 nota(s) de R$ 10,00
1 nota(s) de R$ 5,00
0 nota(s) de R$ 2,00
1 nota(s) de R$ 1,00
```
