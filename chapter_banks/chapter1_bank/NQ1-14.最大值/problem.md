# NQ1-14：最大值

> 题目来源：AcWing 614 | 第1章 程序设计的第一个脚印——变量、输入输出与顺序结构

---

## 题目描述
输入三个整数a、b、c，输出其中的最大者。

### 输入格式
一行，三个整数，用空格隔开。

### 输出格式
一个整数，即三个数中的最大值。

### 样例1
**输入：**
```
7 14 106
```
**输出：**
```
106
```
