# NQ1-10：简单乘积

> 题目来源：AcWing 605 | 第1章 程序设计的第一个脚印——变量、输入输出与顺序结构

---

## 题目描述
读取两个整数，输出"PROD = "后跟它们的乘积。

### 输入格式
两行，每行一个整数。

### 输出格式
输出"PROD = X"。

### 样例1
**输入：**
```
3
9
```
**输出：**
```
PROD = 27
```
