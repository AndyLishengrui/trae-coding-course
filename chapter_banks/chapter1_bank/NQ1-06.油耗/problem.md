## 题目描述
输入行驶距离(km)和消耗汽油量(L)，计算每升汽油行驶的公里数。

### 输入格式
两行：距离(float)和汽油量(float)。

### 输出格式
保留3位小数，后跟" km/l"。

### 样例1
**输入：**
```
500
35.0
```
**输出：**
```
14.286 km/l
```
