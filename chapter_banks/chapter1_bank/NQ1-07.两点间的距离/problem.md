# NQ1-07：两点间的距离

> 题目来源：AcWing 616 | 第1章 程序设计的第一个脚印——变量、输入输出与顺序结构

## 题目描述
给定两点坐标P1(x1,y1)和P2(x2,y2)，计算欧几里得距离。

### 输入格式
一行，四个浮点数x1 y1 x2 y2。

### 输出格式
距离，保留4位小数。

### 样例1
**输入：**
```
1.0 7.0 5.0 9.0
```
**输出：**
```
4.4721
```
