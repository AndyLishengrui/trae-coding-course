# NQ1-01：A + B

> 题目来源：AcWing 1 | 第1章 程序设计的第一个脚印——变量、输入输出与顺序结构

---

## 题目描述
输入两个整数A和B，计算它们的和。

### 输入格式
一行，两个整数A和B，用空格隔开。

### 输出格式
一个整数，即A+B的结果。

### 样例1
**输入：**
```
3 4
```
**输出：**
```
7
```
