## 题目描述
读取四个整数A、B、C、D，计算A×B−C×D的结果。

### 输入格式
一行，四个整数A、B、C、D，用空格隔开。

### 输出格式
输出"DIFERENCA = "后跟计算结果。

### 样例1
**输入：**
```
5 6 7 8
```
**输出：**
```
DIFERENCA = -26
```
