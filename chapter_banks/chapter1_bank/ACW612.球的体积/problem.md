# NQ012：球的体积

> 题目来源：AcWing 612 | 题目ID：ACW612 | 第1章 程序设计的第一个脚印

## 题目描述
V=(4/3)πr³，π=3.14159。

### 输入格式
一个整数r，表示半径。

### 输出格式
"VOLUME = XXX.XXX"，保留3位小数。

### 样例
**输入：**
```
3
```
**输出：**
```
VOLUME = 113.097
```

## 解题思路
V = (4/3)πr³。注意C++中4/3=1（整数除法），必须写4.0/3.0。

## 编程技巧
C++中整数除法的陷阱：4/3=1而不是1.333。必须写成4.0/3.0。Python无此问题。

## 参考代码

### C++
```cpp
#include <cstdio>
int main() { int r; scanf("%d",&r); printf("VOLUME = %.3lf\n",4.0/3.0*3.14159*r*r*r); return 0; }
```

### Python
```python
r = int(input())
print(f"VOLUME = {4.0/3.0 * 3.14159 * r**3:.3f}")
```
