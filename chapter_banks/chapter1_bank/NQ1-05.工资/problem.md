## 题目描述
输入员工编号（整数）、月工作时数（整数）和时薪（浮点数），计算工资总额。

### 输入格式
三行：编号、时数、时薪。

### 输出格式
第一行"NUMBER = X"，第二行"SALARY = U$ XX.XX"。

### 样例1
**输入：**
```
25
100
5.50
```
**输出：**
```
NUMBER = 25
SALARY = U$ 550.00
```
