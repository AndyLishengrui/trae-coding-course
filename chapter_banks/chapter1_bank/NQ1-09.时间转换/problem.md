## 题目描述
将总秒数N转换为HH:MM:SS格式。

### 输入格式
一个整数N，表示总秒数。

### 输出格式
HH:MM:SS格式的时间。

### 样例1
**输入：**
```
556
```
**输出：**
```
0:9:16
```
