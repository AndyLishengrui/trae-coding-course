## 题目描述
计算三个图形面积：直角三角形A*C/2、圆π*C²、梯形(A+B)*C/2。π=3.14159。

### 输入格式
一行，三个浮点数A、B、C。

### 输出格式
三行：TRIANGULO: X / CIRCULO: X / TRAPEZIO: X，各保留3位小数。

### 样例1
**输入：**
```
3.0 4.0 5.2
```
**输出：**
```
TRIANGULO: 7.800
CIRCULO: 84.949
TRAPEZIO: 18.200
```
