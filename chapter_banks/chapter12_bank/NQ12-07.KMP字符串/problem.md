# NQ12-07：KMP字符串

> 题目来源：AcWing 831 | 第12章

---

## 题目描述
给定一个模式串S，以及一个模板串P，所有字符串中只包含大小写英文字母以及阿拉伯数字。
模板串P在模式串S中多次作为子串出现。
求出模板串P在模式串S中所有出现的位置的起始下标。
数据范围：
1≤N≤10^5
1≤M≤10^6

### 输入格式
第一行输入整数N，表示字符串P的长度。
第二行输入字符串P。
第三行输入整数M，表示字符串S的长度。
第四行输入字符串S。

### 输出格式
共一行，输出所有出现位置的起始下标（下标从0开始计数），整数之间用空格隔开。

### 样例1
**输入：**
```
3
aba
5
ababa
```
**输出：**
```
0 2
```
