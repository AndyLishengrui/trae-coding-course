# NQ12-05：单调栈

> 题目来源：AcWing 830 | 第12章

---

## 题目描述
给定一个长度为N的整数数列，输出每个数左边第一个比它小的数，如果不存在则输出-1。

1≤N≤10^5
1≤数列中元素≤10^9

### 输入格式
第一行包含整数N，表示数列长度。
第二行包含N个整数，表示整数数列。

### 输出格式
共一行，包含N个整数，其中第i个数表示第i个数的左边第一个比它小的数，如果不存在则输出-1。

### 样例1
**输入：**
```
5
3 4 2 7 5
```
**输出：**
```
-1 3 -1 2 2
```
