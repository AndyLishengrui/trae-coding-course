# NQ4-09：简单斐波那契

> 题目来源：AcWing 717 | 第4章

---

## 题目描述
计算斐波那契数列的第N项。N从0开始：F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)。

### 输入格式
一个整数N。

### 输出格式
第N项的值。

### 样例1
**输入：**
```
4
```
**输出：**
```
3
```
