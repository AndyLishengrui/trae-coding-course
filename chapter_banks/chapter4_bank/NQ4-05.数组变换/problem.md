# NQ4-05：数组变换

> 题目来源：AcWing 740 | 第4章

---

## 题目描述
输入一个长度为 20 的整数数组 N，将整个数组翻转，使得第一个元素成为最后一个元素，依此类推。输出翻转后的数组。

### 输入格式
输入包含 20 个整数，每个整数占一行，数据范围：-100 ≤ N[i] ≤ 100

### 输出格式
输出数组中所有元素，每个元素占一行，格式为N[i] = x，其中 i 从 0 开始。

### 样例1
**输入：**
```
0
-5
63
23
... (共20个数)

```
**输出：**
```
N[0] = 23
N[1] = 63
... 
N[18] = -5
N[19] = 0

```
