# NQ4-12：质数

> 题目来源：AcWing 726 | 第4章

---

## 题目描述
给定N，输出2到N之间所有的质数（素数）。质数指大于1且只有1和自身两个因子的数。

### 输入格式
一个整数N。

### 输出格式
每行一个质数。

### 样例1
**输入：**
```
10
```
**输出：**
```
2
3
5
7
```
