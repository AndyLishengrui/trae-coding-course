# NQ13-06：图中点的层次

> 题目来源：AcWing 847 | 第13章

---

## 题目描述
给定一个n个点m条边的有向图，图中可能存在重边和自环。
所有边的长度都是1，点的编号为1~n。
请你求出1号点到n号点的最短距离，如果从1号点无法走到n号点，输出-1。
数据范围：1≤n,m≤10^5

### 输入格式
第一行包含两个整数n和m。
接下来m行，每行包含两个整数a和b，表示存在一条从a走到b的长度为1的边。

### 输出格式
输出一个整数，表示1号点到n号点的最短距离。

### 样例1
**输入：**
```
4 5
1 2
2 3
3 4
1 3
1 4
```
**输出：**
```
1
```
