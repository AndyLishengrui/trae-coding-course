# NQ9-06：数的三次方根

> 题目来源：AcWing 790 | 第9章

---

## 题目描述
给定一个浮点数n，求它的三次方根。

数据范围:−10000≤n≤10000

### 输入格式
共一行，包含一个浮点数n。

### 输出格式
共一行，包含一个浮点数，表示问题的解。
注意，结果保留6位小数。

### 样例1
**输入：**
```
1000.00
```
**输出：**
```
10.000000
```
