# NQ9-07：菱形

> 题目来源：AcWing 727 | 第9章

---

## 题目描述
输入一个奇数n，输出一个由*构成的n阶实心菱形。菱形中心为第(n+1)/2行，每行星号数量以中心对称。

### 输入格式
一个奇数n。

### 输出格式
输出一个由*构成的n阶实心菱形。

### 样例1
**输入：**
```
5
```
**输出：**
```
  *
 ***
*****
 ***
  *
```
