# NQ6-02：字符串中的数字个数

> 题目来源：AcWing 761 | 第6章

---

## 题目描述
输入一行字符（长度不超过 100），请你统计一下其中的数字字符的个数。

### 输入格式
输入一行字符。字符中可能包含空格。

### 输出格式
输出一个整数，表示该行字符中数字字符的个数。

### 样例1
**输入：**
```
I am 18 years old this year.

```
**输出：**
```
2

```
