# NQ6-09：信息加密

> 题目来源：AcWing 767 | 第6章

---

## 题目描述
对给定的字符串进行加密处理，加密规则如下：
1. 小写字母：a→b, b→c, …, z→a；
2. 大写字母：A→B, B→C, …, Z→A；
3. 数字：0→1, 1→2, …, 9→0；
4. 其他字符不变。
输出加密后的字符串。

### 输入格式
输入共一行，包含一个字符串，注意字符串中可能包含空格。
数据范围：字符串长度不超过100。

### 输出格式
输出一行，即加密后的字符串。

### 样例1
**输入：**
```
Hello! How are you!

```
**输出：**
```
Ifmmp! Ipx bsf zpv!

```
