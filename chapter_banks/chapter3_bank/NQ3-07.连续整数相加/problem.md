# NQ3-07：连续整数相加

> 题目来源：AcWing 720 | 第3章

---

## 题目描述
给定起始整数A和个数N（N>0），计算从A开始的N个连续整数的和。注意：输入的第二行可能有多余的负数或零，需要一直读入直到遇到第一个正数作为N。

### 输入格式
第一行：整数A。第二行：若干整数，其中第一个大于0的数是N。

### 输出格式
从A开始N个连续整数的和。

### 样例1
**输入：**
```
3
-5 0 -3 4 -1
```
**输出：**
```
18
```
