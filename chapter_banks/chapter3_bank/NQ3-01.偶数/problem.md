# NQ3-01：偶数

> 题目来源：AcWing 708 | 第3章

---

## 题目描述
小鲁想列出从2到100之间的所有偶数。请你写一个程序，按顺序每行输出一个偶数。这是for循环最基础的应用。

### 输入格式
无输入。

### 输出格式
每行一个偶数，从2到100。

### 样例1
**输入：**
```
(无)
```
**输出：**
```
2
4
6
...
100
```
