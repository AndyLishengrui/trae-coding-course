# NQ3-04：连续奇数的和1

> 题目来源：AcWing 714 | 第3章

---

## 题目描述
给定两个整数X和Y，计算它们之间（不含X和Y）所有奇数的和。

### 输入格式
一行，两个整数X和Y。

### 输出格式
一个整数，表示奇数和。

### 样例1
**输入：**
```
6 -5
```
**输出：**
```
5
```
