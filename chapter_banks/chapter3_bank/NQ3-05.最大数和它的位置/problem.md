# NQ3-05：最大数和它的位置

> 题目来源：AcWing 716 | 第3章

---

## 题目描述
小鲁有一组数据，他想找到最大值以及它第一次出现的位置。给定N和N个整数，找出最大值和位置。

### 输入格式
第一行整数N。第二行N个整数。

### 输出格式
第一行输出最大值。第二行输出位置（从1开始）。

### 样例1
**输入：**
```
5
3 2 5 1 4
```
**输出：**
```
5
3
```
