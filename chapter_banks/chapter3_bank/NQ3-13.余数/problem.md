# NQ3-13：余数

> 题目来源：AcWing 715 | 第3章

---

## 题目描述
给定一个整数N。对于1到10000中的每个整数，如果它除以N的余数为2，则输出这个数。

### 输入格式
一个整数N。

### 输出格式
每个满足条件的数一行。

### 样例1
**输入：**
```
13
```
**输出：**
```
2
15
28
41
...
```
