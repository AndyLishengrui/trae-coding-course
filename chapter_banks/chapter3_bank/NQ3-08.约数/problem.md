# NQ3-08：约数

> 题目来源：AcWing 724 | 第3章

---

## 题目描述
小鲁在数学课上学了约数的概念。给定一个正整数N，输出它的所有正约数（从小到大，每行一个）。

### 输入格式
一个正整数N。

### 输出格式
每行一个约数，从小到大。

### 样例1
**输入：**
```
6
```
**输出：**
```
1
2
3
6
```
