# NQ7-08：递归求斐波那契数列

> 题目来源：AcWing 820 | 第7章

---

## 题目描述
请使用递归的方式求斐波那契数列的第 n 项，下标从 1 开始。
斐波那契数列：1, 1, 2, 3, 5 ...，这个数列从第 3 项开始，每一项都等于前两项之和。

### 输入格式
共一行，包含整数 n。
数据范围：1 ≤ n ≤ 30

### 输出格式
共一行，包含一个整数，表示斐波那契数列的第 n 项。

### 样例1
**输入：**
```
4

```
**输出：**
```
3

```
