# NQ7-01：n的阶乘

> 题目来源：AcWing 804 | 第7章

---

## 题目描述
输入一个整数n，请你编写一个函数 int fact(int n)，计算并输出n的阶乘。

### 输入格式
共一行，包含一个整数n。

### 输出格式
共一行，包含一个整数表示n的阶乘的值。

### 样例1
**输入：**
```
3
```
**输出：**
```
6
```
