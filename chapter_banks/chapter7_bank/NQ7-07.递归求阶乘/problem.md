# NQ7-07：递归求阶乘

> 题目来源：AcWing 819 | 第7章

---

## 题目描述
请使用递归的方式求n的阶乘。递归公式：fact(n)=n×fact(n−1)，fact(1)=1。

### 输入格式
共一行，包含一个整数n。

### 输出格式
共一行，包含一个整数，表示n的阶乘的值。

### 样例1
**输入：**
```
5
```
**输出：**
```
120
```
