# NQ7-09：跳台阶

> 题目来源：AcWing 821 | 第7章

---

## 题目描述
一个楼梯有 n 级台阶，每次可走一级或两级，求从第 0 级走到第 n 级的方案数。

### 输入格式
一行一个整数 n。
数据范围：1 ≤ n ≤ 15

### 输出格式
一个整数表示方案数。

### 样例1
**输入：**
```
5

```
**输出：**
```
8

```
