# NQ11-02：高精度减法

> 题目来源：AcWing 792 | 第11章

---

## 题目描述
给定两个正整数，计算它们的差，计算结果可能为负数。

1≤整数长度≤100000

### 输入格式
共两行，每行包含一个整数。

### 输出格式
共一行，包含所求的差。

### 样例1
**输入：**
```
32
11
```
**输出：**
```
21
```
