# NQ11-05：高精度除法

> 题目来源：AcWing 794 | 第11章

---

## 题目描述
给定两个非负整数A，B，请你计算 A / B的商和余数。

数据范围：
1≤A的长度≤100000,
1≤B≤10000
B 一定不为0

### 输入格式
共两行，第一行包含整数A，第二行包含整数B。

### 输出格式
共两行，第一行输出所求的商，第二行输出所求余数。

### 样例1
**输入：**
```
7
2
```
**输出：**
```
3
1
```
