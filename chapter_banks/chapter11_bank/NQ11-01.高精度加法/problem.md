# NQ11-01：高精度加法

> 题目来源：AcWing 791 | 第11章

---

## 题目描述
给定两个正整数，计算它们的和。

数据范围：1≤整数长度≤100000

### 输入格式
共两行，每行包含一个整数。

### 输出格式
共一行，包含所求的和。

### 样例1
**输入：**
```
12
23
```
**输出：**
```
35
```
