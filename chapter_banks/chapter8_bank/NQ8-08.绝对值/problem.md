# NQ8-08：绝对值

> 题目来源：AcWing 810 | 第8章

---

## 题目描述
输入一个整数x，请你编写一个函数 int abs(int x)，输出x的绝对值。

### 输入格式
共一行，包含一个整数x。

### 输出格式
共一行，包含x的绝对值。

### 样例1
**输入：**
```
-5
```
**输出：**
```
5
```
