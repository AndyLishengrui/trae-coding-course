# NQ8-04：斐波那契数列

> 题目来源：AcWing 21 | 第8章

---

## 题目描述
输入一个整数n，要求斐波那契数列的第n项。
假定从0开始，第0项为0。

### 输入格式
输入一个整数n。
数据范围：0 ≤ n ≤ 39

### 输出格式
返回斐波那契数列的第n项。

### 样例1
**输入：**
```
5

```
**输出：**
```
5

```
