# NQ8-07：三元组排序

> 题目来源：AcWing 862 | 第8章

---

## 题目描述
给定N个三元组(x,y,z)，每个三元组包含一个整数x、一个整数y和一个字符串z。按照x从小到大的顺序输出所有三元组。数据保证不同三元组的x值互不相同。

### 输入格式
第一行包含整数N。接下来N行，每行包含一个整数x、一个整数y和一个由小写字母组成的字符串z。

### 输出格式
共N行，按照x从小到大的顺序，每行输出一个三元组。

### 样例1
**输入：**
```
3
1 2 abc
3 4 def
2 1 ghi
```
**输出：**
```
1 2 abc
2 1 ghi
3 4 def
```
