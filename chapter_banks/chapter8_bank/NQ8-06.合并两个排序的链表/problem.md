# NQ8-06：合并两个排序的链表

> 题目来源：AcWing 36 | 第8章

---

## 题目描述
输入两个递增排序的链表，合并这两个链表并使新链表中的结点仍然是按照递增排序的。

### 输入格式
输入两个链表。
数据范围：链表长度[0, 500]

### 输出格式
输出合并后的链表。

### 样例1
**输入：**
```
1->3->5
2->4->5

```
**输出：**
```
1->2->3->4->5->5

```
