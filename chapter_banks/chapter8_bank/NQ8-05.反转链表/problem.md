# NQ8-05：反转链表

> 题目来源：AcWing 35 | 第8章

---

## 题目描述
定义一个函数，输入一个链表的头结点，反转该链表并输出反转后链表的头结点。

### 输入格式
输入一个链表的头结点。
数据范围：链表长度[0, 30]。

### 输出格式
输出反转后的链表的头结点。

### 样例1
**输入：**
```
1->2->3->4->5->NULL

```
**输出：**
```
5->4->3->2->1->NULL

```

### 样例2
**输入：**
```
10->74->87->19->NULL

```
**输出：**
```
19->87->74->10->NULL

```
