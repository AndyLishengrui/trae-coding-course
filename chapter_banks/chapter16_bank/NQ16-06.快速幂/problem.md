# NQ16-06：快速幂

> 题目来源：AcWing 875 | 第16章

---

## 题目描述
给定n组ai, bi, pi，对于每组数据，求出a^b i mod p i的值。

### 输入格式
第一行包含整数n。
接下来n行，每行包含三个整数ai, bi, pi。
数据范围
1≤n≤100000
1≤ai, bi, pi≤2×10^9

### 输出格式
对于每组数据，输出一个结果，表示a^b i mod p i的值。
每个结果占一行。

### 样例1
**输入：**
```
5
1326 8312 7553
1550 7708 3792
500 6795 6235
6880 7895 7532
1904 9984 7790
```
**输出：**
```
2613
3520
1785
7244
5346
```
