# NQ2-13：税

> 题目来源：AcWing 672 | 第2章

---

## 题目描述
小鲁工作了，需要计算个人所得税。税率分档：0-2000免税，2000.01-3000税率8%，3000.01-4500税率18%，4500以上税率28%。注意是分段计税。

### 输入格式
一个浮点数，表示月收入。

### 输出格式
如免税输出"Isento"，否则输出"R$ XX.XX"（保留2位小数）。

### 样例1
**输入：**
```
3002.00
```
**输出：**
```
R$ 80.36
```
