# NQ2-10：点的坐标

> 题目来源：AcWing 662 | 第2章

---

## 题目描述
小鲁在坐标系上画了一个点P(x,y)。请判断这个点在第几象限，或者在坐标轴上（Eixo X / Eixo Y），或者在原点（Origem）。

### 输入格式
一行，两个浮点数x和y。

### 输出格式
输出"Q1"、"Q2"、"Q3"、"Q4"、"Origem"、"Eixo X"或"Eixo Y"。

### 样例1
**输入：**
```
4.5 -2.2
```
**输出：**
```
Q4
```
