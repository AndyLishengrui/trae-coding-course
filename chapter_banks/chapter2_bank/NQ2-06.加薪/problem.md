# NQ2-06：加薪

> 题目来源：AcWing 669 | 第2章

---

## 题目描述
公司年终调薪，小鲁想知道自己的新工资。根据当前工资所在的区间，涨幅不同：0-400涨15%，400.01-800涨12%，800.01-1200涨10%，1200.01-2000涨7%，2000以上涨4%。

### 输入格式
一个浮点数，表示当前工资。

### 输出格式
三行：新工资、涨薪金额、涨幅百分比（整数%）。

### 样例1
**输入：**
```
400.00
```
**输出：**
```
Novo salario: 460.00
Reajuste ganho: 60.00
Em percentual: 15 %
```
