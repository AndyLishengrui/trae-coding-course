# NQ2-04：三角形

> 题目来源：AcWing 664 | 第2章

---

## 题目描述
小鲁在几何课上学了三角形的判定。给定三个浮点数A、B、C，判断它们能否构成三角形。如果能，计算周长；如果不能，计算以A、B为底的梯形面积。

### 输入格式
一行，三个浮点数A、B、C。

### 输出格式
能构成三角形："Perimetro = XX.X"（周长，1位小数）。不能："Area = XX.X"（梯形面积(A+B)*C/2）。

### 样例1
**输入：**
```
6.0 4.0 2.0
```
**输出：**
```
Area = 10.0
```
