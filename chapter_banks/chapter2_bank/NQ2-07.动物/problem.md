# NQ2-07：动物

> 题目来源：AcWing 670 | 第2章

---

## 题目描述
小鲁在生物课上学了动物分类。根据三个特征（脊椎/无脊椎、哺乳/鸟/爬虫/昆虫、食性），判断动物的种类名称。这是一个嵌套条件判断的经典题。

### 输入格式
三行：第一行"vertebrado"或"invertebrado"；第二、三行根据第一行不同。

### 输出格式
动物名称（如aguia, pomba, homem, vaca, pulga, lagarta, sanguessuga, minhoca）。

### 样例1
**输入：**
```
vertebrado
mamifero
onivoro
```
**输出：**
```
homem
```
