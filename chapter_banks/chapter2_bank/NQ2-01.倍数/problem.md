# NQ2-01：倍数

> 题目来源：AcWing 665 | 第2章

---

## 题目描述
小鲁在数学课上学了倍数和约数的概念。给定两个整数A和B，判断它们是否互为倍数关系（即A能被B整除，或B能被A整除）。

### 输入格式
一行，两个整数A和B。

### 输出格式
如果互为倍数，输出"Sao Multiplos"；否则输出"Nao sao Multiplos"。

### 样例1
**输入：**
```
6 24
```
**输出：**
```
Sao Multiplos
```
