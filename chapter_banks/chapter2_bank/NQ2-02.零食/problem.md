# NQ2-02：零食

> 题目来源：AcWing 660 | 第2章

---

## 题目描述
小鲁去小卖部买零食。每种零食有编号（1到5）和单价。给定零食编号和数量，请计算总价。

### 输入格式
一行，两个整数：零食编号X（1-5）和数量Y。

### 输出格式
输出"Total: R$ "后跟总价（保留2位小数）。

### 样例1
**输入：**
```
3 2
```
**输出：**
```
Total: R$ 10.00
```
