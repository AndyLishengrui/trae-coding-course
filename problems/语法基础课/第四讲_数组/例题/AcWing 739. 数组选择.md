# AcWing 739. 数组选择 — 数组选择

**难度:** 中等 | **时间限制:** 1000ms | **内存限制:** 256MB

> 原题链接: https://www.acwing.com/problem/content/739/

## 题目描述

输入一个长度为 100 的数组 A，请你按顺序输出其中不大于 10 的所有元素。

### 输入格式

输入 100 个数，每个数占一行，可能为整数或浮点数。数据范围：`-100 ≤ A[i] ≤ 100`

### 输出格式

按顺序输出数组中所有不大于 10 的元素，每个元素占一行，格式为 `A[i] = x`，其中 i 为原数组中对应元素的下标，x 保留一位小数。

### 样例

**输入:**
```
0
-5
63
-8.5
... (共100个数)
```

**输出:**
```
A[0] = 0.0
A[1] = -5.0
A[3] = -8.5
... (仅输出不大于10的元素)
```

### 提示

注意保留一位小数的输出格式，且仅输出不大于10的元素。

来源：语法题

## AC代码

```cpp
#include <cstdio>

int main()
{
  double a[100];

  for (int i = 0; i < 100; i ++ ) scanf("%lf", &a[i]);

  for (int i = 0 ; i < 100; i ++ )
      if (a[i] <= 10)
          printf("A[%d] = %.1lf\n", i, a[i]);

  return 0;        
}
```
