# NQ004：平均数1

> 题目来源：AcWing 606 | 题目ID：ACW606 | 第1章 程序设计的第一个脚印

## 题目描述
读取两个学生的成绩A和B，A的权重3.5，B的权重7.5，计算加权平均分。

### 输入格式
两行，每行一个浮点数，分别表示A和B。

### 输出格式
输出"MEDIA = "后跟加权平均分，保留5位小数。

### 样例
**输入：**
```
5.0
7.1
```
**输出：**
```
MEDIA = 6.43182
```

## 解题思路
加权平均公式：(A×3.5 + B×7.5) / (3.5+7.5)。分母是权重之和=11，不是2。保留5位小数。

## 编程技巧
C++中所有浮点字面量默认double。Python的/总是返回浮点数，无需担心整数除法。

## 参考代码

### C++
```cpp
#include <cstdio>
int main() { double a,b; scanf("%lf%lf",&a,&b); printf("MEDIA = %.5lf\n",(a*3.5+b*7.5)/11); return 0; }
```

### Python
```python
a = float(input())
b = float(input())
print(f"MEDIA = {(a * 3.5 + b * 7.5) / 11:.5f}")
```
