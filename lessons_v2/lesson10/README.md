# 第10课：前缀和、差分与双指针

> **课时：** 2小时 | **题目：** 7题（4例题+3练习） | **阶段：** 核心算法 | **NQ108-NQ114**

## 一、教学目标

1. 理解**预处理**思想：先花 O(n) 时间计算，后续每次查询 O(1)
2. 掌握一维/二维前缀和与差分的公式推导
3. 双指针滑动窗口：将 O(n²) 暴力优化到 O(n)

## 二、核心公式

```
一维前缀和：S[i] = S[i-1] + a[i]
区间和：sum[l..r] = S[r] - S[l-1]

二维前缀和：S[i][j] = S[i-1][j] + S[i][j-1] - S[i-1][j-1] + a[i][j]
子矩阵和：(x1,y1)→(x2,y2) = S[x2][y2] - S[x1-1][y2] - S[x2][y1-1] + S[x1-1][y1-1]

一维差分（区间[l,r]加c）：B[l] += c, B[r+1] -= c
二维差分（子矩阵加c）：在四个角打标记，最后求前缀和还原

双指针模板：
for (i = 0, j = 0; i < n; i++) {
    while (j < i && check(i, j)) j++;
    // 每步 O(1) 均摊
}
```
