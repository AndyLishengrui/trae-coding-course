# 第5课：多维数组与矩阵模式

> **课时：** 2小时 | **题目：** 12题（5例题+7练习） | **阶段：** 语法基础

## 一、教学目标

1. 掌握二维数组的创建和遍历（C++ `vector<vector<T>>` vs Python 嵌套 `list`）
2. 学会按区域（三角形、矩形）遍历矩阵的条件控制
3. 理解矩阵填充的数学公式思维（平方矩阵 I/II/III）
4. 蛇形矩阵：方向数组 + 循环填充的经典模式

## 二、Python 二维数组注意事项

```python
# ✅ 正确：每个子列表独立
matrix = [[0] * m for _ in range(n)]

# ❌ 错误：所有行指向同一个列表对象！
matrix = [[0] * m] * n
# 修改 matrix[0][0] 会同时修改所有行！
```

## 三、矩阵模式速查

| 区域 | 条件 | 说明 |
|------|------|------|
| 右上半 | `j > i` | 不包括对角线 |
| 左上半 | `j < n-1-i` | 反对角线上方 |
| 上方区域 | `i < j and i+j < n-1` | 去掉左右三角 |
| 平方矩阵 I | `min(i,j,n-1-i,n-1-j)+1` | 到四条边的最近距离 |
| 平方矩阵 II | `abs(i-j)+1` | 到对角线的距离 |
| 平方矩阵 III | `2**(i+j)` 再求 | 2 的幂模式 |
| 蛇形矩阵 | 方向数组 `[(0,1),(1,0),(0,-1),(-1,0)]` | 撞墙转向 |

**教学点：** 平方矩阵 I/II 展示了用数学代替模拟的力量。让 AI 生成两种解法（模拟填充 vs 数学公式），对比复杂度。
