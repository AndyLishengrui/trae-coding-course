## 二、C++ vector vs Python list

| 操作 | C++ `vector<int>` | Python `list` |
|------|-------------------|---------------|
| 创建定长 | `vector<int> a(n, 0)` | `[0] * n` |
| 访问 | `a[i]` | `a[i]`（支持负数索引 `a[-1]`） |
| 遍历 | `for(int x : a)` | `for x in a:` |
| 带索引 | `for(int i=0;i<a.size();i++)` | `for i, v in enumerate(a):` |
| 翻转 | `reverse(a.begin(), a.end())` | `a[::-1]` 或 `a.reverse()` |
| 条件筛选 | 循环+`push_back` | `[x for x in a if cond]` |
| 最值 | `*min_element` / `*max_element` | `min(a)` / `max(a)` |

接第3课的优化思想。用数组视角重新审视：
- 完全数：可以预先计算因子表
- 质数：朴素判质 vs 埃拉托色尼筛法（首次接触"用空间换时间"）

### 斐波那契递推 — DP 思想萌芽

```python
# 迭代递推（O(n) 时间，O(1) 空间）
a, b = 0, 1
for _ in range(n):
    a, b = b, a + b

# 对比：递归（O(2^n) 时间，大量重复计算）
def fib(n):
    if n <= 1: return n
    return fib(n-1) + fib(n-2)
```

**教学点：** 同一个问题，迭代比递归快得多。为什么会这样？（引出第7课的记忆化递归）
