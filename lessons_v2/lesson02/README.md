# 第2课：选择结构——条件判断与分支

> **课时：** 2小时 | **题目：** 14题（7例题+7练习） | **阶段：** 语法基础

## 一、教学目标

1. 掌握 `if/else if/else`（C++）和 `if/elif/else`（Python）
2. 学会用**数据驱动**替代**逻辑堆叠**（dict 映射表 > 长 if-else 链）
3. 理解区间判断、时间循环判断、三角形判定等经典模式
4. Python 链式比较 `a <= x <= b` 的优势

## 二、Python 工具箱

| 工具 | 作用 | 示例 |
|------|------|------|
| `if/elif/else` | 条件分支 | `if x > 0: ... elif x < 0: ...` |
| `a <= x <= b` | 链式比较（Python 独有） | C++ 需要 `a <= x && x <= b` |
| `dict` 映射 | 替代 long if-else | `{61: "Brasilia", 71: "Salvador"}` |
| `dict.get(k, default)` | 安全取值 | `ddd.get(x, "DDD nao cadastrado")` |
| `a, b = b, a` | 交换变量 | 无需临时变量，元组解包 |
| `sorted([a,b,c])` | 排序后简化判断逻辑 | 三角形类型题的核心技巧 |

## 三、关键教学案例

### NQ016: DDD 映射 — 本课核心技巧

```python
# ❌ C++ 风格：8 个 if-elif 分支
if x == 61: print("Brasilia")
elif x == 71: print("Salvador")
# ... 重复 6 次

# ✅ Python 风格：dict 映射表（O(1) 查找）
ddd = {61: "Brasilia", 71: "Salvador", 11: "Sao Paulo",
       21: "Rio de Janeiro", 32: "Juiz de Fora",
       19: "Campinas", 27: "Vitoria", 31: "Belo Horizonte"}
print(ddd.get(x, "DDD nao cadastrado"))
```

**教学点：** 当看到大量 if-elif 堆叠时，第一反应应该是"能不能用表驱动？"。这个习惯能从根本上提升代码质量。

### NQ020: 三角形类型 — 从一般到特殊

排序后降序排列三个边 `a ≥ b ≥ c`，然后按顺序判断：
1. `a >= b + c` → 不能构成三角形
2. `a² == b² + c²` → 直角三角形
3. `a² > b² + c²` → 钝角三角形
4. `a² < b² + c²` → 锐角三角形
5. `a == b == c` → 等边三角形（锐角的特殊情况）
6. `a == b or b == c` → 等腰三角形

**教学点：** 先排序是简化判断逻辑的关键。让 AI 比较"先排序再判断"和"不排序直接判断"两份代码的可读性。
