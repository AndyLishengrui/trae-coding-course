## 二、Python 工具箱（本课新引入）

| 工具 | 作用 | C++ 等价 | 示例 |
|------|------|---------|------|
| `input()` | 读取一行输入 | `cin >>` / `scanf()` | `s = input()` |
| `print()` | 输出 | `cout <<` / `printf()` | `print("Hello")` |
| `int()` / `float()` | 类型转换 | 声明时指定 | `int("42")` → 42 |
| `map(int, ...)` | 批量转换 | 逐个声明 | `a,b = map(int, input().split())` |
| `f"{x:.4f}"` | 格式化输出 | `printf("%.4lf", x)` | `f"A={area:.4f}"` |
| `math.sqrt()` | 平方根 | `sqrt()` | `import math` 后使用 |
| `max()` / `abs()` | 最值/绝对值 | `max()` / `abs()` | Python 内置 |

**双语言要点：** C++ 需要 `#include`、声明类型、`main()` 函数。Python 直接写逻辑。Python 的 `int` 无限大，`float` 是双精度。

## 三、例题精讲

### NQ001-002: 基本输入输出
```python
# Python: 一行解包
a, b = map(int, input().split())
print(a + b)
```
```cpp
// C++: 声明类型
int a, b; cin >> a >> b;
cout << a + b << endl;
```

### NQ008: 钞票（整除取模）
C++ 写了7段重复的 `n /= 100; n %= 100`。Python 用列表+循环消除重复——**这是本课最重要的工程思维。**

### NQ014: 最大值
`max(a, b, c)` 一行即可。C++ 中 `max({a, b, c})`（C++11）。
