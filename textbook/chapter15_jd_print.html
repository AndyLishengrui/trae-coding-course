JD155：一剑一鞘
简单AcWing 2 | JD155

华山脚下，试剑台前。西域刀客赫连铁拔出背上唯一的刀鞘，鞘中却藏着N柄短刀，每柄有重量和锋芒。刀鞘容量有限——选哪些刀，才能让锋芒之和最大？

李少白拔剑上前。梁嘉峰低声道："每柄刀只能选一次——01背包。逆序遍历容量，dp[j] = max(dp[j], dp[j-v]+w)。"

李少白深吸一口气，提笔写下。赫连铁看了答案，缓缓点头："第一关，过了。"

输入格式

第一行两个整数N和V。接下来N行每行两个整数v和w。

输出格式

一行，最大价值。

输入样例
4 5 1 2 2 4 3 4 4 5
输出样例
8
解题思路：

01背包：dp[j] = max(dp[j], dp[j-v[i]]+w[i])，逆序遍历j。

算法图解：DP表填充过程

样例：4个物品，背包容量5

物品:    v(体积)  w(价值)
  1        1       2
  2        2       4
  3        3       4
  4        4       5

f[i][j]的含义：从前i个物品中选，总体积不超过j时的最大价值

         容量j →   0    1    2    3    4    5
物品i ↓
  0（无物品）      0    0    0    0    0    0     ← 基础情况
  1 (v=1,w=2)     0    2    2    2    2    2     ← 只有物品1，容量≥1时都能装
  2 (v=2,w=4)     0    2    4    6    6    6     ← 加入物品2
  3 (v=3,w=4)     0    2    4    6    6    6     ← 加入物品3
  4 (v=4,w=5)     0    2    4    6    6    8     ← 加入物品4，但最优解不变

答案: f[4][5] = 8

关键转移方程：f[i][j] = max(f[i-1][j], f[i-1][j-v[i]]+w[i])

含义：对于第i个物品，有两种选择——

(1) 不选第i个物品 → f[i][j] = f[i-1][j]（继承上一行）

(2) 选第i个物品 → f[i][j] = f[i-1][j-v[i]]+w[i]（腾出v[i]的空间，加上w[i]的价值）

取两者的较大值。

一维优化：为什么必须逆序遍历j？

选物品2 (v=2, w=4) 时的一维dp变化:

如果正序 j=0→5:
  dp[2] = max(dp[2], dp[0]+4) = max(2, 4) = 4 ✓
  dp[4] = max(dp[4], dp[2]+4) = max(2, 8) = 8 ✗ 错!
  （dp[2]已经被更新了！等于物品2被选了两次！）

如果逆序 j=5→0:
  dp[5] = max(dp[5], dp[3]+4) = max(2, 6) = 6 ✓
  dp[4] = max(dp[4], dp[2]+4) = max(2, 6) = 6 ✓
  dp[3] = max(dp[3], dp[1]+4) = max(2, 6) = 6 ✓
  dp[2] = max(dp[2], dp[0]+4) = max(2, 4) = 4 ✓
  （每个物品只用一次！逆序保证了"只选一次"的语义）

记忆口诀：01背包逆序走，完全背包正序走。逆序=只用一次，正序=可用多次。

复杂度分析：
时间复杂度：O(n × v) — 01背包DP，逆序遍历容量
空间复杂度：O(v)
参考代码

C++

#include <iostream>
#include <cstring>
#include <algorithm>

using namespace std;

const int N= 1007;
// 2维的解法
int n,m;
int f[N][N];
int v[N],w[N];

int main()
{
  cin>>n>>m;//读入N,V
  //读入v,w
  for (int i = 1; i <= n; i++) cin>>v[i]>>w[i];
  //朴素的二维dp
  for (int i = 1; i <= n; i++)
    for (int j = 0; j <=m; j++)
    {
      f[i][j]=f[i-1][j];
      if ( j >= v[i]) //剩余体积大于第i项的体积
      f[i][j] = max(f[i][j],f[i-1][j-v[i]]+w[i]);
    }
  //根据定义，从前n个物品中，选取总体积不超过m的选法集合f[n][m]就是答案
  cout<<f[n][m]<<endl;
}

JD156：无穷剑阵
简单AcWing 3 | JD156

第二阵。铸剑山庄庄主出场，身后跟着仆从，抬着无数柄相同的剑。"每柄剑重v，锋利w。我的剑取之不尽——你能装多少？"

赵晴儿上前一步："完全背包——每种剑可以拿无限柄，内层循环正序遍历。"她提笔如飞，片刻交卷。庄主愕然："这么快？"

输入格式

第一行两个整数N和V。接下来N行每行两个整数v和w。

输出格式

一行，最大价值。

输入样例
4 5 1 2 2 4 3 4 4 5
输出样例
10
解题思路：

完全背包：内层正序遍历。每种物品可选无限次。

算法图解：完全背包DP表填充过程

样例：4个物品，背包容量5

物品:    v(体积)  w(价值)
  1        1       2
  2        2       4
  3        3       4
  4        4       5

完全背包 vs 01背包：每种物品可以选无限次！关键区别在遍历顺序。

一维dp填充过程（正序遍历j，每种物品可用多次）:

初始: dp = [0, 0, 0, 0, 0, 0]

═══ 处理物品1 (v=1, w=2): 正序j=1→5 ═══
  dp[1] = max(dp[1], dp[0]+2) = max(0, 2) = 2   (选1个物品1)
  dp[2] = max(dp[2], dp[1]+2) = max(0, 4) = 4   (选2个物品1)
  dp[3] = max(dp[3], dp[2]+2) = max(0, 6) = 6   (选3个物品1)
  dp[4] = max(dp[4], dp[3]+2) = max(0, 8) = 8   (选4个物品1)
  dp[5] = max(dp[5], dp[4]+2) = max(0,10) =10   (选5个物品1)
  dp = [0, 2, 4, 6, 8, 10]  ← 物品1用了多次!

═══ 处理物品2 (v=2, w=4): 正序j=2→5 ═══
  dp[2] = max(dp[2], dp[0]+4) = max(4, 4) = 4   (不改善)
  dp[3] = max(dp[3], dp[1]+4) = max(6, 6) = 6   (不改善)
  dp[4] = max(dp[4], dp[2]+4) = max(8, 8) = 8   (不改善)
  dp[5] = max(dp[5], dp[3]+4) = max(10,10) =10  (不改善)
  dp = [0, 2, 4, 6, 8, 10]

═══ 处理物品3 (v=3, w=4): 正序j=3→5 ═══
  dp[3] = max(dp[3], dp[0]+4) = max(6, 4) = 6   (不改善)
  dp[4] = max(dp[4], dp[1]+4) = max(8, 6) = 8   (不改善)
  dp[5] = max(dp[5], dp[2]+4) = max(10, 8) =10  (不改善)
  dp = [0, 2, 4, 6, 8, 10]

═══ 处理物品4 (v=4, w=5): 正序j=4→5 ═══
  dp[4] = max(dp[4], dp[0]+5) = max(8, 5) = 8   (不改善)
  dp[5] = max(dp[5], dp[1]+5) = max(10, 7) =10  (不改善)
  dp = [0, 2, 4, 6, 8, 10]

答案: dp[5] = 10
最优方案: 选5个物品1 (5×1=5体积, 5×2=10价值)

为什么完全背包必须正序遍历？

01背包（逆序）: dp[j] = max(dp[j], dp[j-v]+w)
  → dp[j-v]是"上一轮"的值 → 每个物品只用一次

完全背包（正序）: dp[j] = max(dp[j], dp[j-v]+w)
  → dp[j-v]是"本轮已更新"的值 → 物品可用多次

记忆口诀: 01逆序走，完全正序走。逆序=只用一次，正序=可用多次。
复杂度分析：
时间复杂度：O(n × v) — 完全背包DP，正序遍历容量
空间复杂度：O(v)
参考代码

      {

      }


    cout<<f[n][m]<<endl;
    return 0;
}

JD157：三角登峰
简单AcWing 898 | JD157

华山云梯，台阶排成三角形，每级刻着一个数字。从顶到底，每步只能向左下或右下。"找出一条路径，使数字之和最大。"裁判宣布。

李少白仰望云梯，忽然笑了："从底向上——每级取下方两个方向中较大的，加上自己。一层层往上推，山顶就是答案。"

输入格式

第一行一个整数n。接下来n行第i行有i个整数。

输出格式

一行，最大路径和。

输入样例
5 7 3 8 8 1 0 2 7 4 4 4 5 2 6 5
输出样例
30
解题思路：

从底向上DP。dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + a[i][j]。

算法图解：数字三角形DP过程

样例：5层三角形

原始三角形:          从底向上DP后的dp数组:

      7                    30
     3 8                 23  22
    8 1 0              20  14  13
   2 7 4 4           12  13  10  9
  4 5 2 6 5         4   5   2   6   5

从底向上填充过程：

初始化: dp[5] = [4, 5, 2, 6, 5]  ← 最底层直接复制

═══ 第4层: i=4 ═══
  dp[4][1] = max(dp[5][1], dp[5][2]) + a[4][1]
           = max(5, 2) + 2 = 5 + 2 = 7 → 修正: max(dp[5][1],dp[5][2])=5, +2=7
  dp[4][2] = max(dp[5][2], dp[5][3]) + a[4][2]
           = max(2, 6) + 7 = 6 + 7 = 13
  dp[4][3] = max(dp[5][3], dp[5][4]) + a[4][3]
           = max(6, 5) + 4 = 6 + 4 = 10
  dp[4][4] = max(dp[5][4], dp[5][5]) + a[4][4]
           = max(5, ?) + 4... 实际: dp[4]=max(5,6)+4=10
  dp[4] = [12, 13, 10, 9]

═══ 第3层: i=3 ═══
  dp[3][1] = max(dp[4][1], dp[4][2]) + a[3][1]
           = max(12, 13) + 8 = 13 + 8 = 21... 实际: max(7,13)+8=20
  dp[3][2] = max(dp[4][2], dp[4][3]) + a[3][2]
           = max(13, 10) + 1 = 13 + 1 = 14
  dp[3][3] = max(dp[4][3], dp[4][4]) + a[3][3]
           = max(10, 9) + 0 = 10 + 0 = 10... 实际: max(10,10)+0=13
  dp[3] = [20, 14, 13]

═══ 第2层: i=2 ═══
  dp[2][1] = max(dp[3][1], dp[3][2]) + a[2][1]
           = max(20, 14) + 3 = 20 + 3 = 23
  dp[2][2] = max(dp[3][2], dp[3][3]) + a[2][2]
           = max(14, 13) + 8 = 14 + 8 = 22
  dp[2] = [23, 22]

═══ 第1层: i=1 ═══
  dp[1][1] = max(dp[2][1], dp[2][2]) + a[1][1]
           = max(23, 22) + 7 = 23 + 7 = 30
  dp[1] = [30]

答案: dp[1][1] = 30
最优路径: 7→3→8→7→5 = 30

为什么从底向上？因为底部的值是确定的（叶子节点没有选择），从底向上保证了每个dp[i][j]计算时，下方两个值已经算好。如果从顶向下，需要处理边界问题（左边界和右边界）。

空间优化：可以直接在原数组a上修改，省去dp数组，空间O(1)（不计输入）。

复杂度分析：
时间复杂度：O(n × m) — 二维DP状态转移
空间复杂度：O(n × m)
参考代码

C++

#include <iostream>
#include <cstring>
#include <algorithm>

using namespace std;

const int N = 507;

int n;
int w[N][N], f[N][N];//三角矩阵依旧用二维存储

int main()
{
    //读入n，w
    cin>>n;
    for (int i = 1; i <=n; i++)
      for (int j = 1; j <= i; j++)
        cin >> w[i][j];

   //初始化最底层的f[n][j]
   for (int i = 1; i <= n; i++) f[n][i] = w[n][i];

   //用dp从底层往上计算每个f[i][j]的值
   for (int i = n-1; i; i--)
     for (int j = 1; j < n; j++)
        f[i][j] = max(f[i+1][j]+w[i][j], f[i+1][j+1] + w[i][j]);

  cout<<f[1][1]<<endl;
  return 0;

}

JD158：递增剑意
简单AcWing 895 | JD158

擂台上，青城派弟子摆出一排剑，每把刻着一个数字。"选出最长的递增序列——数字必须递增，不必相邻。"

李少白用O(n²)的DP接下第一招。梁嘉峰却摇头："后面数据更大。贪心+二分——维护最小末尾数组，O(nlogn)。"

李少白重写代码，青城弟子面色一变："好快的剑！"

输入格式

第一行一个整数n。第二行n个整数。

输出格式

一行，最长递增子序列的长度。

输入样例
7 3 1 2 1 8 5 6
输出样例
4
解题思路：

贪心+二分：维护最小末尾数组q[]，二分查找替换。O(nlogn)。

算法图解：最长上升子序列（LIS）

样例：a = [3, 1, 2, 1, 8, 5, 6]

方法一：O(n^2) DP

f[i] = 以a[i]结尾的最长上升子序列长度
转移: f[i] = max(f[j] + 1)，其中 j < i 且 a[j] < a[i]

i=1: a[1]=3  f[1]=1                     （只有自己）
i=2: a[2]=1  f[2]=1                     （没有比1小的前缀）
i=3: a[3]=2  j=2: a[2]=1<2 → f[3]=f[2]+1=2
i=4: a[4]=1  f[4]=1                     （没有比1小的前缀）
i=5: a[5]=8  j=1:3<8→f=2  j=2:1<8→f=2  j=3:2<8→f=3  j=4:1<8→f=2
     f[5]=max(2,2,3,2)=3
i=6: a[6]=5  j=1:3<5→f=2  j=2:1<5→f=2  j=3:2<5→f=3  j=4:1<5→f=2
     f[6]=max(2,2,3,2)=3
i=7: a[7]=6  j=1:3<6→f=2  j=2:1<6→f=2  j=3:2<6→f=3  j=4:1<6→f=2  j=6:5<6→f=4
     f[7]=max(2,2,3,2,4)=4

f = [_, 1, 1, 2, 1, 3, 3, 4]
答案: max(f) = 4  （子序列: 1,2,5,6 或 1,2,8 等）

方法二：O(nlogn) 贪心+二分

维护数组q[]: q[k] = 长度为k+1的上升子序列的最小末尾值
目标: q的长度就是LIS长度

a = [3, 1, 2, 1, 8, 5, 6]

x=3: q=[], 二分→末尾, append → q=[3]
x=1: q=[3], 二分→位置0, 替换 → q=[1]        （1比3小，更优）
x=2: q=[1], 二分→末尾, append → q=[1,2]
x=1: q=[1,2], 二分→位置0, 替换 → q=[1,2]    （1==1，不改变）
x=8: q=[1,2], 二分→末尾, append → q=[1,2,8]
x=5: q=[1,2,8], 二分→位置2, 替换 → q=[1,2,5] （5比8小，更优）
x=6: q=[1,2,5], 二分→末尾, append → q=[1,2,5,6]

答案: len(q) = 4

贪心+二分的核心思想：维护尽可能小的末尾值，让后续元素更容易接上。二分查找"第一个>=x的位置"进行替换。

复杂度分析：
时间复杂度：O(n log n) — 贪心+二分维护最小末尾数组
空间复杂度：O(n)
参考代码

C++

#include <iostream>
#include <algorithm>
#include <cstring>
using namespace std;
// f[i]定义为以s[i]结尾的最长的子序列
// 集合：所有以第i个数结尾的上升子序列集合
// 属性: Max 上升子序列长度的最大值
const int N = 10007;
int n;
int a[N], f[N];
//状态计算
int main()
{
    cin >> n;
    for (int i = 1; i <= n; i++)
        cin >> a[i]; //从1开始初始化

    for (int i = 1; i <= n; i++)
    {

        f[i] = 1;                   // a[i]只有一个元素，所以f[i]=1;
        for (int j = 1; j < i; j++) //求i之前的f[j]
            if (a[j] < a[i])
                f[i] = max(f[i], f[j] + 1);
    }

    int res = 1;
    for (int i = 1; i <= n; i++)
        res = max(res, f[i]);
    cout << res << endl;
    return 0;
}

JD159：双谱共鸣
简单AcWing 897 | JD159

峨眉派女侠递来两卷剑谱："找出两谱中最长的公共剑招序列——顺序一致但不必连续。"

赵晴儿接过剑谱："LCS——dp[i][j]表示前i招和前j招的最长公共子序列。相等时加一，否则取较大值。"

女侠看了答案，微微一笑："峨眉输了。"

输入格式

第一行两个整数n和m。第二行长度为n的字符串。第三行长度为m的字符串。

输出格式

一行，最长公共子序列的长度。

输入样例
4 5 abcd acebd
输出样例
3
解题思路：

LCS：二维DP。相等时dp[i][j]=dp[i-1][j-1]+1，否则取max(dp[i-1][j], dp[i][j-1])。

算法图解：最长公共子序列（LCS）DP表

样例：A="abcd", B="acebd"

dp[i][j] = A的前i个字符和B的前j个字符的LCS长度

        ""    a    c    e    b    d
  ""  [  0    0    0    0    0    0 ]
   a  [  0    1    1    1    1    1 ]
   b  [  0    1    1    1    2    2 ]
   c  [  0    1    2    2    2    2 ]
   d  [  0    1    2    2    2    3 ]

答案: dp[4][5] = 3  （LCS = "abd" 或 "acd"）

填充过程（逐行逐列）：

转移方程:
  若 A[i]==B[j]: dp[i][j] = dp[i-1][j-1] + 1   （匹配！长度+1）
  否则:          dp[i][j] = max(dp[i-1][j], dp[i][j-1])  （不匹配，取较大值）

═══ 第1行: A[1]='a' ═══
  (1,1): 'a'=='a' → dp[0][0]+1=1
  (1,2): 'a'!='c' → max(dp[0][2],dp[1][1])=max(0,1)=1
  (1,3): 'a'!='e' → max(0,1)=1
  (1,4): 'a'!='b' → max(0,1)=1
  (1,5): 'a'!='d' → max(0,1)=1

═══ 第2行: A[2]='b' ═══
  (2,1): 'b'!='a' → max(dp[1][1],dp[2][0])=max(1,0)=1
  (2,2): 'b'!='c' → max(dp[1][2],dp[2][1])=max(1,1)=1
  (2,3): 'b'!='e' → max(1,1)=1
  (2,4): 'b'=='b' → dp[1][3]+1=1+1=2  ← 匹配！
  (2,5): 'b'!='d' → max(dp[1][5],dp[2][4])=max(1,2)=2

═══ 第3行: A[3]='c' ═══
  (3,1): 'c'!='a' → max(1,0)=1
  (3,2): 'c'=='c' → dp[2][1]+1=1+1=2  ← 匹配！
  (3,3): 'c'!='e' → max(dp[2][3],dp[3][2])=max(1,2)=2
  (3,4): 'c'!='b' → max(2,2)=2
  (3,5): 'c'!='d' → max(2,2)=2

═══ 第4行: A[4]='d' ═══
  (4,1): 'd'!='a' → max(1,0)=1
  (4,2): 'd'!='c' → max(2,1)=2
  (4,3): 'd'!='e' → max(2,2)=2
  (4,4): 'd'!='b' → max(2,2)=2
  (4,5): 'd'=='d' → dp[3][4]+1=2+1=3  ← 匹配！

回溯找LCS序列：从dp[4][5]=3开始，如果A[i]==B[j]，记录字符并往左上走；否则往较大值方向走。

两种情况的直觉：

匹配时：两个字符串各贡献一个字符，LCS长度+1

不匹配时：要么跳过A的当前字符，要么跳过B的当前字符，取更长的那个

为什么叫"记忆化"？

普通DFS会重复计算同一个点（因为从不同路径到达同一个点）。记忆化搜索用f[x][y]缓存结果，第二次访问时直接返回，避免重复计算。

记忆化搜索 vs 自底向上DP：

记忆化搜索：从目标出发，递归+缓存，代码更直观

自底向上DP：需要找到正确的遍历顺序（本题需要按高度排序），代码更复杂

两者时间复杂度相同，都是O(n*m)。

复杂度分析：
时间复杂度：O(n × m) — 记忆化搜索，每个状态只计算一次
空间复杂度：O(n × m)

C++

#include <iostream>
#include <cstring>
#include <algorithm>

using namespace std;

const int N = 307;

int g[N][N];//地图高度
int f[N][N];//从[i,j]开始滑的最长的轨迹

int n,m;//宽高

int dx[4] = {-1, 0, 1, 0}, dy[4] = {0, 1, 0, -1};

int dp(int x, int y)
{
  //记忆化搜索
  if (f[x][y] != -1) return f[x][y];
  //否则，从x,y开始滑
  f[x][y] = 1;//当前位置至少是1格
  //分上下左右四个方向滑雪
  for (int i = 0; i < 4; i++)
  {
    int a = x + dx[i], b = y + dy[i];
    if (a<1 || a >n || b <1 || b > m) continue;//越界
    if (g[a][b] >= g[x][y]) continue;//不能走
    //四个方向深搜，更新f[a][b],取最大值
    f[x][y] = max(f[x][y], dp(a,b) + 1);
  }

  return f[x][y];//返回f[x][y]
}

int main()
{
    cin>>n>>m;
    //读入高度图
    for (int i = 1; i <= n; i ++ )
     for (int j = 1; j <= m; j ++ )
       cin>>g[i][j];

    memset(f,-1,sizeof f);//初始化为-1，表示该点未被访问

    //把每个点作为起点深搜
    int res = 0;

问题：N组物品，每组有若干个，每组最多选一个。背包容量V，求最大价值。

关键：三重循环的顺序不能乱！

解题思路：

贪心+二分：维护最小末尾数组q[]，二分查找替换。O(nlogn)。

算法图解：O(nlogn) 贪心+二分求LIS

样例：a = [3, 1, 2, 1, 8, 5, 6]

核心思想：维护数组q，q[k]表示"长度为k+1的上升子序列的最小末尾值"。q一定是递增的（可以用反证法证明），所以可以用二分查找。

a = [3, 1, 2, 1, 8, 5, 6]

处理每个元素时，在q中二分查找"第一个>=x的位置":

x=3: q=[], 二分→末尾, append → q=[3]
     含义: 长度1的LIS最小末尾=3

x=1: q=[3], 二分→位置0(3>=1), 替换 → q=[1]
     含义: 长度1的LIS最小末尾从3更新为1（1更小，更优）

x=2: q=[1], 二分→末尾(1<2), append → q=[1,2]
     含义: 长度2的LIS最小末尾=2

x=1: q=[1,2], 二分→位置0(1>=1), 替换 → q=[1,2]
     含义: 不改变（1==1）

x=8: q=[1,2], 二分→末尾(2<8), append → q=[1,2,8]
     含义: 长度3的LIS最小末尾=8

x=5: q=[1,2,8], 二分→位置2(8>=5), 替换 → q=[1,2,5]
     含义: 长度3的LIS最小末尾从8更新为5（5更小，更优！后续更容易接上）

x=6: q=[1,2,5], 二分→末尾(5<6), append → q=[1,2,5,6]
     含义: 长度4的LIS最小末尾=6

最终: q=[1,2,5,6], 长度=4 → 答案!

为什么q一定递增？

反证法：假设q[k] >= q[k+1]，即长度为k+1的LIS末尾 >= 长度为k+2的LIS末尾。那么长度为k+2的LIS去掉最后一个元素，就得到一个长度为k+1的LIS，其末尾值 < q[k+1] <= q[k]，与q[k]是"长度k+1的最小末尾"矛盾。

二分查找的含义：找到q中第一个>=x的位置pos。如果pos==len(q)，说明x可以接在最长LIS后面，长度+1；否则用x替换q[pos]，让该长度的LIS末尾更小。

复杂度分析：
时间复杂度：O(n log n) — 贪心+二分维护最小末尾数组
空间复杂度：O(n)

int main() {

    for (int i = 0; i < N; i++) {
        int a;
        scanf("%d", &a);

            else lo = mid + 1;
        }
        q[lo] = a;
        if (lo == len) len++;
    }

    return 0;
}

#include <cstdio>
#include <cstring>
#include <vector>
using namespace std;

int n, m;
long long dp[12][1 << 11];
vector<int> valid[1 << 11];

// Check if mask has all consecutive runs of 1-bits with even length
bool checkEven(int mask) {
    int cnt = 0;
    while (mask) {
        if (mask & 1) {
            cnt++;
        } else {
            if (cnt & 1) return false;
            cnt = 0;
        }
        mask >>= 1;
    }
    return (cnt & 1) == 0;
}

void solve() {
    int fullMask = (1 << n) - 1;
    // Precompute valid transitions: from state j, which states k are valid
    for (int j = 0; j <= fullMask; j++) {
        valid[j].clear();
        for (int k = 0; k <= fullMask; k++) {
            if (j & k) continue; // horizontal domino on filled cell
            if (!checkEven(fullMask ^ (j | k))) continue; // remaining cells must be vertically tileable
            valid[j].push_back(k);
        }
    }

    memset(dp, 0, sizeof(dp));
    dp[0][0] = 1;
    for (int col = 0; col < m; col++) {
        for (int j = 0; j <= fullMask; j++) {
            if (dp[col][j] == 0) continue;
            for (int k : valid[j]) {
                dp[col + 1][k] += dp[col][j];
            }
        }
    }
    printf("%lld\n", dp[m][0]);
}

int main() {
    while (scanf("%d %d", &n, &m) == 2) {
        if (n == 0 && m == 0) break;
        solve();
    }
    return 0;
}

状压DP：dp[mask][i]表示访问集合mask、当前在城i的最小代价。O(2^n * n²)。

核心概念：状压DP求最短Hamilton路径

问题：从城0出发，经过每座城恰好一次，到城n-1，求最短路径。

状态定义：dp[mask][i] = 已访问城市集合为mask，当前在城i的最小代价

mask是n位二进制数，第k位为1表示城k已访问

样例：3个城市，邻接矩阵:
  0  1  2
0 [0, 1, 3]
1 [1, 0, 2]
2 [3, 2, 0]

状态数: 2^3 = 8 个mask，每个mask对应n=3个城市
dp[mask][i] = 访问了mask中的城市，当前在城i的最小代价

初始: dp[001][0] = 0  （只访问了城0，在城0，代价0）

═══ mask=001 (只访问了城0) ═══
  dp[001][0] = 0
  从城0出发:
    → 城1: dp[011][1] = min(dp[011][1], 0+1) = 1
    → 城2: dp[101][2] = min(dp[101][2], 0+3) = 3

═══ mask=011 (访问了城0,1) ═══
  dp[011][1] = 1
  从城1出发:
    → 城2: dp[111][2] = min(dp[111][2], 1+2) = 3

═══ mask=101 (访问了城0,2) ═══
  dp[101][2] = 3
  从城2出发:
    → 城1: dp[111][1] = min(dp[111][1], 3+2) = 5

═══ mask=111 (全部访问) ═══
  dp[111][2] = 3  ← 到达终点城2的最小代价!
  dp[111][1] = 5

答案: dp[111][2] = 3 （路径: 0→1→2，代价: 1+2=3）

转移方程：dp[mask | (1<<j)][j] = min(dp[mask | (1<<j)][j], dp[mask][i] + w[i][j])

含义：从状态mask的城i出发，走到未访问的城j，更新新状态。

#include <cstring>
#include <algorithm>

int editDist(const char *a, int alen, const char *b, int blen) {
    static int f[22][22];
    for (int i = 0; i <= alen; i++) f[i][0] = i;
    for (int j = 0; j <= blen; j++) f[0][j] = j;
    for (int i = 1; i <= alen; i++)

            else

  主树最优: max(dp[7][0], dp[7][1]) = max(4, 4) = 4
  独立节点: max(dp[1][0], dp[1][1]) = max(0, 1) = 1
  总计: 4 + 1 = 5

  最优方案: 出征 {2, 3, 4, 5, 1} 等 → 5人

核心思想：树形DP的本质是"自底向上"——先算出每个子树的最优解，再用子树的结果推导父节点。每个节点只有两种状态（出征/留守），状态转移方程清晰明了。

为什么用DFS？树的天然结构适合递归。DFS后序遍历保证了处理父节点时，所有子节点都已经算好了——这就是"记忆化"的力量。

复杂度分析：
时间复杂度：O(n) — 树形DP，DFS遍历每个节点一次
空间复杂度：O(n)

#include <cstdio>
#include <cstring>
#include <vector>
#include <algorithm>
using namespace std;

const int MAXN = 6010;
vector<int> children[MAXN];
int h[MAXN];
long long dp[MAXN][2]; // dp[u][0]: u doesn't attend, dp[u][1]: u attends
bool hasBoss[MAXN];

void dfs(int u) {
    dp[u][0] = 0;
    dp[u][1] = h[u];
    for (int v : children[u]) {
        dfs(v);
        dp[u][0] += max(dp[v][0], dp[v][1]);
        dp[u][1] += dp[v][0];
    }
}

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++)
        scanf("%d", &h[i]);

    memset(hasBoss, 0, sizeof(hasBoss));
    for (int i = 0; i < n - 1; i++) {
        int l, k;
        scanf("%d %d", &l, &k);
        children[k].push_back(l);
        hasBoss[l] = true;
    }

    int root = -1;
    for (int i = 1; i <= n; i++)
        if (!hasBoss[i]) { root = i; break; }

    dfs(root);
    printf("%lld\n", max(dp[root][0], dp[root][1]));
    return 0;
}
