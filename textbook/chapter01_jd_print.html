JD001：铁令求和
简单AcWing 1 | JD001

李少白第一次来到剑道宗山门前。梁嘉峰递给他两枚铁令，上面各刻着一个数。「加起来，报给我。」

输入格式

一行，两个整数A和B，用空格隔开。

输出格式

一个整数，即A+B的结果。

输入样例
3 4
输出样例
7
解题思路：

读入两个整数，输出它们的和。

复杂度分析：
时间复杂度：O(1) — 固定次数的输入输出操作
空间复杂度：O(1)
参考代码

C++

// ===== C++ 解法 =====
// 第一步：引入输入输出库
// iostream 是 C++ 的标准输入输出头文件，cin 和 cout 都来自这里
#include 
using namespace std;

int main() {
    // 第二步：声明变量
    // int 表示整数类型，a 和 b 是两个"盒子"，用来存放输入的数
    int a, b;

    // 第三步：读入数据
    // cin >> 从键盘读取数据，>> 是"流向"的意思
    // 键盘输入 "3 4" 后，a 变成 3，b 变成 4
    cin >> a >> b;

    // 第四步：计算并输出
    // cout << 输出内容，<< 也是"流向"，把数据流向屏幕
    // endl 表示换行（end line 的缩写）
    cout << a + b << endl;

    // 第五步：返回 0 表示程序正常结束
    return 0;
}

// ===== 运行过程演示 =====
// 输入: 3 4
// a=3, b=4
// a+b = 3+4 = 7
// 输出: 7

Python

# ===== Python 解法 =====

# 第一步：读入一行文字
# input() 从键盘读取一整行文字，返回字符串 "3 4"
line = input()             # line = "3 4"

# 第二步：按空格切分
# .split() 把字符串按空格切成列表 ["3", "4"]
parts = line.split()        # parts = ["3", "4"]

# 第三步：转成整数
# map(int, ...) 把列表中每个元素都变成整数
# list(...) 把结果变成列表 [3, 4]
nums = list(map(int, parts))  # nums = [3, 4]

# 第四步：取出两个数
a = nums[0]                # a = 3（列表第1个元素，下标从0开始）
b = nums[1]                # b = 4（列表第2个元素）

# 第五步：计算并输出
print(a + b)               # 输出 7

# ===== 一行写法（等价于上面五步） =====
# a, b = map(int, input().split())
# print(a + b)

# 【小贴士】map(int, input().split()) 是 Python 竞赛最常用的读入方式
# 拆开理解：input() 读一行 → split() 切分 → map(int, ...) 转整数
C++ vs Python 对照：
cin >> a >> b; ↔ a, b = map(int, input().split())
cout << a+b << endl; ↔ print(a + b)
JD002：铁令相乘
简单AcWing 605 | JD002

梁嘉峰从腰间解下两枚铁令，随手抛给李少白。「上次是加法，」他说，「这次换个运算。」李少白接住一看，每枚铁令背面各刻着一个数字。赵晴儿在旁边提醒道：「还记得加法的三步吗？输入、处理、输出。只不过这次，处理的那一步从加号变成了乘号。」梁嘉峰点了点头：「乘法。报结果的时候，前面加上 PROD = 。」

输入格式

一行，两个整数A和B，用空格隔开。

输出格式

输出 PROD = 后跟A×B的结果。

输入样例
3 9
输出样例
PROD = 27
解题思路：

读入两个整数，输出它们的乘积。

复杂度分析：
时间复杂度：O(1) — 固定次数的输入输出操作
空间复杂度：O(1)
参考代码

C++

#include 
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;   // 读入两个整数，比如输入 "3 9"，则 a=3, b=9

    // 输出格式：先输出 "PROD = "，再输出计算结果
    // 可以用 << 把文字和数字串在一起输出
    cout << "PROD = " << a * b << endl;
    // 运行过程：输出 "PROD = " → 输出 3*9=27 → 换行
    return 0;
}

Python

# 铁令相乘：读入两个整数，输出乘积

# 一行读入并拆包：等价于之前的五步写法
a, b = map(int, input().split())
# 输入 "3 9" → a=3, b=9

# f-string 格式化输出：花括号 {} 里放变量或表达式
# f"PROD = {a * b}" 会把 {a * b} 替换成计算结果 27
print(f"PROD = {a * b}")
# 输出: PROD = 27
f-string 小贴士：
Python 用 f"文字{表达式}文字" 来格式化输出。花括号里可以放变量、运算，甚至函数调用。
JD003：四令求差
简单AcWing 608 | JD003

练功房桌上摆着四枚铁令。梁嘉峰说：「A和B相乘，C和D相乘，把两个积的差报给我。」

输入格式

一行，四个整数A、B、C、D，用空格隔开。

输出格式

输出 DIFFERENCE = 后跟A×B − C×D的结果。

输入样例
5 6 7 8
输出样例
DIFFERENCE = -26
解题思路：

先乘后减：A×B - C×D。注意运算顺序和输出格式。

复杂度分析：
时间复杂度：O(1) — 固定次数的输入输出操作
空间复杂度：O(1)
参考代码

C++

// scanf/printf 比 cin/cout 更快，适合大量数据
// 需要引入 cstdio（C语言标准输入输出库）
#include 

int main() {
    int a, b, c, d;

    // scanf 读入格式：%d 表示读一个整数
    // &a 表示变量 a 的地址（scanf 需要知道存到哪里）
    // 输入 "5 6 7 8" → a=5, b=6, c=7, d=8
    scanf("%d%d%d%d", &a, &b, &c, &d);

    // 先各自相乘，再求差
    // printf 格式：%d 是整数占位符，\n 是换行
    // 运算：5*6 - 7*8 = 30 - 56 = -26
    printf("DIFFERENCE = %d\n", a * b - c * d);
    return 0;
}

// 【小贴士】scanf/printf vs cin/cout
// scanf/printf：C语言风格，速度快，但要写格式符（%d, %f, %lf）
// cin/cout：C++风格，写起来简单，但大数据量时较慢

Python

# 四令求差：A*B - C*D

# 一行读入四个整数
# input().split() 切出4个字符串
# map(int, ...) 把4个字符串都转成整数
# a,b,c,d = ... 把4个整数分别赋给4个变量（拆包）
a, b, c, d = map(int, input().split())

# 运算顺序：先乘后减（乘法优先级高于减法）
# 5*6 - 7*8 = 30 - 56 = -26
print(f"DIFFERENCE = {a * b - c * d}")
JD004：集市算账
简单AcWing 611 | JD004

宗门集市的账房里，算盘珠子噼啪作响。账房先生递来一张货单：「赵姑娘，帮我算算这笔账。」单上写着商品编号、购买数量和单价。赵晴儿看了一眼，把货单递给身旁的李少白：「你来。记住，商品编号只是标记，真正的计算只有数量乘以单价——分清哪些数据有用、哪些是干扰，这也是编程的基本功。」

输入格式

一行，三个数：商品编号（整数）、购买数量（整数）、单价（浮点数）。

输出格式

输出 TOTAL = 后跟总价（数量×单价），保留两位小数。

输入样例
12 1 5.30
输出样例
TOTAL = 5.30
解题思路：

总价 = 数量 × 单价。注意输入是一行三个数，商品编号只用于读入不需要参与计算。

复杂度分析：
时间复杂度：O(1) — 固定次数的算术运算
空间复杂度：O(1)
参考代码

C++

#include 

int main() {
    int id, qty;        // id=商品编号, qty=数量（都是整数）
    double price;       // price=单价（小数，用 double 类型）

    // 第一行：读入编号和数量（两个整数）
    // %d 读整数，&id 和 &qty 是变量的地址
    scanf("%d%d", &id, &qty);

    // 第二行：读入单价（一个小数）
    // %lf 读双精度浮点数（long float 的缩写）
    scanf("%lf", &price);

    // 总价 = 数量 × 单价
    // %.2f 表示保留2位小数输出
    // 注意：id（商品编号）只是读入，不参与计算！
    printf("TOTAL = %.2f\n", qty * price);
    return 0;
}

// 运行演示（输入 "12 1 5.30"）：
// id=12, qty=1, price=5.30
// 总价 = 1 × 5.30 = 5.30
// 输出: TOTAL = 5.30

Python

# 集市算账：第一行是编号和数量，第二行是单价

# 第一行：读入两个整数（商品编号和数量）
id_num, qty = map(int, input().split())
# 输入 "12 1" → id_num=12, qty=1

# 第二行：读入一个小数（单价）
# 注意：这里只读一个数，不需要 split()
price = float(input())
# 输入 "5.30" → price=5.30

# 计算并输出，:.2f 表示保留2位小数
print(f"TOTAL = {qty * price:.2f}")
# 输出: TOTAL = 5.30

# 【注意】id_num 虽然读入了，但题目不需要用它
# 编程中经常需要"读入但不使用"某些数据，别被干扰
JD005：比武台
简单AcWing 604 | JD005

山门内是一片圆形的比武台，青石铺地，平整如镜。李少白绕着边沿走了一圈，估出半径大约是r步。赵晴儿站在台中央，裙角被风吹起：「这块比武台有多大？面积 = π × r²，π取3.14159。」她蹲下来用树枝在泥地上写了公式，「浮点数运算——小数的精度很重要，差之毫厘，谬以千里。」

输入格式

一个浮点数r，表示半径。

输出格式

输出 A= 后跟面积，保留4位小数。

输入样例
2.00
输出样例
A=12.5664
解题思路：

面积 = π × r²，保留4位小数。

复杂度分析：
时间复杂度：O(1) — 固定次数的算术运算
空间复杂度：O(1)
参考代码

C++

#include 

int main() {
    double r;           // 半径是小数，用 double 类型
    scanf("%lf", &r);    // 读入半径，比如输入 "2.00"

    // 圆的面积公式：π × r²
    // r * r 就是 r²（r的平方）
    // %.4f 表示保留4位小数
    // 计算：3.14159 × 2.00 × 2.00 = 12.56636 → 保留4位 → 12.5664
    printf("A=%.4f\n", 3.14159 * r * r);

}

// 【小贴士】保留小数位数的格式符
// %.0f → 不保留小数（四舍五入）

// %.5f → 保留5位小数

Python

r = float(input())
# 输入 "2.00" → r = 2.0

# 计算面积并输出，:.4f 保留4位小数
# 3.14159 * 2.0 * 2.0 = 12.56636 → 12.5664
print(f"A={3.14159 * r * r:.4f}")

# 【小贴士】保留小数位数
# f"{x:.2f}" → 保留2位小数

JD006：剑术考核
简单AcWing 606 | JD006

入门考核的成绩单发下来了。李少白凑过去一看：剑术8.2分，心法6.5分。他正想取平均数，赵晴儿拦住了他：「等等——剑术占3.5成，心法占7.5成，权重不同，不能简单相加除以二。」梁嘉峰走过来，把权重写在石板上：「加权平均，(成绩A×权重3.5 + 成绩B×权重7.5) ÷ 总权重11。这比简单平均更能反映真实水平。」

本题输出前缀 Average = 为原题格式要求。
class="io-section">

输入格式

两行，每行一个浮点数，分别表示剑术成绩A和心法成绩B。

输出格式

输出 Average = 后跟加权平均分，保留5位小数。

输入样例
9.7 5.3
输出样例
Average = 6.70000
解题思路：

加权平均 = (A×3.5 + B×7.5) / 11。保留5位小数。

复杂度分析：
时间复杂度：O(1) — 固定次数的算术运算
空间复杂度：O(1)
参考代码

C++

#include 

int main() {
    double a, b;           // a=剑术成绩, b=心法成绩

    // 两行输入，每行一个浮点数
    // 第一次 scanf 读第一行 → a
    // 第二次 scanf 读第二行 → b
    scanf("%lf%lf", &a, &b);

    // 加权平均公式：(A×权重1 + B×权重2) ÷ 总权重
    // 这里：(剑术×3.5 + 心法×7.5) ÷ (3.5+7.5) = ÷11
    // %.5f 表示保留5位小数
    printf("Average = %.5f\n", (a * 3.5 + b * 7.5) / 11);
    return 0;
}

// 运行演示（输入 9.7 和 5.3）：
// a=9.7, b=5.3
// (9.7*3.5 + 5.3*7.5) / 11 = (33.95 + 39.75) / 11 = 73.7 / 11 = 6.70000

Python

# 剑术考核：加权平均分

# 读入两行，每行一个浮点数
# 注意：这里每行只有一个数，所以用 float(input()) 逐行读
a = float(input())       # 第一行：剑术成绩，输入 "9.7" → a=9.7
b = float(input())       # 第二行：心法成绩，输入 "5.3" → b=5.3

# 加权平均 = (A×3.5 + B×7.5) / 11
# :.5f 保留5位小数
result = (a * 3.5 + b * 7.5) / 11
print(f"Average = {result:.5f}")
# 输出: Average = 6.70000

JD009：铁球体积
简单AcWing 612 | JD009

兵器库角落里，一颗实心铁球蒙着灰尘。李少白擦了擦，用绳子量出半径r。「这铁球有多重？」他自言自语。赵晴儿走过来：「先算体积——球的体积公式是 V = (4/3)πr³，π取3.14159。」她顿了顿，「注意4/3在代码里要写成 4.0/3.0，不然整数除法会把小数部分丢掉，算出来的结果就差远了。」

输入格式

一个浮点数r，表示铁球的半径。

输出格式

输出 VOLUME = 后跟体积，保留3位小数。

输入样例
3
输出样例
VOLUME = 113.097
解题思路：

体积 = 4.0/3.0 × 3.14159 × r³，保留3位小数。

复杂度分析：
时间复杂度：O(1) — 固定次数的算术运算
空间复杂度：O(1)
参考代码

C++

#include 

int main() {
    double r;
    scanf("%lf", &r);       // 读入半径

    // 球的体积公式：V = (4/3) × π × r³
    // 重要：必须写 4.0/3.0，不能写 4/3！
    // 因为 4/3 在 C++ 中是整数除法，结果是 1（小数部分被丢掉）
    // 4.0/3.0 是浮点除法，结果是 1.33333...
    // r*r*r 就是 r³（r的三次方）

简单AcWing 616 | JD011

赵晴儿在沙盘上标了两个哨塔的坐标(x1,y1)和(x2,y2)。她说：「算算它们之间的直线距离。」

输出格式

距离公式 d = √((x₂-x₁)² + (y₂-y₁)²)，保留4位小数。

复杂度分析：
时间复杂度：O(1) — 固定次数的算术运算

参考代码

C++

#include 
#include 

int main() {
    double x1, y1, x2, y2;          // 两个点的坐标
    scanf("%lf%lf%lf%lf", &x1, &y1, &x2, &y2);

    // 两点间距离公式：d = √((x₂-x₁)² + (y₂-y₁)²)
    // sqrt() 是开平方函数，来自 cmath 库

JD014：钱庄换银
简单AcWing 653 | JD014

李少白去镇上钱庄换碎银。掌柜说：「你要换多少文？我用100、50、20、10、5、2、1面额的铜钱给你。」需要知道每种面额各要几枚。

本题输出格式中的 nota(s) de R$ 为巴西货币单位，属于原题格式要求。
class="io-section">

输入格式

一个整数N，表示要换的文数。

输出格式

第一行输出总金额N。接下来7行，按面额从大到小，每行输出 X nota(s) de R$ Y,00，其中X是张数，Y是面额。

输入样例

输出样例
576 5 nota(s) de R$ 100,00 1 nota(s) de R$ 50,00 1 nota(s) de R$ 20,00 0 nota(s) de R$ 10,00 1 nota(s) de R$ 5,00 0 nota(s) de R$ 2,00 1 nota(s) de R$ 1,00
解题思路：

贪心：从大到小依次整除。先输出总金额N，再输出每种面额的张数。

复杂度分析：
时间复杂度：O(n) — 贪心遍历每种面额，面额数为常数
空间复杂度：O(1)
参考代码

C++

#include 

int main() {
    int n;
    scanf("%d", &n);      // 读入总金额，比如 576
    printf("%d\n", n);   // 先输出总金额

    // 贪心算法：从大面额开始换
    // 面额数组：100, 50, 20, 10, 5, 2, 1
    int denoms[] = {100, 50, 20, 10, 5, 2, 1};

    for (int i = 0; i < 7; i++) {
        // n / denoms[i] = 该面额需要几张
        // n % denoms[i] = 换完后剩余金额
        printf("%d nota(s) de R$ %d,00\n", n / denoms[i], denoms[i]);
        n %= denoms[i];  // 更新剩余金额
    }
    return 0;
}

//   6 / 5   = 1, 余 1    → 1 张5
