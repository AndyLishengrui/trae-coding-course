第2章 歧路逢生

条件判断与分支

山道分岔，石碑指路。赵晴儿说："条件判断让程序学会了选择——根据不同的条件，走不同的路。"

本章学习 if/else 条件判断——让程序根据不同的输入做出不同的反应。这是编程从"计算"走向"决策"的关键一步。

⚠ C++ 初学者最容易犯的错：= 和 == 搞混！

= 是赋值（把右边的值存到左边的变量里）
== 是比较（判断两边是否相等，返回 true 或 false）

正确：if (a == 5) — 判断 a 是否等于 5
错误：if (a = 5) — 把 5 赋给 a，条件永远为真！

Python 没有这个坑：赋值用 =，比较用 ==，不会搞混。
JD015：石碑之谜
简单AcWing 665 | JD015

山门前有两条路，路边各立一块石碑。赵晴儿指着石碑上的两个数说：「如果其中一个数能被另一个整除，这两块碑就是一对——走左边这条路。否则走右边。」

给定两个整数A和B，判断它们是否互为倍数关系（即A能被B整除，或B能被A整除）。

本题输出 Sao Multiplos / Nao sao Multiplos 为原题葡语格式（是倍数/不是倍数）。

输入格式

一行，两个整数A和B。

输出格式

互为倍数输出 Yes，否则输出 No。

输入样例
6 24
输出样例
Sao Multiplos
解题思路：

判断 A%B==0 或 B%A==0，只要有一个成立就是倍数关系，输出Yes；否则输出No。

复杂度分析：
时间复杂度：O(1) — 固定次数的输入输出操作
空间复杂度：O(1)
参考代码

C++

#include <iostream>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;  // 输入 "6 24" → a=6, b=24

    // % 是取余运算符：24 % 6 = 0（能整除）
    // || 是"或者"（逻辑或）：只要有一个条件成立就为真
    // == 是比较（注意不是 =，= 是赋值！）

    // 判断逻辑：a能被b整除，或者b能被a整除
    // 24 % 6 == 0 → true（24÷6=4 余0）
    // 短路求值：第一个条件已为真，不再检查第二个
    if (a % b == 0 || b % a == 0)
        cout << "Sao Multiplos" << endl;
    else
        cout << "Nao sao Multiplos" << endl;
    return 0;
}

Python

# 读入两个整数
a, b = map(int, input().split())
# 输入 "6 24" → a=6, b=24

# % 是取余运算符
# or 是"或者"（逻辑或）
# == 是比较（不是赋值 =）

# 判断逻辑：a能被b整除，或者b能被a整除
if a % b == 0 or b % a == 0:
    print("Sao Multiplos")
else:
    print("Nao sao Multiplos")

# 【逻辑运算符对照】
# C++     Python    含义
# &&      and       并且（都为真才为真）
# ||      or        或者（一个为真就为真）
# !       not       取反（真变假，假变真）
JD016：三根木棍
简单AcWing 664 | JD016

赵晴儿从柴堆里抽出三根木棍，量了量长度，让李少白判断它们能不能拼成一个三角形。如果能，算出周长；如果不能，算出以A、B为上下底、C为高的梯形面积，公式为 (A+B)×C÷2。

输入格式

一行，三个浮点数A、B、C。

输出格式

能拼成三角形输出 Perimeter = X.X（周长），拼不成输出 Area = X.X（梯形面积）。

输入样例
6.0 4.0 2.0
输出样例
Area = 10.0
解题思路：

三角形成立条件：任意两边之和大于第三边。成立时周长=A+B+C；不成立时梯形面积=(A+B)*C/2。保留1位小数。

复杂度分析：
时间复杂度：O(1) — 直接公式计算
空间复杂度：O(1)
参考代码

C++

#include <cstdio>
#include <iostream>
using namespace std;
int main() {
    double a, b, c;
    cin >> a >> b >> c;  // 输入 "6.0 4.0 2.0"

    // 三角形成立条件：任意两边之和 > 第三边
    // && 是"并且"（逻辑与）：三个条件都满足才为真
    // 6+4>2 ✓, 6+2>4 ✓, 4+2=6 不>6 ✗ → 不能构成三角形
    if (a + b > c && a + c > b && b + c > a)
        printf("Perimeter = %.1lf\n", a + b + c);
    else
        printf("Area = %.1lf\n", (a + b) * c / 2);
    return 0;
}

// 【逻辑运算符 && || ! 优先级】
// ! (非) > && (与) > || (或)
// 如果不确定优先级，加括号最安全！

Python

# 读入三边长度
a, b, c = map(float, input().split())
# 输入 "6.0 4.0 2.0"

# 三角形成立条件：任意两边之和 > 第三边
# 6+4>2 ✓, 6+2>4 ✓, 4+2=6 不>6 ✗
if a + b > c and a + c > b and b + c > a:
    # 能构成三角形 → 输出周长
    print(f"Perimeter = {a + b + c:.1f}")
else:
    # 不能构成三角形 → 输出梯形面积
    print(f"Area = {(a + b) * c / 2:.1f}")
JD017：比武时辰
简单AcWing 667 | JD017

李少白和师弟在练武场比武。他们从A时开始，到B时结束（只看整点，不看分钟）。如果B>A，比武持续了B-A小时；如果B≤A，说明比武过了零点，持续了24-A+B小时；如果A=B，说明刚好持续了一整天（24小时）。

本题输出 O JOGO DUROU X HORA(S) 为原题葡语格式（游戏持续了X小时）。

输入格式

一行，两个整数A和B（0≤A,B≤23）。

输出格式

输出一个整数，表示比武持续的小时数。

输入样例
16 2
输出样例
O JOGO DUROU 8 HORA(S)
解题思路：

用条件判断：如果B>A，输出B-A；如果B==A，输出24；否则输出24-A+B。

复杂度分析：
时间复杂度：O(1) — 固定次数的比较操作
空间复杂度：O(1)
参考代码

C++

#include <cstdio>
int main() {
    int a, b;
    scanf("%d%d", &a, &b);  // 输入 "16 2" → a=16, b=2

    // 三种情况的逻辑：
    // 情况1：B > A → 没过零点，直接 B - A
    // 情况2：B == A → 刚好24小时（整整一天）
    // 情况3：B < A → 过了零点，24 - A + B

    int res;
    if (a < b)        res = b - a;      // 16 < 2? 否
    else if (a == b)  res = 24;          // 16 == 2? 否
    else               res = 24 - a + b;  // 24 - 16 + 2 = 10

    printf("O JOGO DUROU %d HORA(S)\n", res);
    return 0;
}

// 【if-else if-else 链的执行流程】
// 从上到下依次检查条件，一旦某个条件成立就执行对应代码
// 然后跳过后面所有 else，直接往下走
// 最多只会执行一个分支！

Python

# 读入开始时间和结束时间
a, b = map(int, input().split())
# 输入 "16 2" → a=16, b=2

# 三种情况：
# B > A：没过零点，直接 B - A
# B == A：刚好24小时
# B < A：过了零点，24 - A + B
if a < b:
    horas = b - a
else:
    horas = 24 - a + b  # 包含了 B<=A 的两种情况

print(f"O JOGO DUROU {horas} HORA(S)")
# 输出: O JOGO DUROU 10 HORA(S)

# 【注意】Python 的 if-elif-else 和 C++ 的 if-else if-else 一样
# 但 Python 用缩进（Tab）表示代码块，不用花括号 {}
JD018：三石排序
简单AcWing 663 | JD018

山道旁的空地上，梁嘉峰随手捡了三块石头，用刻刀在上面各凿了一个数字。他把石头往李少白脚前一丢：「乱的。从小到大排好，报给我。」李少白蹲下来，左右比了比。赵晴儿靠在树干上说：「先比前两个，把小的换到前面；再比后两个——这是冒泡排序最朴素的直觉。三个数只需要三次比较，但这个思路能推广到一万个数。」

输入格式

一行，三个整数，用空格隔开。

输出格式

三个数从小到大输出，空格隔开。

输入样例
7 21 -14
输出样例
-14 7 21
解题思路：

用条件判断两两比较确定顺序，或存入数组排序。

复杂度分析：
时间复杂度：O(1) — 排序算法
空间复杂度：O(1)
参考代码

C++

#include <iostream>
using namespace std;
int main() {
    int a, b, c;
    cin >> a >> b >> c;  // 输入 "7 21 -14"

    // 冒泡排序的思路：两两比较，把大的往后换
    // swap(a, b) 交换两个变量的值

    // 第一轮：比较前两个
    if (a > b) swap(a, b);  // 7 > 21? 否 → 不交换

    // 第二轮：比较第一和第三
    if (a > c) swap(a, c);  // 7 > -14? 是 → 交换 → a=-14, c=7

    // 第三轮：比较第二和第三
    if (b > c) swap(b, c);  // 21 > 7? 是 → 交换 → b=7, c=21

    // 结果：a=-14, b=7, c=21 ✓ 从小到大！
    cout << a << " " << b << " " << c << endl;
    return 0;
}

// 【swap 函数】交换两个变量的值
// int x = 5, y = 10;
// swap(x, y); 之后 x=10, y=5

Python

# 读入三个整数
a, b, c = map(int, input().split())
# 输入 "7 21 -14"

# Python 交换两个变量：a, b = b, a（不需要临时变量！）

# 第一轮：比较前两个
if a > b: a, b = b, a   # 7 > 21? 否

# 第二轮：比较第一和第三
if a > c: a, c = c, a   # 7 > -14? 是 → a=-14, c=7

# 第三轮：比较第二和第三
if b > c: b, c = c, b   # 21 > 7? 是 → b=7, c=21

print(a, b, c)
# 输出: -14 7 21

# 【更简洁的写法】
# a, b, c = sorted(map(int, input().split()))
JD019：杂货铺
简单AcWing 660 | JD019

山脚杂货铺有5种干粮，编号1到5，单价分别是4.00、4.50、5.00、2.00、1.50文。赵晴儿报了干粮编号和要买的数量，掌柜让她自己算总价。

输入格式

一行，两个整数：干粮编号X和数量Y。

输出格式

输出 Total: R$ 后跟总价，保留两位小数。

输入样例
3 2
输出样例
Total: R$ 10.00
解题思路：

用数组或条件判断存储5种单价，查表后乘以数量。

复杂度分析：
时间复杂度：O(1) — 固定次数的比较操作
空间复杂度：O(1)
参考代码

C++

#include <cstdio>
int main() {
    int x, y;              // x=干粮编号, y=数量
    scanf("%d%d", &x, &y);  // 输入 "3 2" → x=3, y=2

    // 根据编号查单价——用 if-else if 链逐一比对
    // 注意：这里是 ==（比较），不是 =（赋值）！
    double p;              // p=单价
    if (x == 1) p = 4.0;       // 编号1: 烧饼 4.0文
    else if (x == 2) p = 4.5;  // 编号2: 馒头 4.5文
    else if (x == 3) p = 5.0;  // 编号3: 肉包 5.0文 ← x=3 走这里
    else if (x == 4) p = 2.0;  // 编号4: 馄饨 2.0文
    else p = 1.5;              // 编号5: 花卷 1.5文

    // 总价 = 单价 × 数量
    // x=3 → p=5.0, y=2 → 总价=5.0×2=10.00
    printf("Total: R$ %.2lf\n", p * y);
    return 0;
}

// 【if-else if 链的执行过程】
// 输入 x=3：
// x==1? 3==1? 否 → 跳过
// x==2? 3==2? 否 → 跳过
// x==3? 3==3? 是！→ p=5.0，跳出整个链
// 后面的 else if 和 else 都不再检查！

Python

# 杂货铺：根据编号查单价，计算总价

# 字典（dict）：编号 → 单价 的映射表
# 比 if-else if 链更简洁，查找速度也更快
prices = {1: 4.0, 2: 4.5, 3: 5.0, 4: 2.0, 5: 1.5}

# 读入编号和数量
x, y = map(int, input().split())
# 输入 "3 2" → x=3, y=2

# prices[x] 查表得到单价：prices[3] = 5.0
# 总价 = 5.0 × 2 = 10.00
print(f"Total: R$ {prices[x] * y:.2f}")

# C++ 用 if-else if 链逐一比对（适合条件复杂时）
# Python 用字典查表更简洁（适合"编号→值"映射）
JD020：内力分级
简单AcWing 659 | JD020

宗门把弟子的内力值分成四个等级：[0,25]是入门，(25,50]是初级，(50,75]是中级，(75,100]是高级。超出100则不在评级范围内。李少白测出一名弟子的内力值，需要判断他属于哪个等级。

输入格式

一个浮点数，表示内力值。

输出格式

输出对应区间的名称，或 Out of interval（超出范围）。

输入样例
95.29
输出样例
Interval (75,100]
解题思路：

用 if-elif-else 逐一判断落在哪个区间。

复杂度分析：
时间复杂度：O(1) — 固定次数的输入输出操作
空间复杂度：O(1)
参考代码

C++

#include <iostream>
using namespace std;
int main() {
    double x;
    cin >> x;  // 输入 "95.29"

    // 多分支判断：用 else if 链逐一检查区间
    // [0,25] 用 >= 表示包含0
    // (25,50] 用 > 表示不包含25

    if (x >= 0 && x <= 25)          // 95.29 >= 0 && 95.29 <= 25? 否
        cout << "Interval [0,25]" << endl;
    else if (x > 25 && x <= 50)   // 95.29 > 25 && 95.29 <= 50? 否
        cout << "Interval (25,50]" << endl;
    else if (x > 50 && x <= 75)   // 95.29 > 50 && 95.29 <= 75? 否
        cout << "Interval (50,75]" << endl;
    else if (x > 75 && x <= 100)  // 95.29 > 75 && 95.29 <= 100? 是！
        cout << "Interval (75,100]" << endl;
    else
        cout << "Out of interval" << endl;
    return 0;
}

// 【区间表示法】
// [0,25] → 包含0和25（闭区间）
// (25,50] → 不包含25，包含50（左开右闭）
// 这是数学中的标准记法

Python

# 读入内力值

# 输入 "95.29"

# Python 特有写法：0 <= x <= 25（链式比较）
# 等价于 0 <= x and x <= 25

if 0 <= x <= 25:
    print("Interval [0,25]")      # 入门
elif 25 < x <= 50:
    print("Interval (25,50]")     # 初级
elif 50 < x <= 75:
    print("Interval (50,75]")     # 中级
elif 75 < x <= 100:
    print("Interval (75,100]")    # 高级 ← 95.29 落在这里
else:
    print("Out of interval")       # 超出范围

# Python: elif（更简洁）

JD022：跨夜比武
简单AcWing 668 | JD022

李少白和师弟比武，开始时间是A时B分，结束时间是C时D分。比武可能跨了零点。请算出比武持续了多久。

输入格式

一行，四个整数A、B、C、D，分别表示开始的时、分和结束的时、分。

输出格式

输出比武持续时间，格式为 H:M。

输入样例
8 56 7 37
输出样例
22:41
解题思路：

全部转为分钟做差。如果结果≤0，加上24×60。然后转回时:分格式。

复杂度分析：
时间复杂度：O(1) — 固定次数的输入输出操作
空间复杂度：O(1)
参考代码

C++

#include <cstdio>
int main() {
    int a, b, c, d;
    scanf("%d%d%d%d", &a, &b, &c, &d);
    // 输入 "8 56 7 37" → a=8, b=56, c=7, d=37

    // 关键思路：全部转成分钟再做减法
    // 开始时间 = 8时56分 = 8×60 + 56 = 536 分钟
    // 结束时间 = 7时37分 = 7×60 + 37 = 457 分钟
    int start = a * 60 + b;   // start = 536
    int end = c * 60 + d;     // end = 457

    // 如果结束时间 ≤ 开始时间，说明跨了零点
    // 加上 24×60=1440 分钟（一整天）
    // 457 ≤ 536 ✓ → end = 457 + 1440 = 1897
    if (end <= start) end += 24 * 60;

    // 时间差 = 1897 - 536 = 1361 分钟
    int diff = end - start;

    // 转回 时:分 格式
    // 时 = 1361 / 60 = 22（整除取小时）
    // 分 = 1361 % 60 = 41（取余取分钟）
    printf("%d:%d\n", diff / 60, diff % 60);
    return 0;
}

Python

# 跨夜比武：计算时间差

# 读入 开始时、开始分、结束时、结束分
a, b, c, d = map(int, input().split())
# 输入 "8 56 7 37"

# 全部转成分钟
s = a * 60 + b      # 开始 = 8×60+56 = 536 分钟
e = c * 60 + d      # 结束 = 7×60+37 = 457 分钟

# 跨零点判断：结束 ≤ 开始 → 加一天
if e <= s: e += 24 * 60  # 457+1440 = 1897

# 算差值，再转回 时:分
d = e - s             # 1897-536 = 1361 分钟

解题思路：

输出格式

            解题思路：

#include <iostream>

int main() {
    int a, b, c, d;

    // 条件1：b > a        → 14 > -87 ✓

JD026：木棍辨形
简单AcWing 666 | JD026

梁嘉峰递来三根木棍：「先判断能不能拼成三角形。能的话，再判断是直角、锐角还是钝角三角形。」判断依据：最长边的平方与另外两边平方和的关系。

输入格式

一行，三个浮点数，表示三边长度（已从小到大排列）。

输出格式

不能构成输出 Not a triangle；能构成则输出三角形类型：Equilateral（等边）、Isosceles（等腰）、Scalene（不等边）、Right（直角）、Acute（锐角）、Obtuse（钝角）。

输入样例
6.0 4.0 2.0
输出样例
Not a triangle
解题思路：

先验证两边之和大于第三边。再判断等边/等腰/不等边，然后比较最长边平方判断直角/锐角/钝角。

复杂度分析：
时间复杂度：O(1) — 固定次数的输入输出操作
空间复杂度：O(1)
参考代码

C++

#include <iostream>
#include <algorithm>
using namespace std;
int main() {
    double a, b, c;
    cin >> a >> b >> c;
    // 输入 "6.0 4.0 2.0"

    // 第一步：排序，让 a 成为最长边
    // swap(x,y) 交换两个变量的值
    if (b > a) swap(a, b);  // 确保 a ≥ b
    if (c > a) swap(a, c);  // 确保 a ≥ c（a是最大值）
    if (c > b) swap(b, c);  // 确保 b ≥ c
    // 排序后：a=6.0, b=4.0, c=2.0

    // 第二步：判断能否构成三角形
    // 三角形条件：最长边 < 另外两边之和
    // 6.0 ≥ 4.0+2.0=6.0? 是 → 不能构成三角形
    if (a >= b + c) cout << "Not a triangle" << endl;
    else {
        // 第三步：判断角度（用勾股定理的推广）
        // a² = b² + c² → 直角
        // a² > b² + c² → 钝角
        // a² < b² + c² → 锐角
        if (a*a == b*b + c*c) cout << "Right" << endl;
        if (a*a > b*b + c*c) cout << "Obtuse" << endl;
        if (a*a < b*b + c*c) cout << "Acute" << endl;

        // 第四步：判断边的关系
        if (a == b && b == c) cout << "Equilateral" << endl;      // 等边
        else if (a == b || a == c || b == c) cout << "Isosceles" << endl;  // 等腰
    }
    return 0;
}

JD028：田赋计算
简单AcWing 672 | JD028

李少白入了宗门，开始交田赋。税率分档：2000以下免税，2000.01~3000部分征8%，3000.01~4500部分征18%，4500以上部分征28%。注意是分段计税——只有超出部分按对应税率算。

本题输出 R$ X.XX 和 Isento 为巴西货币和葡语免税标记。

输入格式

一个浮点数，表示月收入。

输出格式

输出 R$ X.XX。免税则输出 Isento。

输入样例
3002.00
输出样例
R$ 80.36
解题思路：

分段计算：1000×8% + 2×18% = 80.36。每段只对超出部分征税。

复杂度分析：
时间复杂度：O(1) — 固定次数的输入输出操作
空间复杂度：O(1)
参考代码

C++

#include <cstdio>
int main() {
    double x;
    scanf("%lf", &x);
    // 输入 "3002.00"

    // 2000以下免税
    if (x <= 2000) { printf("Isento\n"); return 0; }

    // 去掉免税额度，只对超出部分计税
    x -= 2000;       // 3002-2000 = 1002（应税部分）

    double t = 0;    // t=总税额

    // 第一档：0~1000，税率8%
    // 三目运算符：条件 ? 真值 : 假值
    // v = min(x, 1000) → 取本档的应税金额
    if (x > 0) { double v = x < 1000 ? x : 1000; t += v * 0.08; x -= v; }
    // x=1002, v=min(1002,1000)=1000, t=1000×0.08=80, x=2

    // 第二档：1000~2500，税率18%
    if (x > 0) { double v = x < 1500 ? x : 1500; t += v * 0.18; x -= v; }
    // x=2, v=min(2,1500)=2, t=80+2×0.18=80.36, x=0

    // 第三档：2500以上，税率28%
    if (x > 0) t += x * 0.28;
    // x=0, 跳过

    printf("R$ %.2lf\n", t);  // 输出 R$ 80.36
    return 0;
}

// 【分段计税的思路】
// 1. 先去掉免税额度
// 2. 从低档到高档，每档只对"剩余金额"征税
// 3. 每档征完后，减去已征部分，进入下一档

Python

# 田赋计算：分段累进税率

# 输入 "3002.00"

# 2000以下免税
if x <= 2000:
    print("Isento")
else:
    # 去掉免税额度
    x -= 2000          # 3002-2000 = 1002（应税部分）
    t = 0               # t=总税额

    # 第一档：0~1000，税率8%
    if x > 0:
        v = min(x, 1000)   # v = min(1002, 1000) = 1000
        t += v * 0.08      # t = 1000×0.08 = 80
        x -= v              # x = 1002-1000 = 2

    # 第二档：1000~2500，税率18%
    if x > 0:
        v = min(x, 1500)   # v = min(2, 1500) = 2
        t += v * 0.18      # t = 80 + 2×0.18 = 80.36
        x -= v              # x = 0

    # 第三档：2500以上，税率28%
    if x > 0:
        t += x * 0.28      # x=0, 跳过

    print(f"R$ {t:.2f}")  # R$ 80.36

# C++: x < 1000 ? x : 1000  （三目运算符）
# Python: min(x, 1000)      （内置函数，更直观）
