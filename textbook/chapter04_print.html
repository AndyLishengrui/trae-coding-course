数据的容器
数组与线性存储 · 14题 · C++ & Python 双语对照

在编程的世界里，单个变量只能存储一个值。当我们需要处理成百上千个数据时——比如全班同学的成绩、一个月的温度记录、一首诗的所有字符——逐一命名变量变得不切实际。数组（Array）正是为解决这一问题而诞生的数据结构。

数组的核心思想非常简单：连续存储，编号访问。想象一排编号从0开始的储物柜，每个柜子存放一个数据。通过柜子编号（索引），你可以在O(1)时间内直接访问任意一个柜子里的内容——这是计算机科学中最快的访问方式之一。

本章学习目标

① 理解数组的连续存储原理和索引访问机制

② 掌握一维数组的遍历、筛选、变换、翻转、查找五大基础操作

③ 入门二维数组的行列遍历模式

④ 通过斐波那契数列体会递推思想——动态规划(DP)的萌芽

⑤ 通过质数判定学习算法优化——从O(n²)到O(n√n)

📦 C++数组 vs Python列表：两种设计哲学

C++原生数组：定长、类型严格、栈上分配、极高性能。声明int arr[10]时编译器在栈上预留40字节（10×4），访问arr[i]只做一次指针加法。但缺点也很明显：长度编译时确定、不提供越界检查（运行时不安全）。C++的vector弥补了定长缺陷，在堆上动态分配。

Python列表：动态扩容、类型灵活、堆上分配、自带越界检查。Python的list本质是一个指针数组，每个元素指向堆上实际对象。这带来了灵活性——可以在运行时任意增删元素，但也牺牲了性能——访问一个int需要两次指针跳转。

关键差异：C++中int arr[10]的10个int是连续存放的，CPU缓存友好。Python中[1,2,3]的3个元素是3个独立的对象，不保证连续。理解这种差异有助于你写出高性能代码。

NQ046数组中的行AcWing 743
给定一个12×12的二维数组。读取行号L和操作类型T（'S'求和或'M'求平均），计算第L行所有元素的和或平均值。这是二维数组行操作的标准模板。
输入第一行L(0-11)。第二行T('S'或'M')。接下来144个浮点数（12×12矩阵）。
输出结果保留1位小数。
范围矩阵元素−10⁶到10⁶
输入
2
S
(144个浮点数...)
输出
(第2行之和)
思路双层循环遍历矩阵：外层for i in range(12)控制行，内层for j in range(12)控制列。当i==L时累加。如果T=='M'求平均则除以12.0。这种行列遍历模式贯穿所有多维数组题目。
技巧双层循环是二维数组的标准遍历方式。C++中矩阵用double M[12][12]或vector>。Python嵌套列表：[[0]*12 for _ in range(12)]。
C++
#include <cstdio>

int main()
{
  double a[12][12];

  int l;
  char t;
  scanf("%d\n%c", &l, &t);

  for (int i = 0; i < 12; i ++ )
      for (int j = 0; j < 12; j ++ )
          scanf("%lf", &a[i][j]);

  double s = 0;
  for (int i = 0; i < 12; i ++ ) s += a[l][i];

  if (t == 'S') printf("%.1lf\n", s);
  else printf("%.1lf\n", s / 12);

  return 0;        
}
Python
l = int(input())

    for j in range(12):
        x = float(input())
        if i == l: sum_val += x
print(f"{sum_val if t == 'S' else sum_val / 12:.1f}")

NQ048斐波那契数列AcWing 741
斐波那契数列前两项是0和1，之后每一项都是前两项之和。给定N（1≤N≤60），输出前N项。注意结果可能超过32位int范围！
输入一个整数N。
输出一行，空格隔开的N个整数。
范围1 ≤ N ≤ 60
输入
5
输出
0 1 1 2 3
思路递推标准模板：a=0, b=1; for i in range(N): output a; a,b = b, a+b。C++需用long long（64位整数），N=60时F(60)≈1.5×10¹²远超int范围。这是动态规划(DP)思想的萌芽——用前面算出的结果推导后面。
技巧Python自动大整数无需担心溢出。C++千万要用long long！int在N>46时就会溢出。Python的a,b=b,a+b是递推最优雅写法。
C++
#include <iostream>
#include <cstdio>

using namespace std;

int main()
{
    long long f[61];
    f[0] = 0; f[1] = 1;

    for (int i = 2; i <= 60; i ++ ) f[i] = f[i - 1] + f[i - 2];

    int n;
    cin >> n;
    while (n -- )
    {
      int x;
      cin >> x;
      printf("Fib(%d) = %lld\n", x, f[x]);
    }

    return 0;
}
Python
n = int(input())

    result.append(str(a))
    a, b = b, a + b

范围0 ≤ N ≤ 60

思路与NQ048类似但只输出最后一项。递推直到第N项，不需要存储所有中间结果——O(1)空间复杂度。注意N=0的情况：直接输出0。
技巧Python:a,b=0,1;for _ in range(n):a,b=b,a+b;print(a)。注意这个循环次数和输出的对应关系——循环n次后a就是第n项。
C++
#include <iostream>

using namespace std;

int main()
{
  int n;
  cin >> n;

  int a = 0, b = 1;

  for (int i = 0; i < n; i ++ )
  {
    cout << a << ' ';
    int c = a + b;
    a = b;
    b = c;
  }

  cout << endl;

  return 0;
}

#include <iostream>
#include <algorithm>

using namespace std;

int main()
{
  int n, m;
  while (cin >> n >> m, n > 0 && m > 0)
  {
    if (n > m) swap(n, m);

    int sum = 0;
    for (int i = n; i <= m; i ++ )

NQ053完全数AcWing 725
一个数的所有真因子（不含自身）之和等于自身，称为完全数。给定N，输出不超过N的所有完全数。例如6=1+2+3，28=1+2+4+7+14。
输入一个整数N。
输出每行一个完全数。
范围1 ≤ N ≤ 10⁸
输入
30
输出
6
28
思路10⁸以内只有四个完全数：6, 28, 496, 8128。直接判断它们是否≤N即可，不需要枚举计算！这是"数学知识简化算法"的经典案例——有时候知道答案比计算答案更高效。
技巧10⁸以内的完全数是被数学家证明的（欧几里得-欧拉定理）。编程中利用已知数学事实可以大幅简化算法。这是"先思考，再编码"的典范。
C++
#include <cstdio>
#include <iostream>

using namespace std;

int main()
{
  int n;
  cin >> n;

  while (n -- )
  {
    int x;
    cin >> x;

    int s = 0;
    for (int i = 1; i * i <= x; i ++ )
        if (x % i == 0)
        {
          if (i < x) s += i;
          if (i != x / i && x / i < x) s += x / i;
        }

    if (s == x) printf("%d is perfect\n", x);
    else printf("%d is not perfect\n", x);
  }

  return 0;
}
Python
n = int(input())
for x in [6, 28, 496, 8128]:
    if x <= n:
        print(x)
NQ054质数AcWing 726
给定N，输出2到N之间所有的质数（素数）。质数指大于1且只有1和自身两个因子的数。本题是算法优化的入门——同一个问题，不同实现效率差100倍。
输入一个整数N。
输出每行一个质数。
范围2 ≤ N ≤ 10⁶
输入
10
输出
2
3
5
7
思路朴素方法：对2到N的每个数i，检查2到√i是否有因子。关键优化：j*j<=i作循环条件（只需检查到√i）。时间复杂度从O(n²)降到O(n√n)。如果N很大还可以用埃拉托色尼筛法——"空间换时间"思想。
技巧Python用math.isqrt(i)获得整数平方根。判断条件j*j<=i比j<=sqrt(i)更高效（避免浮点数运算）。这是算法优化的第一课。
C++
#include <cstdio>
#include <iostream>

using namespace std;

int main()
{
  int n;
  cin >> n;
  while (n -- )
  {
    int p;
    cin >> p;

    bool is_prime = true;
    for (int i = 2; i * i <= p; i ++ )
        if (p % i == 0)
        {
           is_prime = false;
           break;
        }
    if (is_prime) printf("%d is prime\n", p);
    else printf("%d is not prime\n", p);
  }

  return 0;
}
Python
import math
n = int(input())
for i in range(2, n + 1):
    prime = True
    for j in range(2, int(math.sqrt(i)) + 1):
        if i % j == 0:
            prime = False
            break
    if prime:
        print(i)

📋 本章知识点总结

  • 数组的五大操作：遍历(iterate)、筛选(filter)、变换(transform)、翻转(reverse)、查找(search)
  • C++数组：int arr[n]（栈）、vector<int>（堆）、array<int,n>（栈+STL包装）
  • Python列表：动态扩容、负数索引、切片arr[::-1]、列表推导[x for x in arr if cond]
  • 二维数组遍历：双层for循环——外层行(i)、内层列(j)。行列操作对称，只需改变判断条件
  • 递推思想（DP萌芽）：斐波那契数列——每个新值由前两个已知值计算，不需要回溯所有历史
  • 算法优化第一课：质数判定——从O(n²)穷举到O(n√n)开方优化。同样的结果，不同效率
  • 数学知识助力：完全数——10⁸以内只有4个。数学事实可以大幅简化编程工作量
