NQ067字符串长度AcWing 760
给定一行字符串（可能含空格），输出其长度。
输入一行字符串。
输出字符串长度。
范围长度≤100
输入
Hello World
输出
11
思路用len()或.length()直接获取。Python的input()默认读到换行。C++的getline读取含空格行。
技巧Python:len(input())。C++:getline(cin,s)读取整行含空格。
C++
#include <cstdio>

int main()
{
    char str[101];

    fgets(str, 101, stdin);

    int len = 0;
    for (int i = 0; str[i] && str[i] != '\n'; i ++ ) len ++ ;

    printf("%d\n", len);

    return 0;
}
Python
print(len(input()))
NQ068字符串中的数字个数AcWing 761
统计给定字符串中数字字符('0'-'9')的个数。
输入一行字符串。
输出数字字符的个数。
范围长度≤100
输入
hello2024world
输出
4
思路遍历每个字符，用isdigit()判断是否为数字。Python的sum(c.isdigit()for c in s)一行搞定。
技巧Python: c.isdigit()。C++: c>='0'&&c<='9'。
C++
#include <cstdio>

int main()
{
    char str[101];

    fgets(str, 101, stdin);

    int cnt = 0;
    for (int i = 0; str[i]; i ++ )
        if (str[i] >= '0' && str[i] <= '9')
           cnt ++ ;

    printf("%d\n", cnt);

    return 0;
}
Python
s=input();print(sum(1 for c in s if c.isdigit()))

C++
#include <cstdio>
#include <iostream>

using namespace std;

int main()
{
    int n;
    cin >> n;

    while (n -- )
    {
      string a, b;
      cin >> a >> b;

      int x, y;
      if (a == "Hunter") x = 0;
      else if (a == "Bear") x = 1;
      else x = 2;

      if (b == "Hunter") y = 0;
      else if (b == "Bear") y = 1;
      else y = 2;

      if (x == y) puts("Tie");
      else if (x == (y + 1) % 3) puts("Player1");
      else puts("Player2");
    }

  return 0;  
}

NQ070字符串加空格AcWing 765
给定一个字符串，在每个字符后加一个空格。
输入一行字符串。
输出字符间加空格的字符串。
范围长度≤100
输入
abc
输出
a b c
思路Python用' '.join(s)一行搞定。C++循环输出每个字符+空格。Python字符串不可变，用join比+=高效。
技巧Python的' '.join(s)是O(n)高效拼接。循环+=是O(n²)劣化。
C++
#include <iostream>

using namespace std;

int main()
{
    string a;
    getline(cin, a);

    string b;
    for (auto c : a) b = b + c + ' ';

    b.pop_back();

    cout << b << endl;

    return 0;
}

将字符串中所有的特定字符替换为'#'。

思路Python用s.replace(old,'#')直接替换。C++遍历每个字符判断替换。

#include <cstdio>
#include <iostream>

using namespace std;

int main()
{
    char str[31];
    scanf("%s", str);

    char c;
    scanf("\n%c", &c);

    for (int i = 0; str[i]; i ++ )
        if (str[i] == c)
            str[i] = '#';

    puts(str);

    return 0;
}

NQ073只出现一次的字符AcWing 772
给定字符串，找出第一个只出现一次的字符。如果没有则输出"no"。
输入一行字符串。
输出第一个只出现一次的字符或"no"。
范围长度≤10⁵
输入
abaccdeff
输出
b
思路用字典/数组统计每个字符出现次数，再遍历字符串找第一个次数为1的。Python的Counter最方便。
技巧Python: from collections import Counter。O(n)时间完成两次遍历。
C++
#include <iostream>
#include <cstring>

using namespace std;

int cnt[26];
char str[100010];

int main()
{
    cin >> str;

    for (int i = 0; str[i]; i ++ ) cnt[str[i] - 'a'] ++ ;

    for (int i = 0; str[i]; i ++ )
        if (cnt[str[i] - 'a'] == 1)
        {
          cout << str[i] << endl;
          return 0;
        }

        puts("no");

    return 0;    
}
Python
from collections import Counter
s=input();cnt=Counter(s)
for c in s:
 if cnt[c]==1:print(c);break
else:print('no')
NQ074字符串匹配AcWing 762
给定两个字符串，判断str1是否包含str2作为连续子串。
输入两行：主串和模式串。
输出包含输出"yes"，否则"no"。
范围长度≤100
输入
abcdefg
cde
输出
yes
思路暴力匹配：遍历主串每个位置作为起点，检查是否匹配。也可用Python的in或find。
技巧Python:if sub in s:最简单。C++:s.find(sub)!=npos。
C++
#include <iostream>

using namespace std;

int main()
{
    double k;
    string a, b;
    cin >> k >> a >> b;

    int cnt = 0;
    for (int i = 0; i < a.size(); i ++ )
        if (a[i] == b[i])
            cnt ++ ;

    if ((double)cnt / a.size() >= k) puts("yes");
    else puts("no");

    return 0;
}

s=input();t=input();print('yes' if t in s else 'no')
NQ075信息加密AcWing 767
凯撒加密：将每个字母替换为字母表中其后一个字母(z→a,Z→A)，非字母不变。
输入一行字符串。
输出加密后字符串。
范围长度≤200
输入
Hello, World!
输出
Ifmmp, Xpsme!
思路遍历字符，用ord/chr处理字母循环：c=chr((ord(c)-base+1)%26+base)。非字母直接保留。
技巧Python: ord()/chr()。取模%26处理循环。
C++
#include <iostream>
#include <cstring>
using namespace std;

int main(){

    string s;
    getline(cin,s);//读入一行

    for (auto &c:s)//使用auto注意&c直接引用字符串直接修改
      if (c>='a' && c<='z') 
          c = 'a'+ (c-'a'+1) % 26;//取模运算
         else if (c>='A' && c<='Z') 
          c = 'A' + (c-'A'+1) % 26;

    cout<<s<<endl;//输出结果
}
Python
r=''

 if'a'<=c<='z':r+=chr((ord(c)-97+1)%26+97)
 elif'A'<=c<='Z':r+=chr((ord(c)-65+1)%26+65)
 else:r+=c
print(r)

NQ077单词替换AcWing 770
将句子中的某个单词替换为另一个单词。
输入三行：原句、要替换的单词、新单词。
输出替换后的句子。
范围长度≤200
输入
hello world
world
python
输出
hello python
思路split分解单词，遍历替换，join重建句子。
技巧Python: ' '.join(w if w!=old else new for w in s.split())。
C++
#include <iostream>
#include <sstream>

using namespace std;

int main()
{
    string s, a, b;

    getline(cin, s);
    cin >> a >> b;

    stringstream ssin(s);
    string str;
    while (ssin >> str)
        if (str == a) cout << b << ' ';
        else cout << str << ' ';

    return 0;    
}
Python
s=input();a=input();b=input()
print(' '.join(b if w==a else w for w in s.split()))
NQ078最长单词AcWing 774
找出英文句子中最长的单词。如果有多个，输出第一个。
输入一个英文句子。
输出最长的单词。
范围长度≤500
输入
I love programming
输出
programming
思路split分割单词，找最长：max(words,key=len)。
技巧Python: max(s.split(), key=len)一行。
C++
#include <iostream>

using namespace std;

int main()
{
    string res, str;

    while (cin >> str)
    {
      if (str.back() == '.') str.pop_back();
      if (str.size() > res.size()) res = str;
    }

    cout << res << endl;

    return 0;
}
Python
words=input().split()
print(max(words,key=len))
