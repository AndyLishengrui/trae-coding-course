
# NQ078 思路分析

## 问题描述
输入一个算术表达式，计算并输出其值。表达式包含数字、加减乘除运算符和括号。

## 思考过程
1. **问题分析**：需要处理算术表达式的求值，包括运算符优先级和括号的处理。
2. **算法选择**：使用递归下降解析方法，根据运算符优先级分层处理表达式。
3. **数据结构**：使用类来封装表达式和位置指针，方便递归调用时的状态管理。
4. **优先级处理**：将表达式分解为不同层次，按照运算符优先级从高到低处理。

## 算法思路
- **递归下降解析**：将表达式分解为表达式、项、因子三个层次，递归处理每个层次。
- **运算符优先级**：按照先乘除后加减的顺序处理，括号优先级最高。
- **表达式层次**：处理加减运算符，因为它们的优先级最低。
- **项层次**：处理乘除运算符，它们的优先级比加减高。
- **因子层次**：处理数字和括号，它们的优先级最高。

## 实现步骤
1. **初始化**：创建表达式求值器，存储表达式和当前处理位置。
2. **表达式处理**：处理加减运算符，调用项处理函数获取操作数。
3. **项处理**：处理乘除运算符，调用因子处理函数获取操作数。
4. **因子处理**：处理数字和括号，括号内递归调用表达式处理函数。
5. **输入输出**：读取输入表达式，调用表达式处理函数计算结果并输出。

## 关键点编码逻辑
- **peek 函数**：查看当前字符但不移动位置，用于判断下一个 token 的类型。
- **get 函数**：读取当前字符并移动位置，用于消费已处理的 token。
- **因子处理**：处理括号时递归调用表达式处理函数，处理数字时逐位读取并转换为整数。
- **项处理**：循环处理乘除运算符，因为它们是左结合的。
- **表达式处理**：循环处理加减运算符，同样是左结合的。

## 时间复杂度
- **时间复杂度**：O(n)，其中 n 是表达式的长度。每个字符最多被处理一次。
- **空间复杂度**：O(d)，其中 d 是表达式中括号的最大嵌套深度。递归调用栈的深度取决于括号的嵌套深度。
