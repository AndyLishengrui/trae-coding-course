# NQ100 滚石柱

## 问题分析
本题是一个状态空间搜索问题，要求控制一个石柱在地图上滚动，从起点（X）滚动到终点（O）。石柱有三种状态：站立（1x1）、横躺（1x2）和竖躺（2x1），需要在不同状态间转换以适应地图地形。

## 解题思路
采用广度优先搜索（BFS）算法，具体步骤如下：
1. **状态表示**：使用`Stone`结构体表示石柱的状态，包含基准点坐标（x,y）和状态（0:站立, 1:横躺, 2:竖躺）
2. **方向转换**：预定义方向转换表`direction`，记录每个状态下向四个方向滚动后的新状态和坐标偏移
3. **地图构建**：读取地图，识别起点（X）和终点（O），并确定起点的初始状态
4. **BFS搜索**：
   - 使用队列管理搜索状态
   - 记录每个状态的最小步数（`dist`数组）
   - 对每个状态尝试四个方向的滚动
   - 检查滚动后的状态是否合法（边界检查、障碍物检查）
   - 如果到达终点（O）且状态为站立，返回步数
5. **判断无解**：如果队列为空仍未到达终点，返回Impossible

## 代码实现
- **C++版本**：使用`queue`实现BFS，`dist`三维数组记录状态，`direction`三维数组记录方向转换
- **Python版本**：使用`deque`实现BFS，列表嵌套记录状态，确保Python 3.5兼容性

## 时间复杂度
- 时间复杂度：O(n*m*3)
  - 其中n和m是地图的行数和列数
  - 每个位置有3种可能的状态（站立、横躺、竖躺）
  - 每个状态最多被访问一次，因此总体时间复杂度为O(n*m*3)

## 空间复杂度
- 空间复杂度：O(n*m*3)
  - 地图存储：O(n*m)
  - 状态数组：O(n*m*3)，记录每个位置每种状态的最小步数
  - 队列：最坏情况下O(n*m*3)

## 优化考虑
- **方向转换表**：预计算方向转换，避免运行时重复计算
- **状态去重**：使用`dist`数组记录已访问的状态，避免重复处理
- **边界检查**：在滚动前检查边界和障碍物，减少无效状态
- **输入处理**：Python版本使用`sys.stdin.read()`一次性读取输入，提高处理大数据的效率
- **队列选择**：使用双端队列（deque）实现BFS，确保操作的高效性

## 示例
输入：
```
5 5
#####
#..X#
#..##
#..O#
#####
```
输出：
```
5
```

## 注意事项
- 石柱的基准点是其左上角的格子
- 横躺状态需要占用右侧相邻格子，竖躺状态需要占用下方相邻格子
- 终点必须以站立状态到达
- 地图中的障碍物用'#'表示，空地用'.'表示
- 输入以n=0结束
- 算法假设地图是有效的，且起点和终点存在
