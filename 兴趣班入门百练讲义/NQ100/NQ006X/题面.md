# 1.6 数组替换 NQ006X

## 描述
输入一个长度为10的整数数组X[10]，将里面的非正整数全部替换为1，输出替换完成后的数组。

## 输入
输入包含10个整数，每个整数占一行。数据范围：-100 ≤ X[i] ≤ 100

## 输出
输出新数组中的所有元素，每个元素占一行。输出格式：X[i] = x，其中i为元素下标（从0开始），x为元素值。

## 输入样例
```
10
-9
0
-10
0
-2
3
7
4
-5
```

## 输出样例
```
X[0] = 10
X[1] = 1
X[2] = 1
X[3] = 1
X[4] = 1
X[5] = 3
X[6] = 7
X[7] = 4
X[8] = 1
X[9] = 1
```

## 解题思路
本题要求将数组中的非正整数替换为1并输出。首先读取10个整数到数组中，然后遍历数组，将所有小于等于0的元素替换为1，最后按照指定格式输出数组元素。

## 参考代码(C++)
```cpp
// NQ006X 数组替换
#include <iostream>
using namespace std;

int main() {
    int X[10];
    for(int i=0;i<10;++i) cin>>X[i];
    for(int i=0;i<10;++i) if(X[i]<=0) X[i]=1;
    for(int i=0;i<10;++i) cout<<"X["<<i<<"] = "<<X[i]<<endl;
    return 0;
}
```

## 参考代码(Python)
```python
# NQ006X 数组替换
X = [int(input()) for _ in range(10)]
for i in range(10):
    if X[i] <= 0:
        X[i] = 1
for i in range(10):
    print(f"X[{i}] = {X[i]}")
```
