# NQ006X 数组替换 解题思路

## 问题描述
输入一个长度为10的整数数组X[10]，将里面的非正整数全部替换为1，输出替换完成后的数组。

## 输入输出示例
输入：
```
10
-9
0
-10
0
-2
3
7
4
-5
```

输出：
```
X[0] = 10
X[1] = 1
X[2] = 1
X[3] = 1
X[4] = 1
X[5] = 3
X[6] = 7
X[7] = 4
X[8] = 1
X[9] = 1
```

## 解题思路
1. **读取输入**：读取10个整数，存储到数组X中。
2. **替换非正整数**：遍历数组，将所有小于等于0的元素替换为1。
3. **输出结果**：按照指定格式输出数组元素，格式为"X[i] = x"，其中i为元素下标（从0开始），x为元素值。

## 代码实现
- **C++**：使用数组存储10个整数，通过for循环读取输入，替换非正整数，然后输出结果。
- **Python**：使用列表存储10个整数，通过列表推导式读取输入，遍历列表替换非正整数，然后输出结果。
