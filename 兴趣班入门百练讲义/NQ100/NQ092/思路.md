# NQ092 思路分析

## 问题描述
在一个可变大小的棋盘上，骑士需要从起点K移动到终点H，找到最短的移动路径。棋盘上的.表示可移动的位置，*表示障碍物。骑士可以按照国际象棋中骑士的移动规则（8个方向）移动，求从K到H的最少跳跃次数。

## 思考过程
这是一个典型的最短路径问题，适合使用广度优先搜索（BFS）来解决。BFS能够保证找到无权图中的最短路径，而骑士的移动可以看作是在图中的节点间移动，每个节点到相邻节点的距离都是1。

## 算法思路

### 核心思想：广度优先搜索（BFS）
1. **状态表示**：每个位置(x, y)作为图中的一个节点
2. **搜索过程**：从起点开始，按照8个可能的移动方向进行广度优先搜索
3. **距离记录**：使用距离数组d[x][y]记录从起点到该位置的最短距离
4. **终止条件**：当搜索到终点H时，返回当前距离

### 关键步骤
1. **输入处理**：读取棋盘的列数和行数，以及棋盘的具体布局
2. **定位起点和终点**：遍历棋盘找到K和H的位置
3. **初始化**：将起点加入队列，距离设为0
4. **BFS搜索**：从队列中取出当前位置，尝试8个方向的移动，更新距离并将有效位置加入队列
5. **结果输出**：当找到终点时输出距离，若无法到达则输出-1

## 实现步骤

### C++ 实现步骤
1. 定义骑士的8个移动方向（dx和dy数组）
2. 读取输入，存储棋盘布局
3. 找到起点K和终点H的位置
4. 初始化距离数组d为-1（表示未访问）
5. 使用队列进行BFS搜索：
   - 从起点开始，将距离设为0
   - 对于每个当前位置，尝试8个方向的移动
   - 检查新位置是否合法（在棋盘内且不是障碍物且未访问）
   - 如果合法，更新距离并加入队列
   - 如果到达终点，返回当前距离
6. 输出结果

### Python 实现步骤
1. 导入必要的库（sys和deque）
2. 定义骑士的8个移动方向
3. 读取输入，存储棋盘布局
4. 找到起点K和终点H的位置
5. 使用双端队列进行BFS搜索（与C++类似）
6. 输出结果

## 关键点编码逻辑

### 1. 移动方向定义
使用两个数组dx和dy来表示骑士的8个可能移动方向：
```cpp
const int dx[8] = {1, 2, 2, 1, -1, -2, -2, -1};
const int dy[8] = {2, 1, -1, -2, -2, -1, 1, 2};
```

### 2. 边界检查
使用check函数检查新位置是否合法：
- 是否在棋盘范围内
- 是否不是障碍物
- 是否未被访问过

### 3. 距离计算
使用二维数组d[x][y]记录从起点到(x,y)的最短距离，初始化为-1表示未访问。

### 4. 输入顺序
注意输入顺序是先列数后行数：`cin >> m >> n;`（m是列数，n是行数）

## 时间复杂度

- **时间复杂度**：O(n*m)，其中n是行数，m是列数。每个格子最多被访问一次。
- **空间复杂度**：O(n*m)，需要存储棋盘和距离数组。

## 代码优化建议

1. **内存优化**：对于大棋盘，可以使用动态分配的方式来存储棋盘和距离数组
2. **性能优化**：当找到终点时立即返回，避免不必要的搜索
3. **代码可读性**：使用清晰的变量命名和适当的注释，提高代码可读性

## 与骑士周游问题的区别

- **骑士周游问题**：需要访问所有格子，是NP完全问题，使用DFS+回溯
- **骑士最短路径问题**：只需要找到从起点到终点的最短路径，使用BFS，时间复杂度更低
