# 1.10 数组的右上半部分 NQ010X

## 描述
输入一个二维数组M[12][12]，根据输入的要求，求出二维数组的右上半部分元素的平均值或元素的和。

## 输入
第一行输入一个大写字母，若为S，则表示需要求右上半部分的元素的和；若为M，则表示需要求右上半部分的元素的平均值。
接下来12行，每行包含12个用空格隔开的小数，表示这个二维数组，其中第i+1行的第j+1个数表示数组元素M[i][j]。
数据范围：-100.0 ≤ M[i][j] ≤ 100.0

## 输出
输出一个数，表示所求的平均数或元素的和的值，保留一位小数。


## 解题思路
本题要求根据输入的操作类型，计算二维数组右上半部分的和或平均值。右上半部分是指主对角线以上的部分，即j > i的元素。首先读取操作类型（S表示求和，M表示求平均值），然后读取12x12的二维数组，计算右上半部分的和和元素个数，最后根据操作类型输出和或平均值，保留一位小数。

## 参考代码(C++)
```cpp
// NQ010X 数组的右上半部分
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double a[12][12];
    char t;
    cin >> t;
    for(int i=0;i<12;++i) {
        for(int j=0;j<12;++j) {
            cin >> a[i][j];
        }
    }
    double s = 0;
    int cnt = 0;
    for(int i=0;i<12;++i) {
        for(int j=i+1;j<12;++j) {
            s += a[i][j];
            cnt++;
        }
    }
    cout << fixed << setprecision(1);
    if(t == 'S') cout << s << endl;
    else cout << s/cnt << endl;
    return 0;
}
```

## 参考代码(Python)
```python
# NQ010X 数组的右上半部分
t = input().strip()
a = []
for _ in range(12):
    row = list(map(float, input().split()))
    a.append(row)
s = 0
cnt = 0
for i in range(12):
    for j in range(i+1, 12):
        s += a[i][j]
        cnt += 1
if t == 'S':
    print(f"{s:.1f}")
else:
    print(f"{s/cnt:.1f}")
```
