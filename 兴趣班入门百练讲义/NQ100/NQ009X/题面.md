# 1.9 数组中的行 NQ009X

## 描述
输入一个二维数组M[12][12]，根据输入的要求，求出二维数组中某一行的元素的平均值或元素的和。

## 输入
第一行输入整数L，表示所求的具体行号（行号从0开始计算）。
第二行包含一个大写字母，若为S，则表示需要求第L行的元素的和；若为M，则表示需要求第L行的元素的平均值。
接下来12行，每行包含12个用空格隔开的小数，表示这个二维数组，其中第i+1行的第j+1个数表示数组元素M[i][j]。
数据范围：-100.0 ≤ M[i][j] ≤ 100.0

## 输出
输出一个数，表示所求的平均数或元素的和的值，保留一位小数。

## 解题思路
本题要求根据输入的行号和操作类型，计算二维数组中对应行的和或平均值。首先读取行号L和操作类型（S表示求和，M表示求平均值），然后读取12x12的二维数组，计算第L行的和，最后根据操作类型输出和或平均值，保留一位小数。

## 参考代码(C++)
```cpp
// NQ009X 数组中的行
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double a[12][12];
    int l;
    char t;
    cin >> l >> t;
    for(int i=0;i<12;++i) {
        for(int j=0;j<12;++j) {
            cin >> a[i][j];
        }
    }
    double s = 0;
    for(int i=0;i<12;++i) s += a[l][i];
    cout << fixed << setprecision(1);
    if(t == 'S') cout << s << endl;
    else cout << s/12 << endl;
    return 0;
}
```

## 参考代码(Python)
```python
# NQ009X 数组中的行
l = int(input())
t = input().strip()
a = []
for _ in range(12):
    row = list(map(float, input().split()))
    a.append(row)
s = sum(a[l])
if t == 'S':
    print(f"{s:.1f}")
else:
    print(f"{s/12:.1f}")
```
