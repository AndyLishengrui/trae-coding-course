# 1.13 数组中的列 NQ013X

## 描述
输入一个二维数组M[12][12]，根据输入的要求，求出二维数组中某一列的元素的平均值或元素的和。

## 输入
第一行输入整数C，表示所求的具体列号（列号从0开始计算）。
第二行包含一个大写字母，若为S，则表示需要求第C列的元素的和；若为M，则表示需要求第C列的元素的平均值。
接下来12行，每行包含12个用空格隔开的小数，表示这个二维数组，其中第i+1行的第j+1个数表示数组元素M[i][j]。
数据范围：-100.0 ≤ M[i][j] ≤ 100.0

## 输出
输出一个数，表示所求的平均数或元素的和的值，保留一位小数。

## 解题思路
本题要求根据输入的列号和操作类型，计算二维数组中对应列的和或平均值。首先读取列号C和操作类型（S表示求和，M表示求平均值），然后读取12x12的二维数组，计算第C列的和，最后根据操作类型输出和或平均值，保留一位小数。

## 参考代码(C++)
```cpp
// NQ013X 数组中的列
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double a[12][12];
    int c;
    char t;
    cin >> c >> t;
    for(int i=0;i<12;++i) {
        for(int j=0;j<12;++j) {
            cin >> a[i][j];
        }
    }
    double s = 0;
    for(int i=0;i<12;++i) s += a[i][c];
    cout << fixed << setprecision(1);
    if(t == 'S') cout << s << endl;
    else cout << s/12 << endl;
    return 0;
}
```

## 参考代码(Python)
```python
# NQ013X 数组中的列
c = int(input())
t = input().strip()
a = []
for _ in range(12):
    row = list(map(float, input().split()))
    a.append(row)
s = 0
for i in range(12):
    s += a[i][c]
if t == 'S':
    print(f"{s:.1f}")
else:
    print(f"{s/12:.1f}")
```
