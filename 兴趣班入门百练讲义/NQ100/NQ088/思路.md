# NQ088 思路分析

## 问题描述
莱尼尔射出的箭雨阵中每一支雷电箭依次飞来的高度（高度数据是≤50000的正整数）。请计算每套箭雨拦截系统最多能拦截多少支雷电箭？拦截系统的规则是：第一面海鲁拉盾可以到达任意的高度，但是以后每一面海鲁拉盾都不能高于前一面的高度。

## 思考过程
这是一个典型的最长不上升子序列问题。最长不上升子序列是指一个序列中，元素按照非递增顺序排列的最长子序列。

对于这个问题，我们需要找到箭雨高度序列中的最长不上升子序列，其长度就是最多能拦截的箭数。

## 算法思路

### C++ 实现：动态规划（O(n²)）
1. **状态定义**：`dp[i]` 表示以第i个元素结尾的最长不上升子序列的长度
2. **状态转移**：对于每个元素 `heights[i]`，遍历之前的所有元素 `heights[j]`（j < i），如果 `heights[i] <= heights[j]`，则 `dp[i] = max(dp[i], dp[j] + 1)`
3. **结果**：整个dp数组中的最大值即为最长不上升子序列的长度

### Python 实现：贪心 + 二分查找（O(n log n)）
1. **贪心策略**：维护一个数组 `tails`，其中 `tails[i]` 表示长度为 i+1 的所有不上升子序列中，最后一个元素的最大值
2. **二分查找**：对于每个元素 `h`，在 `tails` 中找到第一个小于 `h` 的位置，用 `h` 替换该位置的元素
3. **结果**：`tails` 数组的长度即为最长不上升子序列的长度

## 实现步骤

### C++ 实现步骤
1. 读取输入的箭雨数量 `n` 和高度数组 `heights`
2. 初始化 `dp` 数组，所有元素初始化为 1（每个元素自身构成一个长度为 1 的子序列）
3. 遍历每个元素 `heights[i]`，计算以该元素结尾的最长不上升子序列长度
4. 找出 `dp` 数组中的最大值，输出结果

### Python 实现步骤
1. 读取输入的箭雨数量 `n` 和高度数组 `heights`
2. 初始化空数组 `tails`
3. 遍历每个高度 `h`：
   - 使用二分查找在 `tails` 中找到第一个小于 `h` 的位置
   - 如果该位置等于 `tails` 的长度，将 `h` 添加到 `tails` 末尾
   - 否则，用 `h` 替换该位置的元素
4. 输出 `tails` 数组的长度

## 关键点编码逻辑

### C++ 动态规划
- **状态转移**：对于每个元素，检查所有之前的元素，更新最长不上升子序列长度
- **结果计算**：使用 `max_element` 函数找到 `dp` 数组中的最大值

### Python 贪心 + 二分查找
- **二分查找**：实现了手动二分查找，寻找第一个小于当前高度的位置
- **贪心策略**：通过维护 `tails` 数组，确保每个位置的元素尽可能大，以便后续元素更容易加入

## 时间复杂度

### C++ 动态规划
- 时间复杂度：O(n²)，其中 n 是箭雨的数量
- 空间复杂度：O(n)，需要一个长度为 n 的 dp 数组

### Python 贪心 + 二分查找
- 时间复杂度：O(n log n)，其中 n 是箭雨的数量，每个元素需要一次二分查找
- 空间复杂度：O(n)，需要一个 `tails` 数组，最坏情况下长度为 n

## 两种方法的比较

| 方法 | 时间复杂度 | 空间复杂度 | 适用场景 | 特点 |
|------|------------|------------|----------|------|
| 动态规划 | O(n²) | O(n) | 小规模数据 | 实现简单，思路清晰 |
| 贪心 + 二分查找 | O(n log n) | O(n) | 大规模数据 | 效率更高，适合处理 n=10000 的情况 |

## 输入输出示例

### 输入样例 1
8
300 207 155 300 299 170 158 65

### 输出样例 1
6

### 解释
最长不上升子序列是：300, 299, 170, 158, 65 或 300, 207, 155, 158, 65 等，长度为 6。
