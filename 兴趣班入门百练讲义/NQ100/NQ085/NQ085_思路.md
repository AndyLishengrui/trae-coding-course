# NQ085 最大路径和问题思路分析

## 问题描述
给定一个由数字组成的三角形，从顶部到底部找一条路径，使得路径上的数字和最大。每一步只能移动到下一行相邻的节点。

## 算法思路
1. **动态规划**：使用二维数组 `f[i][j]` 表示从顶点到第 `i` 行第 `j` 列的最大路径和。
2. **状态转移**：对于每个位置 `(i,j)`，其最大路径和等于上方 `(i-1,j-1)` 和左上方 `(i-1,j)` 位置的最大路径和中的较大值，加上当前位置的数字。
3. **边界条件**：顶点位置 `(1,1)` 的路径和就是它本身。
4. **结果计算**：最后一行所有位置的最大路径和中的最大值即为答案。

## 实现步骤
1. 读取输入的三角形行数 `n`。
2. 读取三角形的数字，存储到二维数组 `a` 中。
3. 初始化动态规划数组 `f`，并设置边界条件 `f[1][1] = a[1][1]`。
4. 从第二行开始，计算每个位置的最大路径和。
5. 遍历最后一行，找到最大的路径和并输出。

## 时间复杂度
- 时间复杂度：O(n²)，其中 n 是三角形的行数。需要遍历三角形的所有元素一次。
- 空间复杂度：O(n²)，需要使用二维数组存储三角形和动态规划状态。
