# 1.7 数组填充 NQ007X

## 描述
输入一个整数V，输出一个长度为10的数组N，其中N[0] = V，每个后续元素的值都为前一个元素的值的2倍。

## 输入
输入一行，包含一个整数V（1 ≤ V ≤ 50）。

## 输出
输出数组中的所有元素，每个元素占一行。输出格式：N[i] = x，其中i为数组下标（从0开始），x为对应的值。

## 输入样例
```
1
```

## 输出样例
```
N[0] = 1
N[1] = 2
N[2] = 4
N[3] = 8
N[4] = 16
N[5] = 32
N[6] = 64
N[7] = 128
N[8] = 256
N[9] = 512
```

## 解题思路
本题要求根据初始值V生成一个长度为10的数组，其中每个元素都是前一个元素的2倍。首先读取输入的整数V，然后创建一个长度为10的数组，将第一个元素设为V，接着通过循环计算后续元素的值，最后按照指定格式输出数组。

## 参考代码(C++)
```cpp
// NQ007X 数组填充
#include <iostream>
using namespace std;

int main() {
    int V, N[10];
    cin >> V;
    N[0] = V;
    for(int i=1;i<10;++i) N[i] = N[i-1] * 2;
    for(int i=0;i<10;++i) cout<<"N["<<i<<"] = "<<N[i]<<endl;
    return 0;
}
```

## 参考代码(Python)
```python
# NQ007X 数组填充
V = int(input())
N = [0] * 10
N[0] = V
for i in range(1, 10):
    N[i] = N[i-1] * 2
for i in range(10):
    print(f"N[{i}] = {N[i]}")
```
