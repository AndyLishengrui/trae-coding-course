# 1.8 数组选择 NQ008X

## 描述
输入一个长度为100的数组A，按顺序输出其中不大于10的所有元素。

## 输入
输入100个数，每个数占一行，可能为整数或小数。数据范围：-100 ≤ A[i] ≤ 100

## 输出
按顺序输出数组中所有不大于10的元素，每个元素占一行。输出格式：A[i] = x，其中i为原数组中对应元素的下标，x保留一位小数。

## 输入样例
```
0
-5
63
-8.5
... (共100个数)
```

## 输出样例
```
A[0] = 0.0
A[1] = -5.0
A[3] = -8.5
... (仅输出不大于10的元素)
```

## 解题思路
本题要求筛选数组中不大于10的元素并输出。首先读取100个数到数组中，然后遍历数组，筛选出所有不大于10的元素，最后按照指定格式输出这些元素，保留一位小数。

## 参考代码(C++)
```cpp
// NQ008X 数组选择
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double A[100];
    for(int i=0;i<100;++i) cin>>A[i];
    cout<<fixed<<setprecision(1);
    for(int i=0;i<100;++i) {
        if(A[i] <= 10.0) {
            cout<<"A["<<i<<"] = "<<A[i]<<endl;
        }
    }
    return 0;
}
```

## 参考代码(Python)
```python
# NQ008X 数组选择
A = []
for i in range(100):
    A.append(float(input()))
for i in range(100):
    if A[i] <= 10.0:
        print(f"A[{i}] = {A[i]:.1f}")
```
