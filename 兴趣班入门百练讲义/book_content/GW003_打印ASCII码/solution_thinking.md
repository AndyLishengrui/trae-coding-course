## 解题思路：字符编码与类型转换

本题要求输入一个可见字符，并输出其对应的十进制 ASCII 码。这是一个关于计算机数据表示和 C++ 语言类型转换的基础问题。

### 1. 字符的本质：ASCII 编码

在计算机内部，所有的字符（如 'A', 'a', '0', '!', '
' 等）都不是以其图形形式存储的，而是以**数字**形式存储的。这种字符到数字的映射关系由编码标准定义，其中最基础和最常用的是 **ASCII (American Standard Code for Information Interchange)** 编码。

例如：
* 字符 'A' 对应数值 65。
* 字符 'B' 对应数值 66。
* 字符 '0' 对应数值 48。

### 2. C++ 中的数据类型和类型提升

在 C/C++ 语言中，`char` 类型被定义为一种**整数类型**。这意味着 `char` 变量既可以存储字符，也可以存储它们的数值（通常是 8 位整数）。

当我们声明一个 `char` 变量并给它赋值一个字符时，例如 `char c = 'A';`，实际上 `c` 中存储的是 65。

### 3. 实现策略：显式类型转换 (Explicit Casting)

为了获取存储在 `char` 变量中的数值（即 ASCII 码）并将其作为整数输出，我们需要进行类型转换。

**数学/操作公式:** 

设输入字符为 $C$，我们需要的输出 $A$ 是：
$$A = \text{Value}(C)\text{ in integer format}$$ 

在 C++ 中，实现这一转换最清晰的方式是使用**显式类型转换**，例如 `static_cast<int>(C)` 或 C 风格的 `(int)C`。

* 当我们直接使用 `std::cout << C;` 时，C++ 的输出流会根据 `C` 的类型（`char`）将其解释为字符并打印其图形表示。
* 当我们使用 `std::cout << static_cast<int>(C);` 时，我们强制告诉编译器和输出流，我们需要的是这个变量中存储的**整数值**，从而得到其对应的 ASCII 码。

整个算法流程极为简单：**读取字符 -> 显式转换为整数 -> 输出整数。**
