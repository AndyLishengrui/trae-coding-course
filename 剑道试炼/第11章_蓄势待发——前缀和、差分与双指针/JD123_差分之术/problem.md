# JD123：差分之术

> **AcWing 797** | 第11章 · 蓄势待发 | 知识点：差分

## 题目描述

赵晴儿指着一排石块："我要把第3块到第7块每块都加上5。如果一块块改，太慢了。"

梁嘉峰说："差分——前缀和的逆运算。你在第3块的位置加5，在第8块的位置减5。最后对整排求一次前缀和，第3到第7块就都加了5，其余不变。"

"就像往水面扔两块石头，"李少白恍然大悟，"波纹叠加后就是最终结果。"

给定一个长度为 n 的整数序列和 m 个操作，每个操作将 [l, r] 的每个数加 c。输出所有操作后的序列。

## 输入格式

第一行两个整数 n 和 m。第二行 n 个整数。接下来 m 行，每行三个整数 l、r 和 c。

## 输出格式

一行，操作后的序列，空格隔开。

## 样例

输入：

```text
5 3
1 2 3 4 5
1 3 2
2 4 1
3 5 3
```

输出：

```text
3 5 8 8 8
```

## 解题思路

### 思考过程

如果对每个操作都遍历 [l, r] 逐个加 c，m 个操作的时间复杂度是 O(m * n)，太慢。有没有办法把"区间加"变成"单点操作"？

关键在于：原数组 a 的差分数组 b 定义为 b[i] = a[i] - a[i-1]。如果让 b[l] += c，再让 b[r+1] -= c，那么对 b 求前缀和后，[l, r] 范围内的每个数都恰好加了 c，范围外不受影响。这就是"两点定波"——在 l 处投入一个正波，在 r+1 处投入一个负波，波纹叠加后恰好覆盖 [l, r]。

### 关键洞察

差分是前缀和的逆运算。前缀和把"单点修改、区间查询"变成 O(1) 查询；差分把"区间修改、单点查询"变成 O(1) 修改。

- 构造差分数组：b[i] = a[i] - a[i-1]（或者直接初始化为全 0，然后对每个 a[i] 做 b[i] += a[i], b[i+1] -= a[i]）。
- 区间加操作：b[l] += c, b[r+1] -= c。
- 还原：对 b 求前缀和就是最终的 a。

### 边界情况

- r = n（区间的右端点是最后一个元素）：b[r+1] 会越界！需要确保差分数组长度为 n+2，或者特判 r < n 时才执行 b[r+1] -= c。
- l = r（区间只有一个元素）：退化为单点加，b[l] += c, b[l+1] -= c，仍然正确。
- c = 0：无操作，不影响结果。
- 多个操作重叠：差分数组会累加，最后求一次前缀和即可正确处理。

### 复杂度解释

- **时间 O(n + m)**：m 个操作每个 O(1)，最后求一次前缀和 O(n)。总共 O(n + m)。
- **为什么比暴力 O(m*n) 快**：暴力是"每操作都遍历一遍区间"；差分是"先记住每个操作的起点和终点，最后一次性算出结果"。把 m 次遍历合并成了 1 次。
- **空间 O(n)**：需要一个长度为 n+2 的差分数组。
