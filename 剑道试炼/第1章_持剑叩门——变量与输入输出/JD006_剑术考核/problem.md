# JD006：剑术考核

> **AcWing 606** | 第1章 · 持剑叩门 | 知识点：加权平均、浮点数

## 题目描述

入门考核有两项：剑术和心法。剑术权重3.5，心法权重7.5。赵晴儿拿到成绩后要算加权平均分。

## 输入格式

两行，每行一个浮点数，分别表示剑术成绩A和心法成绩B。

## 输出格式

输出 `Average = ` 后跟加权平均分，保留5位小数。

## 样例

输入：

```text
9.7
5.3
```

输出：

```text
Average = 6.70000
```

## 解题思路

加权平均 = (A×3.5 + B×7.5) / 11。保留5位小数。
