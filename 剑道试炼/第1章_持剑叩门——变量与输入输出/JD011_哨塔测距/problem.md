# JD011：哨塔测距

> **AcWing 616** | 第1章 · 持剑叩门 | 知识点：数学函数、距离公式

## 题目描述

赵晴儿在沙盘上标了两个哨塔的坐标(x1,y1)和(x2,y2)。她说：「算算它们之间的直线距离。」

## 输入格式

一行，四个浮点数x1, y1, x2, y2，用空格隔开。

## 输出格式

输出两点间的距离，保留两位小数。

## 样例

输入：

```text
1.0 7.0 5.0 9.0
```

输出：

```text
4.4721
```

## 解题思路

距离公式 d = √((x₂-x₁)² + (y₂-y₁)²)，保留4位小数。
