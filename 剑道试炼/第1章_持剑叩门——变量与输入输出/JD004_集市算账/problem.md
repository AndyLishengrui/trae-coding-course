# JD004：集市算账

> **AcWing 611** | 第1章 · 持剑叩门 | 知识点：多步运算

## 题目描述

宗门集市上，赵晴儿帮账房算一笔账。已知商品编号、购买数量和单价，算出总价。

## 输入格式

一行，三个数：商品编号（整数）、购买数量（整数）、单价（浮点数）。

## 输出格式

输出 `TOTAL = ` 后跟总价（数量×单价），保留两位小数。

## 样例

输入：

```text
12 1 5.30
```

输出：

```text
TOTAL = 5.30
```

## 解题思路

总价 = 数量 × 单价。注意输入是一行三个数，商品编号只用于读入不需要参与计算。
