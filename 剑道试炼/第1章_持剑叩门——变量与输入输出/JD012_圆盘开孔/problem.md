# JD012：圆盘开孔

> **AcWing 613** | 第1章 · 持剑叩门 | 知识点：浮点数运算

## 题目描述

赵晴儿在沙盘上画了五个图形，每个图形都用A、B、C三个数来定义。她让李少白算出每个图形的面积：
- 三角形：底A高C，面积 = A×C÷2
- 圆形：半径C，面积 = π×C²
- 梯形：上底A下底B高C，面积 = (A+B)×C÷2
- 正方形：边长B，面积 = B²
- 长方形：长A宽B，面积 = A×B

π取3.14159。

## 输入格式

一行，三个浮点数R、r1、r2。

## 输出格式

五行，分别输出 TRIANGULO（三角形）、CIRCULO（圆形）、TRAPEZIO（梯形）、QUADRADO（正方形）、RETANGULO（长方形）的面积，各保留3位小数。格式为 `名称: 面积`。

## 样例

输入：

```text
3.0 4.0 5.2
```

输出：

```text
TRIANGULO: 7.800
CIRCULO: 84.949
TRAPEZIO: 18.200
QUADRADO: 16.000
RETANGULO: 12.000
```

## 解题思路

三角形=A×C/2，圆形=π×C²，梯形=(A+B)×C/2，各保留3位小数。
