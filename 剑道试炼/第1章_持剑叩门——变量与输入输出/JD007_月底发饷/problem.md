# JD007：月底发饷

> **AcWing 609** | 第1章 · 持剑叩门 | 知识点：浮点数运算、格式化输出

## 题目描述

月底发饷，李少白帮账房核算一名弟子的工钱。已知工号、出工天数和每日工钱。

## 输入格式

第一行一个整数，表示工号。第二行两个数：出工天数（整数）和每日工钱（浮点数）。

## 输出格式

第一行输出工号。第二行输出 `SALARY = U$ ` 后跟实发金额，保留两位小数。

## 样例

输入：

```text
25
100 5.50
```

输出：

```text
NUMBER = 25
SALARY = U$ 550.00
```

## 解题思路

实发金额 = 出工天数 × 每日工钱，保留两位小数。
