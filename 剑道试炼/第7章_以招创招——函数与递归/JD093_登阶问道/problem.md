# JD093：登阶问道

> **AcWing 821** | 第7章 · 以招创招 | 知识点：递归、动态规划

## 题目描述

试炼场尽头，一座石阶直通山顶。石阶共有n级，每次只能跨1级或2级。

赵晴儿站在山脚问："从第一级走到第n级，一共有多少种不同的走法？"

李少白想了想："如果我最后一步跨1级，那之前有f(n-1)种走法；如果最后一步跨2级，那之前有f(n-2)种走法……"

"没错，"赵晴儿点头，"这就是递归。"

## 输入格式

一个整数n（1 ≤ n ≤ 20）。

## 输出格式

输出走法总数。

## 样例

输入：

```text
5
```

输出：

```text
8
```

## 解题思路

### 思考过程

站在第 n 级台阶上"回头看"——你是怎么到达这里的？只有两种可能：

- 从第 n-1 级跳 1 级上来
- 从第 n-2 级跳 2 级上来

这两种路径互不重叠、完全穷尽，所以到达第 n 级的走法总数 = 到达第 n-1 级的走法 + 到达第 n-2 级的走法，即 f(n) = f(n-1) + f(n-2)。

### 关键洞察

这和斐波那契数列的递推关系完全一样！区别只在于初始条件不同：

- 斐波那契：f(1)=1, f(2)=1
- 爬楼梯：f(1)=1, f(2)=2（2级台阶可以"1+1"或直接"2"）

理解了这一点，就可以直接用递归（或记忆化递归、递推）来求解。

### 边界情况

- n = 1：只有 1 种走法（跳 1 级）。
- n = 2：有 2 种走法（1+1 或直接 2）。
- n = 20：f(20) = 10946，在 int 范围内，不会溢出。

### 复杂度解释

- **朴素递归 O(2^n)**：每次分裂成两个子问题，形成一棵二叉树，重复计算极多。比如 f(5) 要算 f(4) 和 f(3)，而 f(4) 又要算 f(3) 和 f(2)——f(3) 被算了两遍。
- **记忆化递归 / 递推 O(n)**：用数组把每个 f(i) 存下来，每个值只算一次。总共有 n 个不同的子问题，每个 O(1)，所以总体 O(n)。
- 本题 n <= 20，朴素递归勉强能过；但如果 n 更大（比如 1000），必须用记忆化或递推。
