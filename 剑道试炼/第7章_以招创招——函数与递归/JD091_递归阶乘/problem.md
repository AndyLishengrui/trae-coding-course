# JD091：递归阶乘

> **AcWing 819** | 第7章 · 以招创招 | 知识点：递归

## 题目描述

李少白在丹房翻到一本古籍，上面记载着一种"以丹炼丹"的奇术——要炼n味丹药，先炼好n-1味；要炼n-1味，先炼好n-2味……直到只剩1味，直接炼成。

赵晴儿看了笑道："这就是递归。一个函数调用自己，层层深入，直到触底再层层返回。阶乘的定义本身就是递归的——fact(n) = n × fact(n-1)，fact(1) = 1。"

"用递归重新实现阶乘函数。"

## 输入格式

一个整数n（1 ≤ n ≤ 10）。

## 输出格式

输出n的阶乘。

## 样例

输入：

```text
5
```

输出：

```text
120
```

## 解题思路

### 思考过程

阶乘的数学定义本身就是递归的：n! = n * (n-1)!，而 (n-1)! = (n-1) * (n-2)!……一直展开到 1! = 1 为止。写递归函数时，把这个数学定义"翻译"成代码即可。

### 关键洞察

递归函数的写法遵循三个固定步骤：

1. **终止条件（Base Case）**：当 n == 1 时直接返回 1，不再调用自身——这是递归的"底部"。
2. **递推关系（Recursive Case）**：return n * fact(n-1)——把当前问题分解为更小的子问题。
3. **缩小规模**：每次调用时 n 减 1，确保朝着终止条件靠近。

如果缺少终止条件，函数会无限调用自身，最终栈溢出（Runtime Error）。

### 边界情况

- n = 1：直接返回 1，不进入递归。
- n = 0：虽然题目保证 n >= 1，但 0! = 1 也是正确的，可以作为额外的终止条件。
- n 较大时（本题 n <= 10）：10! = 3628800，在 int 范围内。如果 n 更大，需要考虑用 long long。

### 复杂度解释

- **时间复杂度 O(n)**：递归调用 n 次，每次做一次乘法，总共 n 次操作。
- **空间复杂度 O(n)**：递归调用栈深度为 n，每层占一个栈帧。
- 为什么不是 O(n^2)：每次递归只做常数时间的乘法，不会在每层循环 n 次。
