# JD040：九九归真

> **AcWing 711** | 第3章 · 千回百转 | 知识点：循环、格式化输出

## 题目描述

赵晴儿教李少白背乘法口诀。她写下一个数N，让李少白从1乘到10，按格式列出N的乘法表：「i x N = i*N」。

## 输入格式

一个整数N。

## 输出格式

10行，格式为 `i x N = i*N`。

## 样例

输入：

```text
140
```

输出：

```text
1 x 140 = 140
2 x 140 = 280
3 x 140 = 420
4 x 140 = 560
5 x 140 = 700
6 x 140 = 840
7 x 140 = 980
8 x 140 = 1120
9 x 140 = 1260
10 x 140 = 1400
```

## 解题思路

for循环从1到10，每次输出i x N = i*N。
