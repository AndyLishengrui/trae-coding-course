# JD153：逐边成林

> **AcWing 859** | 第14章 · 千里奔袭 | 知识点：图论

## 题目描述

梁嘉峰说："Kruskal——按边权从小到大排序，逐条加入。如果这条边的两个端点已经在同一连通块里（用并查集判断），就跳过；否则加入。"

给定一个带权无向图，求最小生成树的总权值。

## 输入格式

第一行两个整数n和m。接下来m行每行三个整数a b w。

## 输出格式

一行，最小生成树的总权值。不连通输出impossible。

## 样例

输入：

```text
4 5
1 2 1
1 3 2
2 3 3
2 4 4
3 4 5
```

输出：

```text
7
```

## 解题思路

Kruskal：O(mlogm)。按边权排序，并查集判环。
