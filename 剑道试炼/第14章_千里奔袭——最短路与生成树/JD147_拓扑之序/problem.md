# JD147：拓扑之序

> **AcWing 848** | 第14章 · 千里奔袭 | 知识点：图论

## 题目描述

城际连横。赵晴儿铺开城池图："城池之间有方向道路。排出一个合法的建设顺序——每条道路都是从先建的城池指向后建的。"

梁嘉峰说："拓扑排序——找入度为0的点，输出后删除它的出边，再找下一个入度为0的点。如果有环，就不可能全部输出。"

给定一个有向图，输出拓扑序。有环则输出-1。

## 输入格式

第一行两个整数n和m。接下来m行每行两个整数a b表示一条有向边。

## 输出格式

一行，拓扑序，空格隔开。有环输出-1。

## 样例

输入：

```text
3 3
1 2
2 3
1 3
```

输出：

```text
1 2 3
```

## 解题思路

BFS+入度维护。有环则无解。
