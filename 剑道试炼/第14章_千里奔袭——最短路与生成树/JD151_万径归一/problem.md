# JD151：万径归一

> **AcWing 854** | 第14章 · 千里奔袭 | 知识点：图论

## 题目描述

梁嘉峰铺开全图："多源最短路——任意两点之间的最短距离。Floyd算法：三重循环，dp[i][j] = min(dp[i][j], dp[i][k] + dp[k][j])。"

给定一个带权图，求任意两点之间的最短距离。

## 输入格式

第一行三个整数n、m和q。接下来m行每行三个整数a b w。接下来q行每行两个整数a b。

## 输出格式

q行，每行一个整数。不可达输出impossible。

## 样例

输入：

```text
3 3 2
1 2 2
2 3 1
1 3 4
1 3
2 1
```

输出：

```text
3
3
```

## 解题思路

Floyd：O(n³)。三重循环枚举中间点。
