# JD044：翻倍剑阵

> **AcWing 738** | 第4章 · 排兵布阵 | 知识点：数组、递推

## 题目描述

赵晴儿在沙盘上布下一个翻倍剑阵。她说：「以第一个数为起点，后面每个数都是前一个的两倍。内力如此，出剑亦是如此——一重更比一重强。」

## 输入格式

一个整数V。

## 输出格式

10行，格式为 `N[i] = X`。

## 样例

输入：

```text
6
```

输出：

```text
N[0] = 6
N[1] = 12
N[2] = 24
N[3] = 48
N[4] = 96
N[5] = 192
N[6] = 384
N[7] = 768
N[8] = 1536
N[9] = 3072
```

## 解题思路

N[0]=V，循环N[i]=N[i-1]*2。
