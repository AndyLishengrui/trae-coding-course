# JD043：正剑除邪

> **AcWing 737** | 第4章 · 排兵布阵 | 知识点：数组、遍历

## 题目描述

练功房的石板上有10道剑气留下的痕迹，每道痕迹上刻着一个数。其中有些数带着邪气（负数或零），梁嘉峰让李少白运起纯阳内力，把这些不纯正的数全部净化，替换成1——象征正气归于一元。

## 输入格式

一行，10个整数，用空格隔开。

## 输出格式

替换后的10个数，每行格式为 `X[i] = 值`。

## 样例

输入：

```text
-73
27
-35
50
-67
86
39
-81
-7
31
```

输出：

```text
X[0] = 1
X[1] = 27
X[2] = 1
X[3] = 50
X[4] = 1
X[5] = 86
X[6] = 39
X[7] = 1
X[8] = 1
X[9] = 31
```

## 解题思路

遍历数组，将≤0的元素替换为1。
