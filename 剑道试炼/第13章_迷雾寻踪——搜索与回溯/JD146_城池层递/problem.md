# JD146：城池层递

> **AcWing 847** | 第13章 · 迷雾寻踪 | 知识点：搜索、回溯

## 题目描述

城际连横。赵晴儿铺开城池图："城池之间有道路相连。从城1出发，到每个城池的最短距离是多少？"

梁嘉峰说："BFS——从城1开始，每层扩展一步。第一次到达的城池，层数就是最短距离。"

给定一个有向图和起点1，求每个点到起点的最短距离。

## 输入格式

第一行两个整数n和m。接下来m行每行两个整数a b表示一条有向边。

## 输出格式

一行，n个整数表示每个点到点1的最短距离，不可达输出-1。

## 样例

输入：

```text
4 4
1 2
2 3
1 3
3 4
```

输出：

```text
0 1 1 2
```

## 解题思路

BFS层序遍历，每层距离+1。
