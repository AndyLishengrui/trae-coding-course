# JD078：两卷对校

> **AcWing 762** | 第6章 · 古卷密文 | 知识点：字符串、匹配

## 题目描述

赵晴儿拿着两卷古卷：「看看第二段经文是不是第一段中的一部分——如果是，就算对上了。」

## 输入格式

第一行一个整数k（忽略，用于兼容）。第二行字符串a。第三行字符串b（子串）。

## 输出格式

b是a的子串输出"yes"，否则输出"no"。

## 样例

输入：

```text
abc
d
```

输出：

```text
no
```

## 解题思路

遍历a的每个位置，用strncmp比较是否与b匹配。匹配则输出yes。strncmp(a+i, b, len(b))==0表示b是a的子串。
