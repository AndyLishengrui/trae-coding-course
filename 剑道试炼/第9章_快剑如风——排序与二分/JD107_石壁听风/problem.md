# JD107：石壁听风

> **AcWing 789** | 第9章 · 快剑如风 | 知识点：二分查找

## 题目描述

赵晴儿递给李少白一排刻着数字的石块，从左到右从小到大排好了。她问："数字 3 第一次出现在哪块石块上？最后一次出现在哪？"

李少白想从头数，但石块有十万块。赵晴儿拦住他："石块是有序的，不用一个个看。先看最中间那块——如果中间的数比 3 大，说明 3 只可能在左半边，右半边不用看了。每次都把范围砍一半，这就是二分。"

"找第一次出现的位置和最后一次出现的位置，各二分一次。"李少白接话道。

"对。如果整个范围里都找不到，就说明没有。"

给定一个升序排列的长度为 n 的整数数组和 q 个查询，对每个查询返回目标值的起始位置和终止位置（从0开始），不存在则返回 `-1 -1`。

## 输入格式

第一行两个整数 n 和 q。第二行 n 个整数（升序）。第三行 q 个待查询的整数。

## 输出格式

每行两个整数，起始位置和终止位置。

## 样例

输入：

```text
6 3
1 2 2 3 3 4
2 3 5
```

输出：

```text
1 2
3 4
-1 -1
```

## 解题思路

### 思考过程

数组有序，要找目标值的起始和终止位置。暴力做法是从头到尾扫描，O(n)。但有序数组可以用二分查找，O(logn)。关键问题是：数组中有重复元素，标准二分只能找到"任意一个"等于目标值的位置，而我们需要找到"第一个"和"最后一个"。解决方法是把标准二分修改两次。

### 关键洞察

两次二分的模板区别在于"找到目标值后怎么收缩边界"：

- **找左边界（第一个 >= x）**：用 `if (a[mid] >= x) r = mid`，意思是"mid 可能就是答案，不能排除它"，所以右边界收缩到 mid。
- **找右边界（最后一个 <= x）**：用 `if (a[mid] <= x) l = mid`，意思是"mid 可能就是答案，不能排除它"，所以左边界收缩到 mid。终止时检查 l 位置是否等于 x。

找到左边界和右边界后，如果左边界位置上的值不等于 x，说明 x 不存在，输出 -1 -1。

### 边界情况

- 目标值不存在：左边界位置上的值 != x，直接输出 -1 -1。
- 目标值只出现一次：左边界 = 右边界。
- 目标值出现在数组最左端或最右端：二分模板仍然正确处理。
- 数组全部是同一个数，目标值就是这个数：左边界 = 0，右边界 = n-1。
- 数组为空（n=0）：题目保证 n >= 1，不需处理。

### 复杂度解释

- **时间 O(q * logn)**：每个查询做两次二分，每次 O(logn)，q 个查询总共 O(q * logn)。
- **为什么不是 O(q * n)**：二分每次把搜索范围砍一半，从 n 个元素中找到目标只需要 logn 步。如果用线性扫描，每步只能排除 1 个元素，需要 n 步。
- **空间 O(1)**：只用了几个变量，不需要额外数组。
