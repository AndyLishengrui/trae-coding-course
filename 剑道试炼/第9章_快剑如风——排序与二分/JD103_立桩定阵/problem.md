# JD103：立桩定阵

> **AcWing 785** | 第9章 · 快剑如风 | 知识点：快速排序、分治

## 题目描述

试炼场上，弟子们按身高排成一列，但顺序完全乱了。梁嘉峰走过去，随便挑了一个弟子站到中间，然后让所有比他矮的站到左边，比他高的站到右边。

"现在左边和右边各自还是乱的，"赵晴儿看出来了。

"对。所以对左边和右边各自重复这个过程——挑一个人，矮的左、高的右。每次都能让一个人站到最终位置上，直到每一组只剩一个人。"梁嘉峰说，"这就是快速排序。一剑分两路，递归再出剑。"

给定一个长度为 n 的整数数列，请用快速排序将其从小到大排序。

## 输入格式

第一行包含整数 n。第二行包含 n 个整数。

## 输出格式

一行，n 个排好序的整数，空格隔开。

## 样例

输入：

```text
5
3 1 2 4 5
```

输出：

```text
1 2 3 4 5
```

## 解题思路

### 思考过程

排序的核心问题是：如何把一个乱序数组变成有序？快排的思路是"分治"——先让一个元素站到正确的位置上（它左边都比它小，右边都比它大），然后对左右两半分别重复这个过程。当每一半都只剩一个元素时，整个数组就有序了。

### 关键洞察

分区（Partition）的具体做法：

1. 选一个基准元素（通常取中间位置的值）。
2. 用双指针：左指针从左往右找 >= 基准的元素，右指针从右往左找 <= 基准的元素，交换它们。
3. 当左指针越过右指针时分区完成——左半部分 <= 基准，右半部分 >= 基准。
4. 对左右两半递归执行同样的操作。

每一轮分区都让基准元素站到最终位置上，这就是快排的"快"所在。

### 边界情况

- 数组已有序（升序或降序）：如果基准选得不好（比如总选第一个），每次只能排除一个元素，退化为 O(n²)。选中间元素作为基准可以有效避免。
- 数组元素全部相同：双指针必须正确处理相等元素，否则可能死循环。标准模板中左指针找 >= 右指针找 <= 已经处理了这种情况。
- n = 1：只有一个元素，无需排序，直接返回。

### 复杂度解释

- **平均 O(nlogn)**：每次分区把数组大致分成两半，递归深度为 logn，每层遍历 n 个元素，所以 n * logn。
- **最坏 O(n²)**：每次分区极度不均衡（一边 0 个一边 n-1 个），退化为 n + (n-1) + ... + 1 = n(n-1)/2。选中间元素作为基准可以避免。
- **空间复杂度 O(logn)**：递归栈的深度，平均为 logn；最坏为 O(n)。
