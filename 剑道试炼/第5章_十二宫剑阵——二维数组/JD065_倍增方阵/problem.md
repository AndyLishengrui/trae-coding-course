# JD065：倍增方阵

> **AcWing 755** | 第5章 · 十二宫剑阵 | 知识点：二维数组、幂运算

## 题目描述

「此阵每一格，剑气强度皆由剑气原点(0,0)倍增而来。」

赵晴儿剑尖轻点沙盘，

「位在(i,j)的剑势，强度为2的(i+j)次方。一生二，二生四，剑气倍增如潮水蔓延。」

## 输入格式

多行，每行一个整数N（0≤N≤15）。N=0时结束。

## 输出格式

每个N输出一个N阶矩阵，每行N个整数用空格隔开。每个矩阵后跟一个空行。

## 样例

输入：

```text
3 0
```

输出：

```text
1 2 4 
2 4 8 
4 8 16
```

## 解题思路

M[i][j] = 2^(i+j)。用位运算 1<<(i+j) 或 pow函数。
