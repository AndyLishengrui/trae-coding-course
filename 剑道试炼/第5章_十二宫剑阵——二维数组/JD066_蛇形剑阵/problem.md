# JD066：蛇形剑阵

> **AcWing 756** | 第5章 · 十二宫剑阵 | 知识点：二维数组、模拟

## 题目描述

「剑阵蜿蜒如蛇，以身引气，气走周身。」

赵晴儿在沙盘上画了一个n行m列的剑阵，

「从左上角开始，依次填入从1到n×m的剑气。行到尽头便拐弯，似灵蛇折返。」

## 输入格式

一行，两个整数n和m。

## 输出格式

n行，每行m个整数用空格隔开。输出后跟一个空行。

## 样例

输入：

```text
3 3
```

输出：

```text
1 2 3 
8 9 4 
7 6 5
```

## 解题思路

模拟蛇形遍历：右→下→左→上循环。维护四个边界。
