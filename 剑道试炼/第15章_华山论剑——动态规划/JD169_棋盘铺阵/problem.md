# JD169：棋盘铺阵

> **AcWing 0** | 第15章 · 华山论剑 | 知识点：动态规划

## 题目描述

华山之巅，云雾缭绕。四位绝顶高手已经等候多时。

第一位是棋圣。他摆出一个n×m的棋盘和一堆1×2的骨牌："铺满整个棋盘，有多少种铺法？"

赵晴儿凝视棋盘，忽然眼中一亮："状压DP——逐列处理。用二进制掩码表示哪些格子被前一列的横骨牌占了。"

棋圣抚掌而笑："好一个状压！老夫输了。"

## 输入格式

多组数据，每组两个整数n和m。以0 0结束。

## 输出格式

每组一行，铺法总数。

## 样例

输入：

```text
2 3
```

输出：

```text
3
```

## 解题思路

状压DP：逐列处理，状态掩码表示被前一列横骨牌占的格子。
