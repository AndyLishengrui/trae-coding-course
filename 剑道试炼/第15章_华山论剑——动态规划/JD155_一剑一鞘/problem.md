# JD155：一剑一鞘

> **AcWing 0** | 第15章 · 华山论剑 | 知识点：动态规划

## 题目描述

华山脚下，试剑台前。西域刀客赫连铁拔出背上唯一的刀鞘，鞘中却藏着N柄短刀，每柄有重量和锋芒。刀鞘容量有限——选哪些刀，才能让锋芒之和最大？

李少白拔剑上前。梁嘉峰低声道："每柄刀只能选一次——01背包。逆序遍历容量，dp[j] = max(dp[j], dp[j-v]+w)。"

李少白深吸一口气，提笔写下。赫连铁看了答案，缓缓点头："第一关，过了。"

## 输入格式

第一行两个整数N和V。接下来N行每行两个整数v和w。

## 输出格式

一行，最大价值。

## 样例

输入：

```text
4 5
1 2
2 4
3 4
4 5
```

输出：

```text
8
```

## 解题思路

### 思考过程

有 N 件物品，每件只能选一次，背包容量为 V，求最大价值。暴力做法是枚举所有 2^N 种选法，N 稍大就超时。动态规划的思路是：用 dp[j] 表示"容量为 j 的背包能装的最大价值"，依次考虑每件物品，更新 dp 数组。

### 关键洞察

状态转移方程：`dp[j] = max(dp[j], dp[j - v[i]] + w[i])`

- `dp[j]`：不选第 i 件物品，保持原值。
- `dp[j - v[i]] + w[i]`：选第 i 件物品，腾出 v[i] 的空间，加上第 i 件的价值。

**为什么必须逆序遍历 j（从 V 到 v[i]）？** 因为每件物品只能选一次。如果正序遍历，dp[j - v[i]] 可能已经在本轮被更新过（相当于同一件物品被选了两次），就变成了完全背包。逆序保证 dp[j - v[i]] 还是"没选第 i 件物品时"的旧值。

### 边界情况

- dp 数组初始化为全 0：表示容量为 j 时初始最大价值为 0。
- 物品体积 v[i] > 当前容量 j：跳过，不更新。
- 所有物品体积都 > V：一个都装不下，答案为 0。
- N = 0：没有物品，答案为 0。

### 复杂度解释

- **时间 O(N * V)**：外层遍历 N 件物品，内层遍历容量 V 到 v[i]，每个状态转移 O(1)。
- **空间 O(V)**：一维滚动数组，只需 V+1 个位置。如果用二维数组是 O(N * V)，可以优化到一维。
- **为什么不是 O(2^N)**：暴力枚举每种选法是指数级；DP 用"容量"作为状态，把指数级的决策压缩为 N * V 个状态，每个状态 O(1) 转移。
