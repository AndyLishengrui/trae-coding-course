# JD167：整分剑法

> **AcWing 0** | 第15章 · 华山论剑 | 知识点：动态规划

## 题目描述

对手是一位数学大师，他写下数字n："把它拆成若干正整数之和，有多少种拆法？"

赵晴儿上前："完全背包——从1到n，每个数可以用无限次。dp[j] += dp[j-i]，模1e9+7。"

大师推了推眼镜："你用背包来解整数划分？有意思。"

## 输入格式

一个整数n（1≤n≤1000）。

## 输出格式

一行，划分方案数模1e9+7。

## 样例

输入：

```text
5
```

输出：

```text
7
```

## 解题思路

完全背包DP：dp[j] += dp[j-i]，i从1到n。模1e9+7。
