# JD172：千机棋局

> **AcWing 0** | 第15章 · 华山论剑 | 知识点：动态规划

## 题目描述

华山绝顶，风雷激荡。最后一位对手——棋魔，传说中的千机棋圣。他缓缓展开一张巨大的人员图谱："这是宗门的命脉——每个人有一个直属上司。现在要派人出征，但一个士兵和他的上司不能同时出征——否则后方崩溃。每个士兵有不同的战斗力。"

梁嘉峰在台下喊道："树形DP！dp[u][0]表示u留守时子树的最大战力，dp[u][1]表示u出征时。出征则下属必须留守，留守则下属可出可留。找到根节点，DFS一遍！"

李少白深吸一口气，闭上眼睛。他想起了第一天来到剑道宗的那个下午——梁嘉峰递给他两枚铁令，赵晴儿在沙盘上画圆。从变量到递归，从数组到图论，从排序到动态规划……每一步都是剑道的修行。

他睁开眼睛，提笔写下最后一行代码。

棋魔看着答案，沉默良久，终于起身，深深一揖："华山论剑，到此为止。"

梁嘉峰走上前来，拍了拍李少白的肩膀："恭喜。你可以出师了。"

赵晴儿在一旁笑了："别急，回去还得教下一届呢。"

## 输入格式

第一行一个整数N。第二行N个整数（每个员工的快乐值）。接下来N-1行每行两个整数l k（l的上司是k）。

## 输出格式

一行，最大总快乐值。

## 样例

输入：

```text
7
1 1 1 1 1 1 1
2 6
3 6
4 6
6 7
5 7
```

输出：

```text
5
```

## 解题思路

### 思考过程

问题是在一棵树上选若干节点，使得没有父子同时被选，且选中节点的权值之和最大。这就是经典的"树的最大独立集"问题。

为什么不能用普通 DP？因为树的结构不是线性的——每个节点可能有多个子节点，状态转移需要考虑整棵子树。但树有一个很好的性质：没有环，天然适合从叶子到根递推。

### 关键洞察

状态定义：对每个节点 u，定义两个状态——

- `dp[u][1]`：u 出征（被选中）时，以 u 为根的子树的最大战力。
- `dp[u][0]`：u 留守（不被选中）时，以 u 为根的子树的最大战力。

状态转移方程：

- **u出征**：u 的所有下属必须留守（题目约束），所以 `dp[u][1] = h[u] + sum(dp[v][0])`，其中 v 是 u 的所有子节点。
- **u留守**：u 的下属可以出征也可以留守，取各自最大值，所以 `dp[u][0] = sum(max(dp[v][0], dp[v][1]))`。

实现步骤：

1. 找到根节点（没有上司的那个人，即入度为 0 的节点）。
2. 从根节点开始 DFS，自底向上计算 dp 值。
3. 答案 = max(dp\[root\]\[0\], dp\[root\]\[1\])。

### 边界情况

- 叶子节点：没有子节点，dp\[u\]\[1\] = h\[u\]，dp\[u\]\[0\] = 0。
- 所有人权值为 0：答案为 0。
- 只有一个节点（N=1）：答案 = h[1]。
- 输入中 l k 表示 l 的上司是 k，需要建邻接表时注意方向：k -> l（父 -> 子）。

### 复杂度解释

- **时间 O(N)**：DFS 遍历每个节点恰好一次，每个节点的 dp 计算需要遍历其子节点，但所有节点的子节点总数 = N-1（树的边数），所以总操作次数为 O(N)。
- **空间 O(N)**：邻接表 O(N)，dp 数组 O(N)，递归栈最深 O(N)（链状树）。
- **为什么不是 O(N²)**：每个节点只被 DFS 访问一次，不会重复遍历。树的边数是 N-1，遍历所有边的总代价是 O(N)。
