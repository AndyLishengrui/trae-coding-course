# JD021：沙盘点位

> **AcWing 662** | 第2章 · 歧路逢生 | 知识点：条件判断、象限

## 题目描述

赵晴儿在沙盘上标了一个点P(x, y)，让李少白判断它落在第几象限，还是在坐标轴上，还是在原点。

## 输入格式

一行，两个浮点数x和y。

## 输出格式

输出 `Primeiro`（第一象限）、`Segundo`（第二）、`Terceiro`（第三）、`Quarto`（第四）、`Eixo X`（X轴上）、`Eixo Y`（Y轴上）或 `Origem`（原点）。

## 样例

输入：

```text
4.5 -2.2
```

输出：

```text
Q4
```

## 解题思路

先判断是否在原点或坐标轴上（x==0 或 y==0），再判断象限。
